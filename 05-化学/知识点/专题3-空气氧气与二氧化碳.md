# 专题 3 · 空气、氧气、二氧化碳（八年级）

> 三大气体是中考实验题与方程式默写的绝对主力。**制取装置选择 + 验满/检验**是必考套路。

## 📌 空气

- 组成（体积分数）：**N₂ 78%、O₂ 21%、稀有气体 0.94%、CO₂ 0.03%**
- 测定空气中 O₂ 含量（红磷燃烧法）：原理 $4P+5O_2\xrightarrow{\text{点燃}}2P_2O_5$，进入瓶内水的体积 ≈ 1/5
  - 成功条件：红磷足量、装置气密性好、冷却后读数
  - 不能用木炭/硫（生成气体）、不能用铁丝（不燃烧）
- 污染物：SO₂、NO₂、CO、可吸入颗粒物；CO₂ 不算空气污染物（但致温室效应）

## 📌 氧气

- 性质：无色无味气体，密度略大于空气，不易溶于水；**助燃**（本身不可燃）
- 现象必背：铁丝在 O₂ 中**火星四射**、生成黑色固体（Fe₃O₄）、放热；硫在 O₂ 中明亮的**蓝紫色火焰**（空气中淡蓝色）；木炭发出白光
- 制法：
  - 工业制法：分离液态空气（物理变化）
  - 实验室：加热高锰酸钾 $2KMnO_4\xrightarrow{\Delta}K_2MnO_4+MnO_2+O_2\uparrow$（棉花防粉末）；分解过氧化氢 $2H_2O_2\xrightarrow{MnO_2}2H_2O+O_2\uparrow$
- 验满：带火星木条**放瓶口**复燃；检验：木条**伸入瓶中**复燃

## 📌 二氧化碳

- 性质：无色无味，密度大于空气，**能溶于水**；不燃烧不支持燃烧；CO₂ + H₂O → H₂CO₃（紫色石蕊变红）；CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O（**澄清石灰水变浑浊 = CO₂ 的检验方法**）
- 制法（实验室）：大理石/石灰石 + 稀盐酸 $CaCO_3+2HCl=CaCl_2+H_2O+CO_2\uparrow$
  - 不能用稀硫酸（CaSO₄ 微溶覆盖表面反应停止）；不能用碳酸钠（太快）
  - 验满：燃着木条放瓶口熄灭；检验：通入澄清石灰水
- 收集：**向上排空气法**（能溶于水，不能用排水法）
- CO：无色无味**有毒**（与血红蛋白结合）、可燃性、还原性；煤炉中毒预防

## 🧩 制取装置选择通法（实验题套路）

- **发生装置**：固+固加热型（KMnO₄）/ 固+液不加热型（H₂O₂、大理石+盐酸）
- **收集装置**：排水法（不易溶于水：O₂）/ 向上排空气（密度大于空气：O₂、CO₂）/ 向下排空气（密度小于空气：H₂）
- 还原氧化铜实验（H₂/CO/C 还原 CuO）→ 见 [[05-化学/专题/实验操作考点-化学]]

## 🔥 易错点

- 符号 ↑↓ 使用：反应物有气体不标；溶液中生成沉淀才标 ↓
- 铁在氧气中燃烧瓶底放少量水/细沙（防炸裂）
- "验满"在瓶口、"检验"进瓶内——位置写错不得分
- 现象描述不能写成结论（"生成白色沉淀"✓，"生成 CaCO₃"✗）
