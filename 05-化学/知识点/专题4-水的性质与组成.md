# 专题 4 · 水的性质与组成（八年级）

> 中等权重专题：电解水实验结论 + 硬水软水 + 净水方法是高频考点。

## 📌 水的组成（电解水实验）

- $2H_2O\xrightarrow{\text{通电}}2H_2\uparrow+O_2\uparrow$
- **口诀：正氧负氢，体积比氢:氧 = 2:1**（正极氧气、负极氢气）
- 检验：正极气体使带火星木条复燃（O₂）；负极气体可燃、淡蓝色火焰（H₂）
- 结论：水由**氢元素和氧元素**组成；化学变化中分子可分而原子不可分

## 📌 水的性质

- 物理性质：无色无味液体，4℃ 时密度最大（1.0 g/cm³），反常膨胀
- 化学性质：通电分解；与 CO₂ 反应（碳酸）；与 CaO 反应（CaO + H₂O → Ca(OH)₂，放热）

## 📌 水的净化

- 净化程度由低到高：静置沉淀 → 吸附沉淀（明矾）→ 过滤 → 吸附（活性炭，物理吸附色素异味）→ 蒸馏（**净化程度最高**）
- 自来水：氯气/二氧化氯消毒（化学变化）
- **硬水 vs 软水**：含较多可溶性钙镁化合物 = 硬水；区分方法：**肥皂水**（泡沫多为软水，浮渣少泡多为硬水）；硬水软化：煮沸（生活中）、蒸馏（实验室）
- 长期饮用硬水的危害：水垢（CaCO₃、Mg(OH)₂）

## 📌 水资源保护

- 水体污染来源：工业三废、农业化肥农药、生活污水
- 节水措施：一水多用、农业滴灌喷灌

## 🔥 易错点

- 电解水"氢二氧一"是**体积比**，不是质量比（质量比氢:氧 = 1:8）
- 明矾净水是吸附**悬浮杂质**沉淀，不能除可溶性杂质
- 活性炭吸附是物理变化；煮沸降低硬度是化学变化（生成沉淀）
- 冰水混合物是纯净物（都是 H₂O）
