# 专题 6 · 化学变化及其表示（八年级）

> 📖 本文是概要版（考前速查）；第一次学或没学懂 → 详细版：[[05-化学/知识点详解/专题6-化学变化及其表示]]

> 质量守恒定律 + 化学方程式 = 中考计算题的基础。**化学计算（第 1 大题常客）全部从这页长出来。**

## 📌 质量守恒定律

- 内容：参加化学反应的各物质质量总和 = 反应后生成的各物质质量总和
- 微观本质：**反应前后原子的种类、数目、质量都不变**（"三不变"）
- "六不变、两变、两可能变"：
  - 不变：原子种类、数目、质量；元素种类、质量；总质量
  - 变：物质种类、分子种类
  - 可能变：分子数目、元素化合价
- 应用：解释现象、推物质组成（质量差法）、配平依据

## 📌 化学方程式

- 书写两原则：以客观事实为依据；遵守质量守恒定律
- 书写步骤：写（左反应物右生成物）→ 配（最小公倍数配平）→ 注（条件、↑↓）→ 等（短线改等号）
- **四个基本反应类型**：

| 类型 | 形式 | 例子 |
| ---- | ---- | ---- |
| 化合 | A+B→AB | C+O₂→CO₂ |
| 分解 | AB→A+B | 电解水 |
| 置换 | A+BC→AC+B | Fe+CuSO₄、H₂+CuO |
| 复分解 | AB+CD→AD+CB | 酸碱中和、碳酸盐+酸 |

- （不属于四类的：CO 还原 CuO——反应物两种化合物+单质? 注意 CO+CuO 不属置换，因 CO 是化合物）

## 📌 化学计算三步法（上海中考格式）

1. 设未知数（设 x，不带单位）
2. 写正确的化学方程式（**配平错误后面全错**）
3. 找相关物质相对分子质量和已知量、未知量 → 列比例式 → 求解 → 答

**微观意义题**（一轮专项）：给出方程式，问"每 N 个 A 分子与 M 个 B 分子反应生成…"——看化学计量数之比。

## 🔥 易错点

- "参加"化学反应的质量总和——不参加反应的（如催化剂、过量反应物）不计入
- 条件"点燃/加热 Δ/高温/催化剂"写错位置或漏写
- ↑↓ 的使用规则（见专题3笔记）
- 计算题：相对分子质量算 2 倍时（如 2H₂O = 2×18=36），漏乘系数最常见
- 质量差法：固体减少量 = 生成气体质量（反应前后都在固体状态的场景）
