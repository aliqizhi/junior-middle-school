# 专题 1-2 · 化学之门与实验探究（八年级）

> 化学入门双专题：语言符号系统 + 实验基本操作。**基本操作是实验题和 5 月实验操作考的地基。**

## 📌 化学使生活更美好（专题 1）

- 化学研究对象：物质的组成、结构、性质、变化
- **物理变化 vs 化学变化**：有无**新物质**生成（判据：燃烧、生锈、发光放热、变色、生成气体/沉淀——但这些都只是"可能"的辅助判据，本质看新物质）
- 物理性质 vs 化学性质（是否需要通过化学变化表现）
- 通用的化学语言：元素符号（1-20 号必须默写）→ 化学式 → 化学方程式

## 📌 体验化学实验探究（专题 2）

### 常用仪器与操作

- 可加热仪器：试管（可直接加热）、烧杯/烧瓶（垫石棉网）、蒸发皿
- 量筒：**不能加热、不能反应容器**；读数平视凹液面最低处
- 药品取用"三不"：不闻（扇闻）、不摸、不尝；剩余药品不放回原瓶
- 液体倾倒：瓶塞**倒放**、口紧挨、标签朝手心
- 酒精灯：外焰加热、禁止吹灭（灯帽盖灭）、禁止对燃

### 物质的提纯

| 方法 | 除什么 | 关键要点 |
| ---- | ---- | ---- |
| 过滤 | 不溶性固体 | **一贴二低三靠**；滤纸边缘低于漏斗口 |
| 蒸发 | 可溶性固体结晶 | 加热搅拌、**出现较多晶体即停**（余热蒸干） |
| 蒸馏 | 除去可溶性杂质（水净化） | 温度计水银球在支管口 |

- 粗盐提纯步骤：溶解 → 过滤 → 蒸发（玻璃棒作用各不同：搅拌加速溶解/引流/搅拌散热）

### 实验探究流程

提出问题 → 猜想假设 → 设计实验（**控制变量**）→ 收集证据 → 得出结论 → 反思评价

## 🔥 易错点

- 爆炸性混合物：可燃气体 + 空气点燃前**必须验纯**
- 量取液体仰视读数偏小、俯视偏大（"仰小俯大"——量出的实际量相反！）
- 过滤后滤液仍浑浊：滤纸破损/液面高于滤纸边缘/仪器不净
- 探究题结论必须回扣"控制变量"：改变一个量、控制其余量
