# 专题 7 · 溶液（九年级）★一模范围

> 📖 本文是概要版（考前速查）；第一次学或没学懂 → 详细版：[[05-化学/知识点详解/专题7-溶液]]

> 溶解度曲线 + 溶质质量分数计算 = 化学计算题的另一大源。学校已超前完成本专题。

## 📌 溶液基础

- 溶液 = 溶质 + 溶剂；**均一、稳定**的混合物
- 溶解过程：扩散吸热 + 水合放热——NaOH 溶解放热明显、NH₄NO₃ 溶解吸热、NaCl 温度变化不大
- 乳化（洗涤剂去油污，乳化作用）vs 溶解（汽油去油污）

## 📌 饱和与不饱和

- 饱和溶液：一定温度下、一定量溶剂里**不能再溶解**某溶质
- 转化（大多数固体）：饱和 ⇄ 不饱和：**加溶剂/升温 → 不饱和**；加溶质/蒸发溶剂/**降温 → 饱和**（Ca(OH)₂ 反向！）
- 饱和溶液不一定浓，不饱和不一定稀（同溶质比较才有意义）

## 📌 溶解度

- 固体溶解度：一定温度下，**100g 溶剂**里达到饱和状态所溶解的质量（四要素：温度、100g 溶剂、饱和、克数）
- 影响因素：内因（溶质溶剂性质）+ 外因（**温度**）；大多数固体随温度升高增大（Ca(OH)₂ 反常下降）
- **溶解度曲线三用法**：
  1. 比较同一温度下溶解度大小
  2. 判断结晶方法：陡升型（KNO₃）→ **降温结晶（冷却热饱和溶液）**；缓平型（NaCl）→ **蒸发结晶**
  3. 判断析出/混合物提纯（KNO₃ 中混少量 NaCl → 降温结晶）
- 气体溶解度：随温度升高**减小**、随压强增大**增大**（烧开水冒泡、汽水开盖冒气）

## 📌 溶质质量分数

$$\text{溶质质量分数}=\dfrac{\text{溶质质量}}{\text{溶液质量}}\times100\%$$

- 溶液质量 = 溶质 + 溶剂；稀释前后**溶质质量不变**（稀释计算的核心）
- 配制一定溶质质量分数的溶液：计算 → 称量（量取）→ 溶解 → 装瓶贴标签
  - 误差分析：俯视量水（水少 → 偏大）、砝码生锈（偏小）、左码右物（偏小）
- 混合溶液质量分数：$w=\dfrac{m_1w_1+m_2w_2}{m_1+m_2}$

## 🔥 易错点

- 溶解度"100g 水"基准别忘了写温度
- 稀释加水量 = 稀释后溶液质量 − 原溶液质量（不是溶质质量差）
- 蒸发溶剂析晶后质量分数：饱和状态先查该温度溶解度，不能直接用原分数
- 结晶方法选错（KNO₃ 用蒸发结晶 = 错）
- 化学变化中溶液质量变化：析出沉淀/放出气体要减去，溶解要加上
