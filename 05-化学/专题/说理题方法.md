# 化学说理题方法（新中考失分重灾区）

> 老师纪要："中考化学命题趋势——减少记忆性题目，增加情景化、说理类题目……说理题占比高、失分严重，强调在练习中重视说理表达的订正与反思。"

## 什么是说理题

题目要求"**请解释原因 / 说明理由 / 你的判断依据是什么 / 为什么**"的题。按新中考说法，考的是"证据推理与模型认知"素养——**不能只答结论，必须给逻辑链**。

## 万能三段式

1. **判断/结论**：直接回答问题本身（一句话）。
2. **依据**：引用化学原理/规律（用规范术语，别口语化）。
3. **回扣情境**：把原理套到题目情境收尾（"所以…"）。

**示例**：为什么炒菜用铁锅比铝锅更补铁？
- 判断：因为铁锅在使用中会有微量铁元素进入食物。
- 依据：铁是人体必需元素，缺铁会引起贫血。
- 回扣：所以用铁锅烹调能补充少量铁元素。

## 常见说理套路（题型清单）

| 情境类型 | 核心依据 |
| ---- | ---- |
| 为什么用…而不用… | 性质决定用途（如 CO₂ 灭火：不燃不助燃、密度大） |
| 为什么某操作后…（实验） | 操作目的 + 原理（"防止…""便于…"） |
| 图像/数据变化解释 | 先说变量关系，再说原理（"温度升高，分子运动加快…"） |
| 工艺流程某步的作用 | 该步除什么/防什么（"加入过量 X 是为了将 Y 完全除去"） |
| 环保/安全情境 | 相关化学性质 + 影响路径 |
| 除杂/鉴别依据 | 沉淀/气体/颜色现象 + 复分解条件或金属活动性 |

## 高分细节

- 用化学术语：写"使指示剂变色"而不是"变色了"；写"金属活动性比氢强"而不是"比较活泼"。
- 微观解释宏观："分子间有间隔""原子种类不变"。
- 流程图题：每一步箭头都问自己"进来什么、出去什么、为什么"。
- 订正时**单独分析失分原因**：没答到点（缺依据）？没逻辑链（跳步）？还是术语不规范？（化学老师明确要求的订正方式）

## 训练节奏

- 每周综合卷的说理题逐条订正，录入错题卡时错因分类多为"**表达不规范**"
- 自己出声讲一遍（费曼法，家长当听众——化学纪要的"小老师"建议）
