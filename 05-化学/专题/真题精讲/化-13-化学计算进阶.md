# 化-13 真题精讲 · 化学计算进阶

> **教材对照**：物质的量与计算 → **新教材专题 5**（物质的微观构成）＋**专题 6**（化学变化及其表示）；能源与环保情境 → 专题 10，见 [[05-化学/学科总览]]。

## 📝 题目

**题 1（规范计算·制氢情境）** 按生产来源与碳排放，氢能分为：灰氢（化石燃料制氢，碳排放高）、蓝氢（天然气制氢，辅以 CO₂ 捕捉与封存）、绿氢（可再生能源电解水制氢，全过程 100% 绿色）。
(1) 煤炭生成"灰氢"属于＿＿（填"物理变化"或"化学变化"）。
(2) 通过反应 $CH_4+H_2O\xrightarrow[\text{催化剂}]{\text{高温}}CO+3H_2$ 制备的氢气属于＿＿；消耗 3 mol 甲烷，理论上可制取＿＿克氢气？（根据化学方程式计算）

**题 2（规范计算·火箭情境）** 朱雀二号火箭以液氧和液态甲烷作推进剂。
(1) 甲烷（CH₄）由＿＿种元素组成，1 mol CH₄ 中约含有＿＿个碳原子。
(2) 甲烷在氧气中充分燃烧的化学方程式是＿＿。
(3) 某种制取甲烷的反应：$CO_2+4H_2\xrightarrow{\text{催化剂}}CH_4+2X$，X 的化学式是＿＿。
(4) 电解水实验中，每分解 18 g 水可生成氧气的物质的量是＿＿ mol。（根据化学方程式计算）

**题 3（守恒法补全）** 天文观测证认出星际分子，其中有水、氨气和丙酮。
(1) 水中的氧元素以＿＿态存在；氢气分子与氧气分子在一定条件下生成水，写出化学方程式。
(2) NH₃ 中氮、氢原子个数比为＿＿；NH₃ 的摩尔质量为＿＿。
(3) 丙酮（C₃H₆O）由＿＿种元素组成，属于＿＿（填"有机物"或"无机物"）；实验室加热醋酸钙晶体制丙酮，请补全：$CaC_4H_8O_5\xrightarrow{\Delta}C_3H_6O\uparrow+\underline{\ \ }+H_2O$。

**题 4（表格信息计算）** 以四氯化碳和金属钠为原料在 700℃ 隔绝空气反应可制金刚石：$CCl_4+4Na\xrightarrow{700^\circ C}C+4X$。
(1) 四氯化碳由＿＿种元素组成；金刚石中碳元素以＿＿态存在；X 的化学式是＿＿。
(2) 16 g 甲烷在不同条件下的体积如下表：

| 条件 | 0℃/101 kPa | 20℃/101 kPa | 0℃/202 kPa |
| ---- | ---- | ---- | ---- |
| 体积 | 22.4 L | 24.0 L | 11.2 L |

Ⅰ、甲烷属于＿＿（填"有机物"或"无机物"）；Ⅱ、16 g 甲烷中约含多少个甲烷分子？Ⅲ、对比表中数据：压强变大，甲烷分子间的间隔＿＿（填"变大""变小"或"不变"）。

## 🧭 思路导航（渐进提示）

**题 1**
- **提示 1（识别）**：表格定类＋方程式计算；钥匙是"新物质生成与否"和**计量数比＝物质的量之比**。
- **提示 2（突破）**：制氢分类只看制法对碳排放的处理；计算走"设列算答"，CH₄ 与 H₂ 按 1:3 放大。
- **提示 3（路线）**：变化判断 → 对照表格定"蓝氢" → 设 x（mol）→ 关系式 1:3 → 换算质量。

**题 2**
- **提示 2（突破）**：1 mol CH₄ 含 1 mol 碳原子；推 X 用原子账；电解水按 2H₂O ~ O₂ 取半。
- **提示 3（路线）**：组成与微粒数 → 写燃烧方程式并配平 → 守恒推 X → 18 g 先化成 mol 再代入计算。

**题 3**
- **提示 2（突破）**：元素存在形态看"游离态＝单质"；补全方程式是**守恒三段式**的标准舞台。
- **提示 3（路线）**：数两边的原子账 → 差额连同 Ca 归入未知物 → 报账目写结论。

**题 4**
- **提示 2（突破）**：表格题先找"只变一个量"的两组数据（同温比压强、同压比温度）；分子数走 m→n→N。
- **提示 3（路线）**：守恒推 X → 有机物判定 → 16 g ÷ 16 g/mol = 1 mol → 6.02×10²³ → 由 22.4 L→11.2 L 判间隔。

## ✍️ 详解

**题 1**：(1) 煤炭制氢生成了新物质氢气（等），属于**化学变化**。
(2) 天然气制氢辅以 CO₂ 捕捉与封存，对照表格属**蓝氢**。
解：设可制取氢气的物质的量为 x。$$CH_4+H_2O\xrightarrow[\text{催化剂}]{\text{高温}}CO+3H_2$$
$$1\text{ mol}\qquad\qquad\qquad\quad 3\text{ mol}$$
$$3\text{ mol}\qquad\qquad\qquad\quad x$$
列式：1/3 = 3/x，x = 9 mol；m(H₂) = 9 mol × 2 g/mol = **18 g**。答：理论上可制取 18 g 氢气。

**题 2**：(1) 甲烷由碳、氢 **2** 种元素组成；1 mol CH₄ 含 1 mol 碳原子 ≈ **6.02×10²³** 个。
(2) $$CH_4+2O_2\xrightarrow{\text{点燃}}CO_2+2H_2O$$（C 1=1，H 4=4，O 4=4 ✓）
(3) 反应前 C 1、O 2、H 8；反应后已知部分（CH₄）含 C 1、H 4，差额归 2X：每个 X 含 H 2、O 1 → **X = H₂O**。
(4) 解：设生成氧气的物质的量为 y。n(H₂O) = 18 g ÷ 18 g/mol = 1 mol。$$2H_2O\xrightarrow{\text{通电}}2H_2\uparrow+O_2\uparrow$$
列式：2 : 1 = 1 mol : y，y = **0.5 mol**。答：可生成氧气 0.5 mol。

**题 3**：(1) 水是化合物，氧元素以**化合态**存在；$$2H_2+O_2\xrightarrow{\text{一定条件}}2H_2O$$（H 4=4，O 2=2 ✓）
(2) N : H = **1 : 3**；M(NH₃) = 14 + 1×3 = **17 g/mol**。
(3) C₃H₆O 含 C、H、O **3** 种元素，含碳的化合物 → **有机物**；1 mol C₃H₆O 含 1 mol 氧原子 ≈ 6.02×10²³ 个。
补全（三段式）：**判断**——未知物为 **CaCO₃**。**依据**——反应前后原子种类、数目不变：反应前 Ca 1、C 4、H 8、O 5；反应后已知部分（C₃H₆O＋H₂O）含 C 3、H 8、O 2，差额为 Ca 1、C 1、O 3，恰构成 1 个 CaCO₃。**回扣情境**——代回方程式 $CaC_4H_8O_5\xrightarrow{\Delta}C_3H_6O\uparrow+CaCO_3\downarrow+H_2O$，两边原子账闭合，补全成立。

**题 4**：(1) 四氯化碳由 C、Cl **2** 种元素组成；金刚石是碳单质，碳以**游离态**存在。
守恒推 X（三段式简写）：反应前 C 1、Cl 4、Na 4；反应后已知 C 1，差额 Cl 4、Na 4 归 4X → 每个 X 含 Na 1、Cl 1 → **X = NaCl**。
(2) Ⅰ、甲烷含碳 → **有机物**。Ⅱ、解：n(CH₄) = 16 g ÷ 16 g/mol = 1 mol，N = 1 mol × 6.02×10²³/mol = **6.02×10²³ 个**。答：约含 6.02×10²³ 个甲烷分子。Ⅲ、同温（0℃）下压强加倍（101→202 kPa），体积 22.4 L→11.2 L，分子个数不变而体积减半 → 分子间隔**变小**（补充：同压下 0℃→20℃，22.4 L→24.0 L，温度升高间隔变大）。

## ⚠️ 评分点与易错

- 规范计算四步"**设、列、算、答**"缺一不可；设的量要带单位（设物质的量为 x，不是设质量为 x mol）。
- 用 mol 解题先把已知量**统一成物质的量**，再按计量数比列比例；直接拿质量列 1:3 是高频失分。
- 关系式法（CH₄ ~ 3H₂）可跳过中间产物一步到位，但要写明"由方程式计量数比"作依据。
- 守恒推化学式**别漏系数**（4X 是四份 X、2X 是两份 X），推出后必须代回方程式验原子账。
- 表格题先控制变量再读数：比较压强影响必须**同温**，比较温度影响必须**同压**；"间隔变小"不要写成"分子变小"。
- 摩尔质量带单位 g/mol，题 3(2) 答"17"不带单位会被扣分；游离态/化合态只对**元素**而言，说"水中的氧分子"直接错。
