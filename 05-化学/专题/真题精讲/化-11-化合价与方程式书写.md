# 化-11 真题精讲 · 化合价与方程式书写

> **教材对照**：化合价与化学式 → **新教材专题 5**；方程式书写与配平 → **新教材专题 6**，见 [[05-化学/学科总览]]。

## 📝 题目

**题 1（化合价计算）** (1) 铁酸镍（NiFe₂O₄）可作为催化剂将 CO₂ 转化为 O₂，已知其中 Fe 为 +3 价，则 Ni 元素的化合价为（　）
A．+1　B．+2　C．+3　D．+4
(2) 一氧化二氮（N₂O）在手术中常用作麻醉剂，其中氮元素的化合价为（　）
A．−2　B．−1　C．+1　D．+2

**题 2（由守恒推化学式）** (1) 次氯酸钠（NaClO）可用于消毒杀菌，制备次氯酸钠的化学方程式为 2NaOH + Cl₂ = X + H₂O + NaClO，X 的化学式为（　）
A．NaCl　B．NaClO₃　C．Na₂O　D．Na₂O₂
(2) 发射通讯卫星的火箭上发生的化学反应：2N₂H₄ + N₂O₄ = 3N₂ + 4X，其中 X 的化学式是（　）
A．N₂O　B．O₂　C．H₂O　D．NO

**题 3（方程式正误与配平）** 下列化学方程式书写正确的是（　）
A．$2KClO_3\xrightarrow[\Delta]{MnO_2}2KCl+3O_2\uparrow$
B．$4Fe+2O_2\xrightarrow{\text{点燃}}2Fe_2O_3$
C．$CO_2+C\xrightarrow{\text{高温}}CO$
D．$CaCO_3+2HCl=2CaCl_2+H_2O+CO_2\uparrow$

## 🧭 思路导航（渐进提示）

**题 1**
- **提示 1（识别）**："新物质求化合价"，钥匙是**代数和为零**＋两个锚点（O 取 −2、题给某元素价态）。
- **提示 2（突破）**：设未知价态为 x，按化学式中原子个数展开：x × 个数 ＋ 已知 × 个数 ＋ 氧 × 个数 = 0。
- **提示 3（路线）**：NiFe₂O₄ 一次方程解 x；N₂O 同法，注意 N₂O 是整体设 2y。

**题 2**
- **提示 1（识别）**：方程式缺一项求化学式，本质是**质量守恒的原子账**。
- **提示 2（突破）**：反应前后各元素原子逐个清点，差额除以未知项的系数，即得每个分子的构成。
- **提示 3（路线）**：数账 → 差额归 X → 对照选项确定化学式，最后**代回整体验算**。

**题 3**
- **提示 1（识别）**：方程式正误题，按"化学式 → 配平 → 条件 → ↑↓"四查。
- **提示 2（突破）**：三个错误项各错一处：B 化学式错（应为 Fe₃O₄）、C 未配平、D 未配平。
- **提示 3（路线）**：把错误项改写成正确方程式，改错本身就是最好的配平练习。

## ✍️ 详解

**题 1**：(1) NiFe₂O₄ 中 O 为 −2 价、Fe 为 +3 价，设 Ni 为 x：x + 2×(+3) + 4×(−2) = 0，x + 6 − 8 = 0，x = **+2** → **选 B**。
(2) N₂O 中 O 为 −2 价，设 N 为 y：2y + (−2) = 0，y = **+1** → **选 C**。

**题 2**：(1) 数原子账：反应前 Na 2、O 2、H 2、Cl 2；反应后已知（H₂O + NaClO）提供 H 2、O 2、Na 1、Cl 1。差额归 2X：每个 X 含 Na 1、Cl 1 → **X = NaCl，选 A**。
(2) 反应前 N 2×2＋2 = 6、H 8、O 4；反应后 3N₂ 提供全部 N 6 个。差额归 4X：每个 X 含 H 2、O 1 → **X = H₂O，选 C**。

**题 3**：逐项四查（化学式 → 配平 → 条件 → ↑↓）：
- A：$2KClO_3\xrightarrow[\Delta]{MnO_2}2KCl+3O_2\uparrow$，K、Cl、O 各原子左右相等，条件、"↑"齐全 → **正确**。
- B 错两处：铁在氧气中燃烧生成 **Fe₃O₄** 而非 Fe₂O₃，正确写法 $3Fe+2O_2\xrightarrow{\text{点燃}}Fe_3O_4$（原式本身也未配平：Fe 4≠4、O 4≠6）。
- C 未配平：正确写法 $CO_2+C\xrightarrow{\text{高温}}2CO$。
- D 未配平：CaCO₃ + 2HCl 应生成 **1 个** CaCl₂，正确写法 $CaCO_3+2HCl=CaCl_2+H_2O+CO_2\uparrow$（原式把 CaCl₂ 写成 2 个，Cl 不守恒）。
→ **选 A**。

## ⚠️ 评分点与易错

- 化合价口诀先立锚再算：**O −2、H +1、单质 0、代数和 0**；NiFe₂O₄ 这类"新物质"题就是把锚点搬进陌生化学式。
- 题源排版中题 1(1) 曾出现 NiFe₃O₄/NiFe₂O₄ 两种写法（OCR 讹误）：按"Fe 为 +3 价"和选项答案自洽，化学式应为 **NiFe₂O₄**（Ni +2）。若为 NiFe₃O₄ 会解出 Ni = −1，无此选项。此处以 NiFe₂O₄ 作答。⚠️ 待核对（原 PDF 图文版未复核）。
- 推 X 后必须**代回方程式整体验算一遍**（原子账闭合才算对），只推出不回验容易漏系数错误。
- 高频化学式正误点：Fe₃O₄（不是 Fe₂O₃）、硫酸铁 Fe₂(SO₄)₃（不是 FeSO₄）、氯化铵 NH₄Cl（不是"氯化氨"）。
- 配平最小公倍数法从**只出现一次的元素**（常为金属、O）下手；配平后检查"↑↓"是否该标、条件是否写全。
- 化合价与离子符号写法相反：化合价标在元素符号**正上方**（先符号后数字），离子符号标在**右上角**（先数字后符号，1 省略）——默写卷上两处位置写反即错。
- 方程式里的"Δ"与"高温"不通用：C 还原 CuO、CaCO₃ 分解用"高温"，CO/H₂ 还原 CuO、KClO₃ 分解用"Δ（加热）"。

**常用化合价锚点速查**：K、Na、Ag +1；Ca、Mg、Ba、Zn +2；Al +3；O −2；H +1；氢氧根 OH −1、硝酸根 NO₃ −1、碳酸根 CO₃ −2、硫酸根 SO₄ −2。单质中元素化合价为 0；"先写正负号、再写数值，1 不省略"是标注格式要求。
