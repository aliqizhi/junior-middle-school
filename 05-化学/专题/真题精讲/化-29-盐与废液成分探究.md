# 化-29 真题精讲 · 盐与废液成分探究

> **教材对照**：旧教材"6. 常用的金属和盐 → 6.2 盐和肥料" → **新教材专题 8 酸、碱、盐**（盐与复分解、成分探究），见 [[05-化学/学科总览]]。

## 📝 题目

**题 1（废液成分探究）** 用 NaOH 溶液与稀盐酸做中和实验，混合后对溶液中溶质的组成提出猜想：
①甲同学猜想：只含 NaCl；
②乙同学猜想：含 NaCl、NaOH 和 HCl。
(1) 甲、乙两位同学的猜想都合理吗？说明理由。
(2) 请提出一个不同的猜想，并设计实验证明。

**题 2（盐的制备流程）** 用碳酸钠溶液与石灰水反应制取氢氧化钠：
(1) 发生反应的化学方程式＿＿；通过＿＿操作得到无色滤液；再通过＿＿操作得到白色固体。
(2) 三位同学对白色固体提出猜想：A 纯净的 NaOH；B NaOH 与 Ca(OH)₂ 的混合物；C NaOH 与 Na₂CO₃ 的混合物。任选一种猜想设计实验证明。

## 🧭 思路导航（渐进提示）

**题 1**
- **提示 1（识别）**：中和反应后溶质猜想——产物 NaCl 必有，争论的是**反应物是否剩余**。
- **提示 2（突破）**：NaOH 与 HCl **不能共存**（会继续反应）→ 乙的猜想内部矛盾；剩余只有三种可能：恰好中和 / 酸过量 / 碱过量。
- **提示 3（路线）**：(1) 乙不合理（NaOH+HCl=NaCl+H₂O，二者不共存）。(2) 新猜想"NaCl 和 HCl（酸过量）"→ 取样滴加紫色石蕊，变红则含 HCl（或加锌粒看气泡、加 CuO 看溶解）。

**题 2**
- **提示 1（识别）**：复分解制备 + "产物纯度检验"双连题。
- **提示 2（突破）**：Na₂CO₃+Ca(OH)₂→CaCO₃↓+2NaOH；白色固体可能混有**过量的反应物**——检验谁过量就用谁的特征反应，且试剂选择不能引入新干扰（检验 Na₂CO₃ 用足量 CaCl₂ 而非 Ca(OH)₂）。
- **提示 3（路线）**：方程式 → 过滤（固液分离）→ 蒸发（结晶）；验证 B：取样加水溶解，通 CO₂（或滴 Na₂CO₃）看是否浑浊（检出 Ca(OH)₂）；验证 C：滴加足量稀盐酸看气泡（检出 Na₂CO₃）。

## ✍️ 详解

**题 1(1)** **乙同学不合理**。NaOH 与 HCl 能发生中和反应（$NaOH+HCl=NaCl+H_2O$），二者在同一溶液中不能共存；甲"恰好完全反应只含 NaCl"合理。
**(2)** **新猜想：溶液中含 NaCl 和 HCl（盐酸过量）**。
实验设计：取样，滴加几滴紫色石蕊溶液——若变红，证明含 HCl（补充：另取样加锌粒，产生气泡可进一步确证）。

**题 2(1)** $Na_2CO_3+Ca(OH)_2=CaCO_3\downarrow+2NaOH$；**过滤**（分出 CaCO₃ 沉淀）；**蒸发**（结晶析出 NaOH——注意 NaOH 溶液蒸发时要防潮解/防 CO₂，实际操作在蒸发皿中蒸干）。
**(2) 以验证猜想 C（混有 Na₂CO₃）为例**：
- 取白色固体少许溶于水，滴加**足量稀盐酸**；
- 若**产生气泡**，说明含 Na₂CO₃（$Na_2CO_3+2HCl=2NaCl+H_2O+CO_2\uparrow$），猜想 C 成立。
- 规范提示：不能用 Ca(OH)₂ 检验 Na₂CO₃——它本身与 NaOH 不冲突，但若要**同时**检验两种杂质，需"先足量 CaCl₂ 溶液除尽 CO₃²⁻ 并观察沉淀，再取滤液滴酚酞验 OH⁻"（两步接力，同 [[化-26-碱的性质与中和反应]] 题 2 的逻辑）。

## ⚠️ 评分点与易错

- **猜想评价的表述**：不能只答"不合理"，必须写"NaOH 与 HCl 会继续反应（不共存）"——依据句是得分点。
- **共存三分类**：恰好中和（只有盐）/ 酸过量（盐+酸）/ 碱过量（盐+碱）——中和后溶质猜想的标准框架。
- **除杂试剂的选择性**：验 Na₂CO₃ 用 **CaCl₂/BaCl₂**（只沉 CO₃²⁻、不引 OH⁻）；用石灰水会引入 OH⁻，后续酚酞变红无法判断是原有的还是引入的。
- 操作排序：先**过滤**分离沉淀，再**蒸发**结晶——顺序颠倒不得分；方程式 CaCO₃↓ 别漏。
