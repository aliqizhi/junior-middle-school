# 化-30 真题精讲 · 物质的检验与提纯

> **教材对照**：旧教材"化学实验复习单元·物质的检验" → **新教材专题 2 体验化学实验探究** + 专题 8 相关离子检验，见 [[05-化学/学科总览]]。

## 📝 题目

**题 1（不加试剂鉴别）** 不利用其他试剂，鉴别四瓶无标签液体：盐酸、水、硫酸铜溶液和氢氧化钠溶液。设计方案并说明每步结论。

**题 2（离子检验顺序设计）** 某废液可能含有硫酸钠、氯化钠、碳酸钠中的一种或几种。设计实验确定其成分（给出试剂顺序与预测现象）。

## 🧭 思路导航（渐进提示）

**题 1**
- **提示 1（识别）**："不用其他试剂"= 先**物理观察**（颜色），再用**已鉴别出的溶液当试剂**互滴。
- **提示 2（突破）**：四瓶中 **CuSO₄ 溶液呈蓝色**，一眼定一枚棋子；蓝色溶液加入其余三瓶，**出现蓝色沉淀 Cu(OH)₂ 的就是 NaOH**；最后两瓶（盐酸/水）用 NaOH 是否变色 + 盐酸与……——此时还需一个判据区分酸和水。
- **提示 3（路线）**：观察蓝色 → CuSO₄；CuSO₄ 分别滴入另三瓶 → 出蓝色沉淀的是 NaOH；余下两瓶互相滴加或取样加热/挥发闻味——盐酸有**刺激性气味**、水没有（或：分别加到 Cu(OH)₂ 沉淀中，能溶解沉淀的是盐酸）。

**题 2**
- **提示 1（识别）**：三离子检验（CO₃²⁻、SO₄²⁻、Cl⁻）的**顺序设计**题——核心是"先验谁不干扰谁"。
- **提示 2（突破）**：Ag⁺ 会同时沉淀 CO₃²⁻/SO₄²⁻/Cl⁻，所以 **Cl⁻ 必须最后验**；验 SO₄²⁻ 与 CO₃²⁻ 用足量 **Ba(NO₃)₂**（先出气泡的是 CO₃²⁻、后出白色沉淀的是 SO₄²⁻），且用硝酸盐**不引入 Cl⁻**。
- **提示 3（路线）**：①取样滴加足量稀硝酸（验 CO₃²⁻，出气泡）；②再加足量 Ba(NO₃)₂（出白色沉淀验 SO₄²⁻）；③过滤，滤液滴 AgNO₃（白色沉淀验 Cl⁻）。

## ✍️ 详解

**题 1**：
1. **观察颜色**：呈蓝色的为 **CuSO₄ 溶液**。
2. 取 CuSO₄ 溶液分别滴入其余三瓶：产生**蓝色沉淀**的原溶液为 **NaOH**（$CuSO_4+2NaOH=Cu(OH)_2\downarrow+Na_2SO_4$）。
3. 区分盐酸与水（任选其一，规范表述）：
   - 方案 A：取步骤 2 的蓝色沉淀，分别加入两瓶液体——**沉淀溶解、溶液变蓝绿色**的是盐酸（$Cu(OH)_2+2HCl=CuCl_2+2H_2O$），不溶的是水；
   - 方案 B：打开瓶盖扇闻——有**刺激性气味**的是盐酸，无味的是水。

**题 2**（试剂顺序：稀硝酸 → 足量硝酸钡 → 硝酸银）：

| 步骤 | 操作 | 现象 → 结论 |
| ---- | ---- | ---- |
| 1 | 取样，滴加足量稀硝酸 | 有气泡 → 含 **Na₂CO₃**；无气泡 → 不含 |
| 2 | 步骤 1 溶液中滴加足量 Ba(NO₃)₂ 溶液 | 白色沉淀 → 含 **Na₂SO₄**；无现象 → 不含 |
| 3 | 过滤，滤液中滴加 AgNO₃ 溶液 | 白色沉淀 → 含 **NaCl**；无现象 → 不含 |

**依据**：步骤 1 的稀硝酸先排除 CO₃²⁻（否则 CO₃²⁻ 也会与 Ba²⁺ 生成 BaCO₃ 沉淀，干扰 SO₄²⁻ 检验）；步骤 2 用硝酸钡而不用氯化钡，**避免引入 Cl⁻ 干扰步骤 3**；AgNO₃ 检 Cl⁻ 时溶液已呈酸性，排除了其他沉淀干扰。

## ⚠️ 评分点与易错

- **"不加试剂"题的固定起手式**：先看颜色（蓝色=Cu²⁺、浅绿=Fe²⁺、黄色=Fe³⁺），颜色是免费的试剂。
- **互滴定身份**：两组无色溶液可互滴辨（如 NaOH+HCl：酚酞先红后褪 vs 先无后红不可辨，需借助沉淀/气体）。
- **离子检验顺序的铁律**：CO₃²⁻ 最先（酸化排除）、Cl⁻ 最后（Ag⁺ 干扰最大）；中间验 SO₄²⁻ 用 **Ba(NO₃)₂ 稀硝酸酸化**。
- 试剂写"**足量**/过量"：目的写明"将××除尽，排除干扰"——只写试剂名不写目的扣一半分。
- 题 2 原卷答案即此三步表；注意"将混合物过滤后取滤液"这句不能省（不滤掉 BaSO₄ 会遮蔽 AgCl 的观察）。

## ✅ 答案速查

| 题 | 关键答案 |
| ---- | ---- |
| 题 1 | 蓝色→CuSO₄；产蓝色沉淀→NaOH；溶沉淀/刺激性气味→盐酸；余为水 |
| 题 2 | 稀硝酸（气泡→CO₃²⁻）→足量 Ba(NO₃)₂（沉淀→SO₄²⁻）→滤液加 AgNO₃（沉淀→Cl⁻） |
