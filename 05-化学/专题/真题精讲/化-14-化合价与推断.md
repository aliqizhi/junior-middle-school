# 化-14 真题精讲 · 化合价与推断

> **教材对照**：新教材专题 5（物质的微观构成：化合价）＋专题 6（化学变化及其表示）＋专题 8（金属活动性初步），见 [[05-化学/学科总览]]。

## 📝 题目

**题 1（2024·嘉定二模）** 工业上常用 $2C+SiO_2\xrightarrow{\text{高温}}Si+2CO\uparrow$ 制取粗硅，关于该反应叙述正确的是（　）
A．碳元素由化合态转化为游离态　B．该反应属于置换反应　C．该反应在常温下能较快进行　D．参加反应的 C 和 SiO₂ 的质量之比为 2:1

**题 2（徐汇期中）** 根据化学方程式 $MnO_2+4HCl(\text{浓})\xrightarrow{\Delta}X+Cl_2\uparrow+2H_2O$ 可以获取的信息是（　）
A．反应在常温下也可以发生　B．X 的化学式是 MnCl　C．一种元素的化合价发生改变　D．反应生成的各物质质量之比

**题 3（黄浦阶段练习·多选）** 金属 M 与 AgNO₃ 溶液反应：$M+2AgNO_3=M(NO_3)_2+2Ag$。有关说法**错误**的是（　）
A．该反应属于置换反应　B．金属 M 可能是铝　C．M 的金属活动性比 Ag 强　D．M 的金属活动性一定比 Cu 强

**题 4（宝山期末）** 关于硫酸铜晶体说法正确的是（　）
A．俗称：胆矾　B．化学式：CuSO₄　C．颜色：白色　D．式量：178

## 🧭 思路导航（渐进提示）

- **提示 1（识别）**：题 1 考"置换反应定义 + 质量比要按相对原子质量算"；题 2 考"化学方程式能告诉我们什么"；题 3 考"金属活动性 + 化合价定化学式"；题 4 考"结晶水合物常识"。
- **提示 2（突破）**：质量比 ≠ 计量数比（要乘相对原子质量）；反应条件"Δ"写进方程式就是"必须加热"；M(NO₃)₂ 告诉你 M 显 +2 价；晶体 = 无水盐 · 结晶水。
- **提示 3（路线）**：题 1 逐项过：谁是单质谁是化合物 → 置换定义；算质量比 24:60 化简。题 2 用原子守恒推 X → 再逐项判断"哪条信息真能从方程式读出"。题 3 由 M(NO₃)₂ 定 +2 价 → 排除铝；再讨论"M 一定比 Cu 强吗"。题 4 记牢 CuSO₄·5H₂O。

## ✍️ 详解

**题 1**：
- A：反应前碳是**单质**（游离态），反应后变成 CO（化合态）——方向说反，且真正"由化合态转游离态"的是**硅**（SiO₂→Si）。错。
- B：单质（C）+ 化合物（SiO₂）→ 化合物（CO）+ 单质（Si），**是置换反应**。✓
- C：条件是"高温"，常温下几乎不反应。错。
- D：m(C):m(SiO₂) = (2×12):(60) = **24:60 = 2:5**，不是计量数比 2:1。错。
- **答案：B**

**题 2**：先守恒推 X：Mn 左 1 → X 含 1 Mn；Cl 左 4 = X 中 Cl + 2（Cl₂）→ X 含 2 Cl → **X = MnCl₂**（选项 B 写 MnCl，错）。
- A：条件"Δ"表明需加热，常温不反应。错。
- B：MnCl₂ ≠ MnCl。错。
- C：Cl 从 HCl 中的 −1 价变为 Cl₂ 中的 **0 价**——化合价改变。✓
- D：推知 X 后即可算生成物质量比（MnCl₂ : Cl₂ : H₂O = 126 : 71 : 36）——**可以获取**。✓
- **答案：C、D**（若单选卷，优先选 C——化合价改变是最直接的信息；本卷为不定项。此题是"从方程式能读出什么"的好教材，见易错区。）

**题 3**：由 M(NO₃)₂：硝酸根 −1 价 × 2 = −2 → **M 显 +2 价**。
- A：单质 + 化合物 → 化合物 + 单质，置换反应。✓（说法正确）
- B：铝显 +3 价，只能生成 Al(NO₃)₃，**M 不可能是铝**——"可能"说法**错误**。✓选
- C：M 能置换 AgNO₃ 中的 Ag → 活动性 M > Ag。（说法正确）
- D：M > Ag 不能推出 M > Cu——若 M 是 +2 价且排在 Cu、Ag 之间（如汞 Hg：Hg+2AgNO₃ 可反应，但 Cu>Hg），则 M 比 Cu **弱**。"一定比 Cu 强"**错误**。✓选
- **答案：B、D**

**题 4**：硫酸铜晶体 = 五水硫酸铜 CuSO₄·5H₂O。
- A：俗称**胆矾/蓝矾** ✓；B：晶体化学式是 CuSO₄·5H₂O（CuSO₄ 是无水盐）✗；C：**蓝色**（无水 CuSO₄ 才是白色）✗；D：M = 160 + 5×18 = **250**，178 ✗。
- **答案：A**

## ⚠️ 评分点与易错

- **质量比 ≠ 计量数比**：必须乘相对原子质量再化简（题 1D 的 2:1 是命题人挖的坑）。
- **推 X 后代回验原子账**：题 2 若不推 X 就答题，B 选项"MnCl"根本无法判断。
- **化合价与化学式互锁**：M(NO₃)₂ ⇔ M 是 +2 价——"铝"选项就是考这一条（Al³⁺ 只能配三个硝酸根）。
- **"一定"类说法找反例**：M>Ag 时 M 可能落在 Cu、Ag 之间，D 的反例是汞。
- **晶体常识打包记**：胆矾/蓝矾 = CuSO₄·5H₂O = 蓝色 = 式量 250；无水硫酸铜白色（检验水的常用试剂）。
- **多选题标记**：上海卷不定项"漏选得一半分、错选不得分"，没把握时宁少选。
