# 化-12 真题精讲 · 概念辨析与分类

> **教材对照**：物质分类与基础概念 → **新教材专题 1~2、5**；酸碱盐初步 → **新教材专题 8**，见 [[05-化学/学科总览]]。

## 📝 题目

**题 1（概念辨析）** (1) 有关物质分类的说法正确的是（　）
A．只含一种物质的是单质　B．含多种元素的物质是混合物
C．只含一种元素的物质是纯净物　D．含多种元素的纯净物是化合物

(2) 某物质经分析只含碳元素，则对该物质分析正确的是（　）（不定项）
A．一定是纯净物　B．可能是混合物　C．一定是化合物　D．可能是单质

**题 2（概念关系归类）** 化学概念之间具有并列、包含、交叉等关系，M、N 之间的图示关系为"M 包含 N"。下表中符合图示关系的是（　）
选项／M／N：
A．单质／纯净物　B．含氧化合物／氧化物　C．纯净物／混合物　D．纯净物／化合物
（题源答案为 B、D 两项均符合，此处按多解处理）

**题 3（酸碱盐初步）** (1) 关于酸、碱、盐组成的说法一定正确的是（　）（不定项）
A．酸和碱一定含氢元素　B．酸和盐一定含氧元素
C．碱和盐一定含金属元素　D．酸、碱、盐一定都含非金属元素
(2) 关于 Na₂CO₃ 的描述错误的是（　）
A．俗名是纯碱　B．溶于水，滴加酚酞，溶液变红色
C．滴加足量的盐酸，无明显现象　D．滴加适量的石灰水，产生白色沉淀

## 🧭 思路导航（渐进提示）

**题 1**
- **提示 1（识别）**："只含碳元素能推出什么"，考**纯净物／混合物 × 单质／化合物**的四格分类。
- **提示 2（突破）**：反例制胜——金刚石＋石墨（只含碳的混合物）一例即可同时推翻 A 与 C。
- **提示 3（路线）**：先按"物质种类"分纯净物/混合物，再按"元素种类"分单质/化合物，两步走完再对照选项。

**题 2**
- **提示 1（识别）**：Venn 关系题，图示已文字化为"M 包含 N"（N ⊂ M）。
- **提示 2（突破）**：每个选项翻译成一句话——"所有 N 都是 M 吗？"，再反查有没有只是 M 不是 N 的例子（有才叫"包含"而非"等同"）。
- **提示 3（路线）**：并列（同层互斥）、包含（子集）、交叉（部分重叠）三选一，用实例代回验证。

**题 3**
- **提示 1（识别）**：酸碱盐组成"一定"题＋Na₂CO₃ 性质判断，考**反例库**。
- **提示 2（突破）**：反例专业户：HCl（无氧的酸）、NH₄Cl（无金属的盐）、NH₃·H₂O（无金属的碱）、Na₂CO₃（显碱性的盐）。
- **提示 3（路线）**：逐项找反例淘汰；Na₂CO₃＋盐酸按复分解写方程式看现象。

## ✍️ 详解

**题 1**：(1) A 错：只含一种物质的是**纯净物**（单质还须只含一种元素）；B 错：含多种元素的物质可能是化合物（如 KClO₃ 含 K、Cl、O 三种元素却是纯净物）；C 错：O₂ 与 O₃ 混合只含一种元素却是混合物；D 对：纯净物＋多种元素＝化合物 → **选 D**。
(2) 只含碳元素：可能是金刚石（单质），也可能是金刚石与石墨的混合物，但碳元素无法组成化合物（化合物至少两种元素）→ **选 BD**。判断→依据→回扣情境：A"一定纯净物"错在"石墨＋金刚石"这一反例；C"一定是化合物"错在化合物定义本身。

**题 2**：按"M 包含 N"（N ⊂ M）逐项验证：A 单质 ⊂ 纯净物，是 N 包含 M，方向反了，错；B 氧化物（两元素含其一为氧的化合物）是含氧化合物的**子集** → M 包含 N ✓；C 纯净物与混合物**并列**（物质的第一层分类），错；D 化合物 ⊂ 纯净物 ✓ → **B、D 均符合（选 BD）**。
补一组常考关系：氧化反应与化合反应**交叉**（C＋O₂ 点燃既氧化又化合；CH₄＋2O₂ 点燃是氧化不是化合；CaO＋H₂O 是化合不是氧化）。

**题 3**：(1) A 对：酸电离出 H⁺ 必含 H（HCl），碱含 OH⁻ 必含 H（NaOH）；B 错：HCl、NaCl 均不含氧；C 错：NH₃·H₂O 是不含金属的碱，NH₄Cl 是不含金属的盐；D 对：酸含 H（非金属），碱含 O（非金属），盐必含酸根离子团（含非金属）→ **选 AD**。
(2) Na₂CO₃（纯碱/苏打，**盐**不是碱）遇足量稀盐酸会发生复分解：$Na_2CO_3+2HCl=2NaCl+H_2O+CO_2\uparrow$，**明显冒气泡**，C 描述错误 → **选 C**；D 中 $Na_2CO_3+Ca(OH)_2=CaCO_3\downarrow+2NaOH$ 生成白色沉淀，正确。

## ⚠️ 评分点与易错

- 三对概念一张图：**物质 →（物质种类）→ 纯净物/混合物；纯净物 →（元素种类）→ 单质/化合物；化合物 → 氧化物**。判断顺序不可乱。
- "同种元素组成的物质不一定是单质"（O₂＋O₃、红磷＋白磷）——"物质"与"纯净物"一字之差，反例必背。
- Na₂CO₃ 是盐不是碱（纯碱不是碱）；碳酸氢钠 NaHCO₃ 是酸式盐——俗名带"碱"的常是坑。
- 概念关系题常见标准：混合物 ⊃ 溶液（包含）、氧化反应与化合反应（交叉）、化合物 ⊃ 氧化物（包含）。
- 不定项题漏选得部分分、错选不得分（上海卷规则）：拿不准时先保最有把握的一项再权衡。

**概念关系速查（Venn 三型）**

| 关系 | 含义 | 实例 |
| ---- | ---- | ---- |
| 并列 | 同层互斥 | 纯净物／混合物；单质／化合物；酸／碱／盐（化合物内部） |
| 包含 | 子集关系 | 纯净物 ⊃ 化合物 ⊃ 氧化物；混合物 ⊃ 溶液；含氧化合物 ⊃ 氧化物 |
| 交叉 | 部分重叠 | 氧化反应／化合反应；浓溶液／饱和溶液 |
