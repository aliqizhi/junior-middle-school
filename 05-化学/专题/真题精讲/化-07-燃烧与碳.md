# 化-07 真题精讲 · 燃烧与碳

> **教材对照**：旧教材专题 4.1、4.2 → **新教材专题 9**（化学反应的调控）＋专题 3（CO₂ 部分），见 [[05-化学/学科总览]]。

## 📝 题目

**题 1（燃烧与灭火）** (1) 干垃圾焚烧可用于发电，焚烧前一般需粉碎处理。粉碎的目的是（　）
A．降低可燃物的着火点　B．使可燃物分子变小
C．增大与氧气的接触面积　D．减少消耗氧气的质量

(2) 2020 年上海中考真题：盖沙灭火的原理是（　）
A．降低温度　B．取走可燃物　C．隔绝氧气供应　D．降低着火点

(3) 下列几种常用的灭火方法及灭火原理均正确的是（　）
A．油锅着火，用水浇灭，使温度降到可燃物的着火点以下
B．液化气起火，关闭阀门，隔绝空气
C．住宅失火，用高压水枪灭火，降低可燃物着火点
D．森林着火，砍伐出隔离带，移走可燃物

**题 2（碳单质）** (1) 不属于同素异形体的一组物质是（　）
A．红磷与白磷　B．木炭与活性炭　C．氧气与臭氧　D．金刚石与石墨

(2) 对事实的解释错误的是（　）
A．书写档案规定必须使用碳素墨水——常温下碳的化学性质稳定
B．石墨能够做电池的电极材料——石墨能够导电
C．焦炭可以把铁从它的氧化物矿石里还原出来——焦炭具有氧化性
D．制糖工业中用活性炭来脱色以制白糖——活性炭具有吸附性

(3) 关于金刚石和石墨的说法不正确的是（　）
A．金刚石和石墨可以互称为同素异形体
B．1 g 金刚石和 1 g 石墨含有原子数相同
C．金刚石和石墨中原子的排列方式相同
D．常温下金刚石和石墨的化学性质稳定

**题 3（CO₂/CO 转化与鉴别）** 有关 CO₂、CO 的说法正确的是（　）
A．组成：CO₂ 比 CO 多一个氧元素
B．除杂：CO₂ 中混有少量 CO，可以用点燃的方法除去
C．收集：都不可以用排空气法收集
D．鉴别：可以用溶解性、点燃等方法鉴别这两种气体

## 🧭 思路导航（渐进提示）

- **提示 1（识别）**：题 1 的钥匙是"燃烧三条件、灭火三原理**一一对应**"；题 2 的钥匙是"同素异形体＝**同种元素的不同单质**"；题 3 的钥匙是"除杂不增不减、鉴别现象不同"。
- **提示 2（突破）**：着火点是物质的属性**不可降低**，降温只能"降到着火点以下"；碳的还原性（夺氧）与吸附性（物理）分属两个体系。
- **提示 3（路线）**：转化题用"碳三角"：C → CO₂ → CO → CO₂ → CaCO₃，每个箭头配一个方程式；鉴别题逐项查"操作可行、现象可辨"。
- **碳三角方程式自检**：C＋O₂ 点燃 → CO₂；CO₂＋C 高温 → 2CO；2CO＋O₂ 点燃 → 2CO₂；CO＋CuO 加热 → Cu＋CO₂；CO₂＋Ca(OH)₂ → CaCO₃↓＋H₂O。五个箭头都能默写，转化题就有底了。

## ✍️ 详解

**题 1**：(1) 粉碎使燃料颗粒变小、与空气接触面增大，燃烧更充分 → **选 C**；着火点是属性不能降低（A 错），分子大小不因粉碎改变（B 错），耗氧量由燃料量决定（D 错）。
(2) 盖沙覆盖火体，隔绝氧气（空气）→ **选 C**。
(3) A 油锅着火不能用水（油浮水面溅开扩大火势，应用锅盖隔绝空气）；B 关阀门的原理是**移走可燃物**（不是隔绝空气）；C 水枪灭火是降温到着火点以下，"降低着火点"表述错；D 正确 → **选 D**。

**题 2**：(1) 同素异形体须是**单质**：木炭、活性炭的主要成分虽是碳，但都是含杂质的**混合物**，不互为同素异形体 → **选 B**（A、C、D 均为同素异形体）。
(2) 焦炭炼铁体现的是碳的**还原性**（高温下夺氧：$2Fe_2O_3+3C\xrightarrow{\text{高温}}4Fe+3CO_2\uparrow$），不是氧化性 → **选 C**。
(3) C 错：金刚石与石墨物理性质差异巨大的原因正是**碳原子排列方式不同** → **选 C**；同素异形体、等质量等原子数、常温稳定性均正确。

**题 3**：判断→依据→回扣情境：**选 D**。A 错：元素只论种类不论个数，应为"一个 CO₂ 分子比一个 CO 分子多一个氧原子"；B 错：大量 CO₂ 中的少量 CO **点不着**（CO₂ 不支持燃烧），且除杂要求不增不减；C 错：CO₂ 密度比空气大用向上排空气法，CO 密度与空气接近且有毒，一般不用排空气法，但题干说"都不可以"过于绝对（CO₂ 可以）——按选项原意判错；D 对：CO₂ 能溶于水而 CO 难溶、点燃 CO 有淡蓝色火焰而 CO₂ 无现象，现象不同即可鉴别。回扣情境：两种气体组成元素相同但分子构成不同，性质差异由此而来。

## ⚠️ 评分点与易错

- 灭火原理三选一要说**全称**："降低温度至着火点以下"≠"降低着火点"，后者必错。
- 同素异形体判定两步：先看是否都是**单质**，再看是否**同种元素**；O₂/O₃、红磷/白磷、金刚石/石墨/C₆₀ ✓，冰/干冰、CO/CO₂（化合物）✗。
- "碳单质物理性质差异大 → 排列方式不同；化学性质相似 → 都由碳原子构成"，这句话是简答采分点。
- CO₂→CO 用 CO₂ + C（高温），CO→CO₂ 用点燃或还原金属氧化物；书写时条件"高温"与"点燃"不能互换。
- 干冰是固态 CO₂（升华吸热用于人工降雨、制冷），与"冰"（H₂O）毫无关系，命名类陷阱常考。
- CO 有毒（与血红蛋白结合），尾气必须点燃或收集，相关装置题见 [[05-化学/专题/真题精讲/化-09-制气与还原实验]]。
