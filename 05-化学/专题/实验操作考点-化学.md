# 化学实验操作考点（5 月实验考 5 分）

> 实验操作考共 15 分钟，化学部分 5 分。必须拿满。系统整理自 `~/Downloads/00.中考/05.化学/[18039042]制取气体、还原氧化铜实验专项练习`。

## 必考实验一：氧气/二氧化碳的制取

- 检查气密性：连接导管入水，手握试管，有气泡冒出（松手回吸一段水柱）
- 装药品顺序：先固后液；加锌粒/大理石用镊子滑入
- O₂（KMnO₄ 法）：试管口略向下倾斜（防冷凝水倒流炸裂）、棉花、先撤导管后熄灯（防倒吸）
- CO₂：向上排空气法、验满（燃着木条瓶口）

## 必考实验二：氢气/一氧化碳还原氧化铜

- 装置顺序：制气 → 净化/干燥 → 还原 → 检验产物 → 尾气处理（CO 有毒必须点燃或收集）
- **操作口诀（H₂/CO 还原 CuO）：氢气早出晚归，酒精灯迟到早退**
  1. 先通气体排尽装置内空气（防爆炸）
  2. 再点燃酒精灯加热
  3. 反应完先熄灯，继续通气至冷却（防铜再被氧化）
- 现象：黑色粉末逐渐变红（CuO→Cu），管口有水珠（H₂ 还原）/ 石灰水变浑浊（CO 还原）
- 结论表达："氧化铜失去氧被还原，氢气得到氧被氧化，氢气具有还原性"

## 必考实验三：粗盐提纯（过滤+蒸发）

- 一贴二低三靠；玻璃棒三次作用（引流、搅拌、转移）
- 蒸发：出现较多晶体停止加热

## 高频操作细节（扣分点）

| 操作 | 规范 |
| ---- | ---- |
| 取用粉末 | 药匙/纸槽，试管倾斜送到底部 |
| 倾倒液体 | 瓶塞倒放、标签朝手心、口挨口 |
| 闻气体 | 扇闻 |
| 加热液体 | 不超过试管容积 1/3，外焰，管口不对人 |
| 熄灭酒精灯 | 灯帽盖灭（禁止嘴吹） |
| 量筒读数 | 平视凹液面最低处 |
