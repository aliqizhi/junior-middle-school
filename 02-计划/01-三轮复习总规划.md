# 三轮复习总规划（2026.10 → 2027.6）

> 节奏对齐学校：12 月底校内大考是第一站。每阶段结束做一次"知识库健康检查"：掌握度更新 + 错题清零率。

## 第一轮 · 基础巩固 + 新课同步（现在 → 12 月底）

**目标：基础题零失误，把"会做"变成"拿满分"。**

- 数学：九年级新课（相似、三角比、二次函数、圆）当天笔记；同步回刷六~八年级公式总表（[[03-数学/知识点/00-六至八年级核心公式定理总表]]）；每周 2 套一模卷，只要求 1-22 题全对 + 23-25 题拿步骤分
- 物理：新课（九年级上册收尾）+ 力学三重点（密度、压强、浮力）系统过一遍；电学跟着新课同步建笔记
- 化学：一模范围（八年级全一册 + 九年级 88 页前）专题梳理；**每周固定：综合卷 1 套 + 专题复习 1 次 + 方程式默写 1 次**
- 语文/英语：古诗文滚动默写（正确率 ≥95%，家默抽背签字）；英语考纲词汇过一遍
- 12 月考前两周：错题本大清查，所有"待复习"错题变式重做

## 第二轮 · 一模 + 专题突破（12 月底 → 2027.2）

**目标：中档题稳定拿分，压轴题形成固定解题套路。**

- 数学：第 21-25 题逐题号专题（[[03-数学/专题/中考题型地图]]），每个题型总结"识别特征→方法→易错"
- 物理：**电学四大题型专项**（电路动态/电路故障/电学计算/方法策略）+ 浮力压轴专项
- 化学：说理题专项（情景描述、原因解释类）；酸碱盐（专题 8）等重点章节
- 跨学科案例：15 分专项（生物+地理核心概念 + 真题题型）
- 寒假：错题全部重做一遍 + 2025/2026 各区一模卷精选

## 第三轮 · 二模 + 真题实战（2027.3 → 6 月）

**目标：考试节奏、时间分配、书写规范全部定型。**

- 二模卷全真限时训练（120 分钟掐表），训练"大题时间分配 = 分值 + 2 分钟"（道法老师方法，通用）
- 5 月：理化实验操作考（每周过一遍实验考点）+ 外语听说
- 最后三周：只做真题 + 错题 + 滚动默写，**不做新难题**；作息调到考试节奏

## 每周固定节奏（贯穿三轮）

| 时间 | 任务 |
| ---- | ---- |
| 周一~五 每天晚 | 当天新课 → 知识点笔记补全（15 分钟）+ 当天错题入卡（10 分钟） |
| 周一~五 任意 | 闪卡/默写滚动（10 分钟 × 3 天） |
| 周六 | 本周错题集中订正 + 变式重做 + 数学一模卷 2 套 |
| 周日 | 周复盘（错因统计 → 定下周主线）+ 下周计划 + 更新倒计时 |

## 各科"绝不丢的分"清单（每天扫一眼）

- [ ] 数学 1-16 题（选择+基础填空）全对
- [ ] 化学方程式默写 100%
- [ ] 物理实验步骤书写完整（设列算验答）
- [ ] 语文古诗文默写 95%+
- [ ] 英语听力保底
- [ ] 跨学科案例 15 分拿到 12+
- [ ] 理化实验操作 15 分拿满
