# 家长协作指南

> 依据 2026.10 家长会各科纪要整理。家长的角色不是"第二个老师"，而是三件事：**营造环境、监督机制、正向反馈**。

## 每周固定配合清单

| 频次 | 做什么 | 出处 |
| ---- | ---- | ---- |
| 每天 | 提供安静整洁的学习环境，保障规律作息与健康饮食 | 化学纪要 |
| 每天 | 电子产品管控：先独立完成作业，再核对答案，**杜绝依赖 AI/搜题工具直接抄** | 语文纪要 |
| 每周 | **语文家默：抽背古诗文并签字**，目标正确率 95%+ | 语文纪要 |
| 每周 | **化学：监督方程式默写 + 综合卷完成**（学校每周三项任务） | 化学纪要 |
| 每周 | 让孩子当"小老师"，挑 1 道错题讲给你听（讲得出 = 真懂） | 化学纪要 |
| 周日 | 看一眼周计划的错因统计和下周主线，给一句具体的肯定 | 全科 |

## 三条红线（老师明确要求）

1. **不协助递送外卖/零食/电子产品进校**（学校违禁规定，家长配合属违规）。
2. **不盲目加量刷题**，尤其外区/外地模拟题——"控制额外刷题量，回归中考真题为主的学习路径，听从教师建议"。
3. **不以分数否定孩子**——避免孩子产生自我放弃心理；关注学习动机而非只盯分数。

## 怎么看这套知识库

- 每周日花 5 分钟看 `02-计划/周计划/` 最新一周的"错因统计"：**如果"方法不会"占比高 → 回知识点补漏；如果"计算错误"占比高 → 限时训练**。这个判断比看总分有用。
- 考试后（月考/期中/一模）：把试卷拍下来/扫描，错题逐张录入错题卡（可让 ZCode 批量辅助），同时更新知识点掌握度。
- 12 月底校内大考是本届最重要的定位参考，考前两周家里配合：只滚动错题和默写，不加新任务。

## 可选的加分动作

- 化学：家庭小实验（小苏打+白醋等），激发兴趣（化学纪要建议）。
- 英语：家里英文视频/阅读优先选知识类内容（科普、vlog），拓宽知识面应对多模态阅读。
- 全科：保留孩子所有作文电子稿、按主题归档（语文老师要求，家长协助保管）。
