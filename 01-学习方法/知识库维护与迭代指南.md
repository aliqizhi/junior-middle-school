# 知识库维护与迭代指南（家长/维护者版）

> 这套库是"活"的：随学习进度、考试结果、新资料持续演进。本页写清楚**谁在什么时候更新什么**，以及**怎么让 ZCode 增量维护**。

## 更新节奏与责任人

| 时机 | 更新什么 | 谁做 |
| ---- | ---- | ---- |
| 每天 | 女儿：当天知识点笔记 + 错题卡 | 女儿 |
| 每周日 | 周复盘：错因统计、下周主线、掌握度更新 | 女儿（家长看一眼） |
| 每次考试后 | 试卷错题批量录入、掌握度全校更新 | 家长发起，ZCode 辅助 |
| 每次家长会后 | 新纪要放入 `91-家长会纪要/`，同步更新：学科总览的"老师策略"、三轮规划 | 家长发起，ZCode 辅助 |
| 每月 | 51jiaoxi 下载 30 份资料 → 更新 `90-资料库` 索引 → 补对应章节 | 家长（点选），ZCode（下载与整合） |

## ZCode 增量更新指令模板（直接复制使用）

- 补章节笔记：
  > 在知识库里补充「数学/九年级/相似三角形」下缺的知识点笔记，对照 `90-资料库/资料清单索引.md` 里的对应资料，风格按 `_templates/模板-知识点笔记.md`。
- 考后录入：
  > 这是本次月考的试卷照片/文字，帮我把错题逐张建成错题卡（错因我来口述，你来整理），并更新对应知识点的掌握度。
- 纪要更新：
  > `91-家长会纪要/` 里有新纪要，提取老师新要求，更新各科"学科总览"和复习规划里受影响的部分。
- 出变式题：
  > 给错题卡「XX-XX」出 3 道同类变式题（附答案），难度梯度：基础/标准/综合，风格对齐上海中考。

## 每月 30 张下载券使用流程

1. 打开 [[99-归档/待补充清单]]，按优先级取最上面的缺口。
2. 在 51jiaoxi 检索（关键词带"沪教版（五四制）"或"上海"），挑 **知识点总结/一模二模汇编/教材电子版** 三类为主。
3. 下载后放入 `~/Downloads/00.中考/对应学科/`，并在 `90-资料库/资料清单索引.md` 登记。
4. 让 ZCode 把新资料中有价值的内容整合进对应章节笔记（原件不入 git）。

## 版本管理约定

- 每个学科里程碑、每次批量更新后 `git commit + push`（GitHub 私有仓库即异地备份）。
- 大文件（PDF/PPTX/ZIP）永不进库（.gitignore 已拦截）；扫描件放 `~/Downloads/00.中考/` 并在索引中登记路径。
- 学期结束后把过期周计划移入 `99-归档/`。

## 内容质量基准（防止"看着很全但不对版"）

- 章节划分必须与学校所用教材一致（数学=沪教版五四制目录；化学=2024 新教材沪科技版专题；物理=沪教版章节）。
- 分值/题型以市教委文件 + 本地 2026 真题核对，不确定的标注"待核对"。
- 每条知识点尽量挂来源（教材章节/哪份资料/老师纪要），便于追溯。
