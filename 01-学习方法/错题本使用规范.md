# 错题本使用规范

> 老师纪要原话：化学——"**主要的就是错题再练习！**"；历史——"注重错题，错题改正多练习更关键"；物理——"作业复盘最重要，要她自己捋思路"。错题闭环是这套系统的核心机制。

## 一、五类错因（每道错题必须归因）

| 错因 | 典型表现 | 对策 |
| ---- | ---- | ---- |
| **概念不清** | 定义/条件记错、公式用错场合 | 回到知识点笔记，补"成立条件"一栏，闪卡加入 |
| **审题失误** | 看漏条件、答非所问、单位没看 | 在错题卡上写下"下次审题先圈什么"（圈关键词清单） |
| **计算错误** | 移项变号、去分母漏乘、开方丢负 | 限时口算训练 + 记下具体算错的那一步 |
| **方法不会** | 完全没思路 / 思路中断 | **回到知识点笔记补方法模板**；变式 3 道必做 |
| **表达不规范** | 步骤跳步、没写依据、答案没答 | 照"规范解答"重写一遍，物理按"设列算验答" |

> 语文老师的观察可迁移到全科：优秀学生的订正是"结构化、多角度反思并标注知识点"的。

## 二、一题五步（每张错题卡）

1. **原题**：抄题干必要部分，图必须画。
2. **错解**：原样保留，不擦不改。
3. **错因**：五选一 + 一句话展开（"表面原因/根本原因"）。
4. **正确思路**：**自己捋**，禁止抄答案；写不出来 = 概念不清，先回笔记。
5. **变式 3 道**：周六统一补——同型 1 道 + 换条件 1 道 + 综合 1 道。来源优先：《举一反三》系列 → 各区一模二模汇编 → 2026 真题。

## 三、复习排期（1-3-7-15-30 天）

- 错题卡建好当天，排期字段填上 5 个日期（今天 +1/3/7/15/30 天）。
- 到期重做**只看题干**，独立完成：
  - 一次做对 → 该期打勾；30 天期做对后标记"已消灭"🏆
  - 做错 → 状态改"反复错"，易错指数升一档，重新排期，且必须重做 3 道变式
- 装了 Spaced Repetition 插件后，到期卡自动出现在复习队列；没装插件就每天搜 `状态: 待复习`。

## 四、老师强调的三个"错题相关动作"

1. **化学**：每周综合卷的说理题，订正时单独分析"失分原因"（是没答到点，还是没逻辑链）。
2. **物理**：大题错题必须"写清楚步骤 → 验证 → 最后定答案"，步骤闭环重写。
3. **语文**：错题订正按"多角度结构化"进行，并补充对应知识点（此规范全科适用）。

## 五、什么不用进错题本

- 纯笔误且该知识点已熟练（掌握度=3）：在周计划记一笔即可。
- 难度远超中考的竞赛题/外地偏题：不进（老师反对刷外地题，时间留给真题）。
