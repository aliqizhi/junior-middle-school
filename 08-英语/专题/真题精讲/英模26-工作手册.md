# 英模26 工作手册（批次作业规范）

> 本手册是英模26 精讲批次（代理或人工）的**唯一作业标准**。格式范本：`英模26-宝山-上.md` / `英模26-宝山-下.md`，动笔前先完整读这两篇。

## 一、输入资产（每区相同结构）

| 资产 | 路径 | 说明 |
| ---- | ---- | ---- |
| 页图-试卷 | `/tmp/en_ym26_pages/{区}/juan-*.png` | 150dpi，8–10 页 |
| 页图-答案 | `/tmp/en_ym26_pages/{区}/da-*.png` | 手写批注版或印刷版 |
| 页图-合一 | `/tmp/en_ym26_pages/{金山|崇明|青浦}/all-*.png` | 试卷+答案合一 PDF（金山/崇明/青浦专用） |
| 文字层 | `/tmp/en_ym26_text/{区}-试卷.txt` | **仅宝山/黄浦有**，其余区纯扫描 |
| 听力音频 | 仅 8 区有（原件在归档区 mp3） | 一般无需处理音频 |

页图如被 /tmp 清理，可随时用 `pdftoppm -png -r 150 <pdf> <前缀>` 重生成（PDF 在 `~/Downloads/00.中考/03.英语/01.一模2026/{区}/`）。

## 二、产出要求

- **文件**：`08-英语/专题/真题精讲/英模26-{区}-上.md`（听力+语法词汇，题 1–43）与 `英模26-{区}-下.md`（词形/句型转换+阅读+作文，题 44–84）。
- **frontmatter 与标题**：完全照抄宝山篇的字段结构，替换区名/题号/题源。
- **题干**：逐题录入（校正 OCR 错词后），选项 A)-D) 齐全；阅读语篇**不必全文照录**——首字母/完形需录空格所在句群，选择/问答录题干与选项，另用 1–2 句概括文章脉络。
- **解析**：每题"**答案** + 一句规则/定位依据"，风格对齐宝山篇（不写废话）。
- **作文**：审题三步 + 参考范文（≥90 词）+ 评分要点。

## 三、答案处理（诚实第一）

1. 答案以卷面答案版为准：**手写批注版**逐字辨认、**印刷版**直接誊录；辨认不确定处一律 `⚠️ 待核对：…` 标注，禁止臆测后装作确定。
2. 听力（1–20）多数区**无答案无音频**：只给图/选项/方法，明确写"批注版未作答、本区无音频"；如答案版含听力答案（如杨浦听力答案图）则照录。
3. 印刷答案与语言规则冲突时，以卷面为准并加 ⚠️ 说明疑点。
4. 文末加一行斜体数据来源说明（照宝山篇改区名）。

## 四、配图工作流

1. 需要裁的图：听力 A 六图块（`q1-5.png`）、阅读海报/图表、C/D 篇插图、作文海报。**纯文字区不硬裁**。
2. 用 PIL 按比例裁：坐标 = 预览图估算的分数 × 实际尺寸（页面 1241×1754）。脚本放 `/tmp/en_ym26_tools/crop_{区}.py`，输出 `08-英语/专题/真题精讲/figs/英模26-{区}/q{题号}.png`。
3. **每张裁片必须 Read 核验**（内容完整、不带邻近题、不缺边），偏了调整分数重裁，最多迭代 2 次，仍不满意就用最接近版本并在 md 中注明"裁片略偏"。
4. 裁图从**无手写批注的卷面页**取（juan-*）；作文海报等若批注版更清晰可用批注版。

## 五、边界

- 只新建 `英模26-{区}-上/下.md` 与 `figs/英模26-{区}/`，**不改** 00-英模26总览、学科总览及其他区文件（总览由主会话统一更新）。
- 不改 91-题库、不碰归档区原件。
- 完成后汇报：区名、两文件路径、裁图数、⚠️ 标注清单、辨认存疑点。
