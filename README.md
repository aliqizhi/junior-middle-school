# junior-middle-school · 上海中考学习知识库

为上海初三学生（2027 届中考）构建的 Obsidian 结构化学习知识库：知识点、专题方法、错题闭环、间隔重复、备考计划一体化。

- 教材版本：沪教版（五四制）数学 / 沪教版物理 / 沪科技版（2024 新教材）化学 / 沪教版生命科学
- 考试基准：上海市初中学业水平考试（总分 750），时间线与分值见 [[02-计划/00-中考全景与时间线]]
- 使用入口：Obsidian 中打开本目录为仓库（vault），从 [[00-首页]] 开始

## 基本约定

1. **原件不进库**：PDF/PPTX/ZIP 等大文件统一留在 `~/Downloads/00.中考/`，`90-资料库` 只放索引和少量精选文本；`.gitignore` 已配置拦截大文件。
2. **笔记粒度**：先按"章/专题"组织，随使用逐步原子化；知识点笔记带 frontmatter（考频/掌握度/易错指数），供看板聚合。
3. **迭代方式**：见 `01-学习方法/知识库维护与迭代指南.md`（新纪要、新试卷、掌握度更新 → 增量更新对应章节）。
