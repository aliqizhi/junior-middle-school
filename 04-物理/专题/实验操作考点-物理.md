# 物理实验操作考点（5 月实验考 10 分）

> 实验操作考"合格制、按分值计入"，共 15 分钟一场。**这是必须拿满的 15 分里的物理部分（10 分）**。系统整理自 `~/Downloads/00.中考/04.物理/2026年上海中考物理实验操作知识点整理.docx`（待全文提炼补充）。

## 八大核心实验（笔试+操作双覆盖）

| 实验 | 核心考点 | 高频扣分点 |
| ---- | ---- | ---- |
| 用刻度尺测长度 | 估读一位、视线正对 | 忘估读 |
| 用天平测质量 | 左物右码、游码归零、镊子取码 | 用手拿砝码 |
| 测量密度（量筒+天平） | 先测质量再测体积、排水法读数视线平视 | 先放水里再称（沾水偏大） |
| 弹簧测力计测力 | 调零、竖直方向读数 | 斜拉读数 |
| 凸透镜成像规律 | 共轴调节、光屏找最清晰像 | 未找"最亮最小"点就读数 |
| 伏安法测电阻 | 滑变最大阻值处开关闭合、多次测量取平均 | 闭合开关前滑片不在最大阻值位 |
| 测小灯泡功率 | 额定电压下调亮、P=UI | 用平均功率（错） |
| 探究浮力（称重法） | 浸没前后各读数一次 | 物体触壁/触底 |

## 操作考通用规范

1. **先调零**再使用（天平/测力计/电流表电压表机械调零）
2. 连接电路时**开关断开**、滑变在**最大阻值**
3. 电流表串联、电压表并联、正负接线柱不接反
4. 读数：先看量程与分度值，视线正对刻度
5. 实验结束：整理器材归位

## 复习节奏

- 4 月起每周过 2 个实验（看学校实验室练习安排）
- 5 月考前一周：每天口述一遍全流程（对着清单说操作步骤）
