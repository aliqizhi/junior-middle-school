# 物-09 真题精讲 · 能源信息与电磁

> 本讲选 3 道选择题，分别取自"能源、材料与社会""走进信息时代""电能从哪里来"三份一轮训练，覆盖能源分类、电磁波应用、电磁感应与磁场对电流的作用三大识记+辨析考点。题 3 的四个选项实验已用文字完整描述，无需看图。

## 📝 题目

### 题1（原卷单选第 2 题，能源卷）新能源分类

下列各组能源中，都属于新能源的是（　　）

A. 电能、水能、风能
B. 太阳能、地热能、核能
C. 液化气、沼气、酒精
D. 石油、天然气、煤

### 题2（原卷单选第 1 题，信息卷）电磁波应用

下列关于电磁波的说法正确的是（　　）

A. 电磁波在空气中的传播速度是 $340\ \text{m/s}$
B. 北斗卫星导航系统通过电磁波提供定位服务
C. 电磁波只能传递声音信号，不能传递图像信号
D. 光缆通信中光在光纤中一直沿直线传播

### 题3（原卷单选第 3 题，电能卷）动圈式话筒的原理

唱卡拉 OK 时的动圈式话筒：对着话筒唱歌时，声音使处于磁场中的线圈振动，从而线圈中产生随声音变化的电流。下列实验能说明动圈式话筒工作原理的是（　　）

A. 闭合电路的一部分导体在磁场中做切割磁感线运动，电路中接有灵敏电流计（无电源）
B. 通电导体放在磁场中，电路中接有电源
C. 奥斯特实验：通电直导线平行放置于静止的小磁针上方
D. 两块磁铁的同名磁极相互靠近

## 🧭 思路导航（渐进提示）

### 题1
- **提示 1（识别）**：能源三套分类——一次/二次、可再生/不可再生、常规/新能源；本题考第三套。
- **提示 2（突破）**：新能源 = 太阳能、风能、地热能、核能、潮汐能、生物质能等**新近开发利用**的能源；化石能源与电能是"常规/二次"。
- **提示 3（路线）**：逐组排查——只要组内混入一个常规能源即淘汰。

### 题2
- **提示 1（识别）**：电磁波概念的"数字 + 应用"正误判断，$3\times10^{8}\ \text{m/s}$ 与 $340\ \text{m/s}$ 的对比是第一陷阱。
- **提示 2（突破）**：电磁波可在真空中传播、可传声也可传像；光纤传光是利用光在内壁**多次反射**曲折前进。
- **提示 3（路线）**：逐项核对"速度 / 应用 / 传什么 / 怎么传"。

### 题3
- **提示 1（识别）**：题干关键句"线圈振动 → 产生电流"= 机械能转化为电能 = **电磁感应**（磁生电），与发电机同原理。
- **提示 2（突破）**：辨析三兄弟看电路——**无电源有电流表**（磁生电：发电机、动圈式话筒）；**有电源**（电生动：电动机、扬声器）；**导线+小磁针**（电流的磁效应：奥斯特、电磁铁）。
- **提示 3（路线）**：给题干定性 → 逐项给四个实验贴标签 → 选同原理者。

## ✍️ 详解

### 题1（逐项排除）

- **A**：电能是**二次能源**（由其他能源转化而来），水能属于常规能源——混入非新能源。✗
- **B**：太阳能、地热能、核能都是新近大规模开发的**新能源**。✓
- **C**：液化气来自石油（化石能源），沼气、酒精虽属生物质能，但整组不齐。✗
- **D**：石油、天然气、煤是典型的**化石能源（常规能源）**，且不可再生。✗

**答案：$\boxed{\text{B}}$**

**辨析速记**："新能源"≠"可再生"——核能是新能源，但核燃料矿产短期内无法补充，属**不可再生**能源。

### 题2（逐项排除）

- **A**：$340\ \text{m/s}$ 是**声**在空气中的速度；电磁波在空气中的速度约为 $3\times10^{8}\ \text{m/s}$。✗
- **B**：卫星与地面之间是真空，只能靠电磁波传递信息，北斗定位正是电磁波的应用。✓
- **C**：电磁波既能传递声音信号，也能传递图像、数据等各种信号。✗
- **D**：光纤通信中，光从光纤一端射入，在内壁**多次反射（全反射）**曲折前进，并非一直沿直线传播。✗

**答案：$\boxed{\text{B}}$**

### 题3（逐项排除）

先定性：话筒"振动 → 产生随声音变化的电流"，是把机械能转化为电能，属**电磁感应（磁生电）**现象。

- **A**：无电源、靠切割磁感线产生感应电流——电磁感应实验，与发电机、动圈式话筒同原理。✓
- **B**：有电源、通电导体在磁场中受力——电动机原理（电能→机械能），是"电生动"，与话筒相反。✗
- **C**：奥斯特实验说明通电导线周围存在磁场——电流的磁效应（电生磁）。✗
- **D**：同名磁极相互排斥——磁极间的相互作用，与电磁感应无关。✗

**答案：$\boxed{\text{A}}$**

| 装置 | 原理 | 能量转化 | 电路特征 |
| ---- | ---- | ---- | ---- |
| 发电机、动圈式话筒 | 电磁感应 | 机械能→电能 | 无电源、有电流表 |
| 电动机、扬声器/听筒 | 磁场对电流的作用 | 电能→机械能 | 有电源 |
| 电磁铁、奥斯特实验 | 电流的磁效应 | 电能→磁场能 | 通电导线 + 小磁针/铁屑 |

## ⚠️ 评分点与易错

- **"新能源"与"可再生"是两套标准**：核能（新能源、不可再生）、水能（常规、可再生）——分类题先确认考的是哪套标准。
- **两组速度数字**：$3\times10^{8}\ \text{m/s}$（电磁波/光）与 $340\ \text{m/s}$（声），填空、判断最爱混。
- **光纤不是"直线"**：光在光纤内壁多次反射曲折前进，"一直沿直线传播"必错；"多次反射传递信息"才是标准表述。
- **发电机 / 电动机一眼判**：看电路里**有无电源**——有电源是"电生动"（电动机），无电源有电流表是"磁生电"（发电机、话筒）。
- **话筒 vs 扬声器是反的**：动圈式话筒"磁生电"，扬声器（喇叭）、耳机听筒"电生动"，两者原理互逆，选项常成对出现设坑。
