# 电学四大题型（老师钦定的突破方向）

> 老师纪要原文："电学学习的四个重点方向：电路动态分析、电路故障判断、电学计算以及方法策略总结。**即使成绩较好的学生也可能在这部分内容上存在薄弱环节**。"

## 题型一：电路动态分析

**触发动作**：滑片移动、开关通断、换电表位置。

**固定流程**：
1. 判断电路连接（电流表当导线、电压表当断路，画等效图）
2. 判断哪个量变：滑片动 → R变 → 若串联：R总变 → I = U/R总 变 → 各处电压用 U=IR 或串联分压判断
3. 串联：电阻大分压多；并联：各支路独立互不影响
4. 表格化答案：每个表（电流表/电压表）读数"变大/变小/不变"逐个判

**口诀**：先定连接，再看变阻，最后用欧姆+分压分流。

## 题型二：电路故障判断

**仅两种故障**：断路（开路）和短路。

| 现象 | 结论 |
| ---- | ---- |
| 串联：一灯灭一灯亮 | 灭的那个**短路** |
| 串联：两灯都灭，电流表无示数 | **断路**（用电压表找：并在某灯两端有示数→该灯断路） |
| 电压表示数 ≈ 电源电压 | 与电压表并联的那段**断路**（或被测灯短路以外的灯短路） |
| 电流表有示数、电压表无示数 | 被测元件**短路** |

**答题句式**："电压表并联在 L1 两端无示数，并联在 L2 两端有示数且接近电源电压，故 L2 断路。"

## 题型三：电学计算（大题规范）

1. 识别电路状态（开关通断前后可能两种电路）
2. 能用的公式：$I=\dfrac UR$、$P=UI=I^2R=\dfrac{U^2}{R}$、$W=Pt$
3. 串联分压 $\dfrac{U_1}{U_2}=\dfrac{R_1}{R_2}$、并联分流 $\dfrac{I_1}{I_2}=\dfrac{R_2}{R_1}$
4. **范围/最值**：电流表、电压表量程限制 → 求滑动变阻器接入范围（高频压轴小问）
   - 先算允许的最大电流 → 定变阻器最小值；再算电压表满量程 → 定最大值

## 题型四：方法策略（实验与数据处理）

- **伏安法测电阻**：多次测量取平均（减小偶然误差）；变阻器规格选择：从分压范围倒推（2026 真题第 10 题）
- **测小灯泡电功率**：额定电压下读数；P额=U额I额；灯丝电阻随温度变化→不能取平均
- **图像法**：U-I 图像斜率含义（定值电阻斜率=R）
- 控制变量法、转换法（电流表/小灯泡亮度显示电流大小）等研究方法表述

## 🔥 易错点

- 动态分析写"变大"时要想清楚自变量是谁
- 故障判断只答"断路/短路"不指明元件 = 不得分
- 变阻器范围题：两个量程限制都要列不等式
- "额定功率"与"实际功率"符号区分书写
