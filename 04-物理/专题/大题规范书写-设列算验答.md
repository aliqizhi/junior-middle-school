# 物理大题规范书写：设 → 列 → 算 → 验 → 答

> 老师纪要原话："中考要求题目步骤严谨完整，**逻辑闭环，不是会写答案就可以**，包括计算……现在步骤分很严格，要写清楚步骤要验证，最后定答案，跟数学大题一样。"

## 五步模板（每个计算大题都这样写）

1. **设**：明确研究对象和物理量。`设物体所受浮力为 F浮`
2. **列**：写原始公式（不是变形式）。`根据阿基米德原理：F浮 = ρ液gV排`
3. **算**：代入数据（带单位）。`F浮 = 1.0×10³ kg/m³ × 9.8 N/kg × 2×10⁻⁴ m³ = 1.96 N`
4. **验**：数量级/单位/合理性。`浮力小于重力，物体会下沉，与题意相符`
5. **答**：完整答句。`答：金属块所受浮力为 1.96 N。`

## 扣分点自查清单

- [ ] 每个公式第一次出现写的是**原始公式**
- [ ] 代入的数据都带单位，且单位统一
- [ ] 计算分步写，结果有"="和单位
- [ ] g 取值与题干一致（9.8 或 10，写明）
- [ ] 涉及图像/表格的数据注明来源（"由表 2 第 3 列"）
- [ ] 最后有答句
- [ ] 说理题：判断 + **物理依据** + 结论三段齐全（例："因为流速大处压强小，机翼上方压强小于下方，故产生向上的升力"）

## 说理题三段式（化学说理题同理）

1. **判断**（是什么）："水面会下降。"
2. **依据**（为什么）：引用物理规律原文
3. **结论**（所以）：回到题目情境收尾

## 训练方式（周计划固定任务）

- 每周 1-2 道大题**只练书写**：做完对着上面清单逐项打勾
- 把最近一次考试的大题拍照存进错题卡，标出丢的"步骤分"
