# 物理 · 公式与常数速记（闪卡）

> 每天 5 分钟。遮住答案自测。

## 基本公式

// 速度、重力公式 #card
?
$v=\dfrac{s}{t}$；$G=mg$（g = 9.8 N/kg，上海卷常取 9.8）

// 压强两个公式及适用对象 #card
?
固体：$p=\dfrac{F}{S}$；液体：$p=\rho gh$；均匀柱体两者通用（$p=\rho gh$）

// 密度公式与单位换算 #card
?
$\rho=\dfrac{m}{V}$；1 g/cm³ = 1.0×10³ kg/m³；ρ水 = 1.0×10³ kg/m³

// 功、功率公式 #card
?
$W=Fs$；$P=\dfrac{W}{t}=Fv$；1 kW = 1000 W

// 杠杆平衡条件 #card
?
$F_1L_1=F_2L_2$（力臂：支点到力作用线的垂直距离）

// 欧姆定律 + 串联电路规律 #card
?
$I=\dfrac{U}{R}$；串联：I 相同，U=U₁+U₂，R=R₁+R₂，$\dfrac{U_1}{U_2}=\dfrac{R_1}{R_2}$

// 并联电路规律 #card
?
U 相同，I=I₁+I₂，$\dfrac{1}{R}=\dfrac{1}{R_1}+\dfrac{1}{R_2}$，$\dfrac{I_1}{I_2}=\dfrac{R_2}{R_1}$

// 电功率四个公式 #card
?
$P=UI=I^2R=\dfrac{U^2}{R}=\dfrac{W}{t}$

// 焦耳定律 #card
?
$Q=I^2Rt$

// 比热容与热量计算 #card
?
$Q=cm\Delta t$；c水 = 4.2×10³ J/(kg·℃)

// 阿基米德原理 #card
?
$F_浮=\rho_液 g V_排$（V排 是排开液体体积，浸没时 = V物）

// 称重法浮力与物体密度 #card
?
$F_浮=G-F_示$；$\rho_物=\dfrac{G}{G-F_示}\rho_水$

// 热值与燃料放热 #card
?
$Q=mq$

// 滑轮组拉力公式（不计摩擦） #card
?
$F=\dfrac{G+G_动}{n}$，s=nh（n 为承重绳段数）

## 关键常数与数据

// 光速、声速（15℃空气） #card
?
c = 3×10⁸ m/s；v声 = 340 m/s

// 家用电压、安全原则 #card
?
火线-零线 220 V；不接触低压带电体、不靠近高压带电体

// 1 kW·h 等于多少焦耳 #card
?
3.6×10⁶ J

// 凸透镜成缩小实像、放大实像、放大虚像的条件 #card
?
u>2f 缩小实像（照相机）；f<u<2f 放大实像（投影仪）；u<f 放大虚像（放大镜）

// 浸没后继续下压，浮力怎么变？ #card
?
不变（V排 不变）

// 串联电路中一灯灭一灯亮，故障是什么？ #card
?
灭的那盏灯短路
