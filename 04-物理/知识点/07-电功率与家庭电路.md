# 电功率与家庭电路 ★大题必考

> 📖 本文是概要版（考前速查）；第一次学或没学懂 → 详细版：[[04-物理/知识点详解/07-电功率与家庭电路]]

> 2026 真题"电熨斗"题块（10 分）：铭牌读数、电能计算、U-I 图象求电阻、双电阻丝组合——这页就是它的知识底座。

## 📌 电功与电功率

- 电功（电能）：$W=UIt$；单位 J、**kW·h**（1 kW·h = 3.6×10⁶ J）
- 电功率：$P=\dfrac{W}{t}=UI$
- 纯电阻电路四件套：$P=UI=I^2R=\dfrac{U^2}{R}$；$W=UIt=I^2Rt=\dfrac{U^2}{R}t$
- **额定 vs 实际**：额定电压/功率是铭牌值；实际功率随实际电压变（$P_{实}=P_{额}\cdot(\dfrac{U_{实}}{U_{额}})^2$）
- 电能表：参数"3000 r/kW·h"→ 转盘转 n 圈耗电 $W=\dfrac{n}{3000}$ kW·h

## 📌 焦耳定律

- $Q=I^2Rt$（通用式）；纯电阻电路 Q=W
- 电热利用（电热器）与防止（散热孔）

## 📌 家庭电路

- 电压 220 V；组成：进户线→电能表→总开关→保险→用电器
- **火线与零线**：火线对地 220 V；测电笔：手触笔尾金属体，氖管发光=火线
- 三孔插座：上孔接地线（防外壳带电触电）；保险丝用电阻率大、熔点低的铅锑合金
- 引起电流过大的两个原因：**短路、总功率过大**
- 安全原则：不接触低压带电体，不靠近高压带电体

## 🧩 电熨斗型大题套路（2026 真题同型）

1. 铭牌："额定电压 220 V、最大功率 1650 W" → $R=\dfrac{U^2}{P}$
2. 双电热丝串/并联组合调温：分别算两种接法的总功率
3. U-I 图象：斜率 = $\dfrac{1}{R}$（读图取两点算）
4. 电能："以最大功率工作 0.1 h" → $W=Pt$，注意 kW·h 与 J 换算

## 🔥 易错点

- kW·h ↔ J 换算（×3.6×10⁶）；分钟↔小时
- "实际功率"用实际电压算，别拿额定功率硬套
- 并联电器越多总电阻越小、总功率越大（"总功率过大"跳闸）
- 串联分压：额定电压不同的灯串联时，**电阻大的分得电压大**，可能超额定电压
