# 热学

> 2026 真题"工程与实践"题块考了热熔胶的物态变化 + 比热容计算（Q=cmΔt）。

## 📌 温度与物态变化（六变）

- 温度计原理：液体热胀冷缩；使用规范（液泡全浸、稳定后读数、不碰壁底）
- 体温计：量程 35-42℃，有缩口（可离开人体读数，用前甩）

| 过程 | 吸/放热 | 例子 |
| ---- | ---- | ---- |
| 熔化 ↔ 凝固 | 吸 ↔ 放 | 冰化水、热熔胶受热变液 |
| 汽化（蒸发+沸腾）↔ 液化 | 吸 ↔ 放 | 汗液蒸发降温、"白气"=液化 |
| 升华 ↔ 凝华 | 吸 ↔ 放 | 樟脑丸变小、霜、窗花（内侧） |

- 晶体有熔点（冰 0℃），熔化过程**吸热但温度不变**；非晶体没有
- 蒸发致冷；沸腾条件：达沸点 + 继续吸热

## 📌 内能与比热容

- 分子动理论：分子在运动、有间隙、存在引力斥力；扩散现象（温度越高越快）
- 内能：所有分子动能+势能；改变内能两方式：**做功、热传递**（等效）
- **比热容** $c$：单位质量物体升温 1℃ 吸收的热量；水的比热容大 $c_{水}=4.2\times10^3\ \text{J/(kg·℃)}$ → 调节气候、做冷却剂
- 热量计算：$Q=cm\Delta t$；热值 $q$：$Q=mq$（燃料）
- 热机：内能→机械能；四冲程（做功冲程对外做功）；热机效率 $\eta=\dfrac{W_{有用}}{Q_{放}}$

## 🔥 易错点

- "白气"是**液化**成的小水滴，不是水蒸气（水蒸气看不见）
- 温度不变 ≠ 不吸热（晶体熔化、液体沸腾）
- Δt = 末温 − 初温，降温题算"放出的热量"取绝对值
- 比热容是物质属性，与质量、吸放热无关
