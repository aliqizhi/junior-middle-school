# 密度、压强与浮力 ★力学核心

> 老师纪要："密度、压强与浮力构成力学三大重点，**浮力题目难度加大，已成为区分学生能力的关键题型**"。2026 真题最后一个题块就是"研究浮力"实验（9 分）。

## 📌 密度

- $\rho=\dfrac{m}{V}$；水 $\rho=1.0\times10^3\ \text{kg/m}^3$；单位换算 1 g/cm³ = 1000 kg/m³
- 密度是**物质属性**：与质量、体积、形状无关（冰化水质量不变、密度变大、体积变小）
- 鉴别物质、间接测量（量筒+天平测不规则物体密度）

## 📌 压强（进阶）

- 液体压强 $p=\rho gh$：只与**密度和深度**有关（帕斯卡裂桶）
- **柱体压强公式** $p=\rho gh$（对均匀实心柱体：$p=\dfrac{F}{S}=\dfrac{G}{S}=\rho gh$）——上海卷最爱
- 帕斯卡原理：加在密闭液体上的压强能够大小不变地被液体向各个方向传递（液压机）
- 流体压强与流速：**流速大处压强小**（飞机升力、两船相吸、地铁安全线）

## 📌 浮力 ★核心难点

### 四种求浮力方法（按题选）

| 方法 | 公式 | 适用 |
| ---- | ---- | ---- |
| 称重法 | $F_浮=G-F_示$ | 弹簧测力计实验（2026 真题） |
| 阿基米德原理 | $F_浮=\rho_液 g V_排$ | 通用；**V排 ≠ V物**（除非浸没） |
| 压力差法 | $F_浮=F_{向上}-F_{向下}$ | 理论解释 |
| 平衡法 | $F_浮=G$（漂浮/悬浮） | 静止在液面或液中 |

### 浮沉条件

- 漂浮：$F_浮=G$，$\rho_物<\rho_液$，$V_排<V_物$
- 悬浮：$F_浮=G$，$\rho_物=\rho_液$，$V_排=V_物$（可停任意深度）
- 下沉：$F_浮<G$，$\rho_物>\rho_液$
- **浸没后继续下移，浮力不变**（V排不变）——2026 真题填空考点

### 经典综合（上海大题高频）

- 柱体放入液体：容器底压强变化 $\Delta p=\dfrac{\Delta F}{S}$；液面升降判断（比较 ρ物 与 ρ液）
- 冰包石/冰化水：水面变化看 $\rho$ 关系
- 叠加体、切割叠放 → [[04-物理/专题/压强浮力-上海特色题型]]

## 🔥 易错点

- $V_排$ 与 $V_物$ 混用（漂浮时只有一部分排开）
- 浮力与深度无关（浸没后）——"越深浮力越大"是错的
- 阿基米德原理对**气体也适用**（飞艇）
- 单位陷阱：cm³ ↔ m³（×10⁻⁶）
- 压强变化量问题：先明确"对容器底的压力变化量 = 浮力？"只在物体未触底且液体未溢出时成立
