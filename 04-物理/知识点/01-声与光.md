# 声与光

> 概念送分模块，但要"秒答"。2026 真题在"生活与自然"题块里考了光的反射/折射成像辨析。

## 📌 声现象

- 产生：振动；传播需介质（固>液>气，真空不传声）
- 三特性：**音调（频率）、响度（振幅）、音色（发声体本身）**——2026 真题"调节音量"就是改响度
- 噪声控制三途径：声源处、传播过程、人耳处
- 超声波（方向性好：B超、声呐）/次声波（地震、海啸监测）
- 声速 340 m/s（15℃空气）；回声测距 $s=\dfrac{vt}{2}$

## 📌 光现象

- 直线传播：影子、日食月食、小孔成像（实像）；光速 $c=3\times10^8$ m/s
- **反射**：镜面反射/漫反射（都遵循反射定律）；平面镜成像：**等大、等距、虚像、左右相反**
- **折射**：光从空气斜射入水/玻璃，折射角<入射角；水中的鱼变浅、筷子弯折
- **透镜**：凸透镜（会聚，可成实/虚像）、凹透镜（发散，虚像）
- **凸透镜成像规律**（必背表）：

| 物距 u | 像的性质 | 应用 |
| ---- | ---- | ---- |
| u>2f | 倒立缩小实像，f<v<2f | 照相机、眼睛 |
| u=2f | 等大实像 | 测焦距 |
| f<u<2f | 倒立放大实像，v>2f | 投影仪 |
| u=f | 不成像 | — |
| u<f | 正立放大虚像 | 放大镜 |

## 🔥 易错点

- "水中倒影/平面镜" = **反射**虚像；"水中的鱼/透过水看" = **折射**虚像（2026 真题辨析"鱼在云中游"：云=反射，鱼=折射）
- 实像能成在光屏上，虚像不能
- 近视：像成在视网膜**前**，配凹透镜；远视相反
- 音调 vs 响度：听不清=响度；"尖细刺耳"=音调
