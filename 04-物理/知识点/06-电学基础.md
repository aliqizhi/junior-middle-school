# 电学基础：电流、电压、电阻与欧姆定律 ★电学核心

> 📖 本文是概要版（考前速查）；第一次学或没学懂 → 详细版：[[04-物理/知识点详解/06-电学基础]]

> 电学占中考物理约 40%。2026 真题"测量电阻"题块（8 分）= 伏安法 + 故障判断，全部建立在这页的基础上。

## 📌 三大物理量

| 物理量 | 符号 | 单位 | 仪表 | 使用要点 |
| ---- | ---- | ---- | ---- | ---- |
| 电流 | I | A | 电流表 | **串联**接入；"+"进"−"出；不超量程；**不能直接接电源两端** |
| 电压 | U | V | 电压表 | **并联**在被测两端；不超量程；**可以直接测电源电压** |
| 电阻 | R | Ω | （伏安法） | 导体属性：与材料、长度、横截面积、温度有关 |

- 串联电路：$I=I_1=I_2$；$U=U_1+U_2$；$R=R_1+R_2$（分压：$\dfrac{U_1}{U_2}=\dfrac{R_1}{R_2}$）
- 并联电路：$I=I_1+I_2$；$U=U_1=U_2$；$\dfrac{1}{R}=\dfrac{1}{R_1}+\dfrac{1}{R_2}$（分流：$\dfrac{I_1}{I_2}=\dfrac{R_2}{R_1}$）

## 📌 欧姆定律

$$I=\dfrac{U}{R}$$

- 变形：$U=IR$、$R=\dfrac{U}{I}$（R 由导体本身决定，**不随 U、I 改变**——"R=U/I 只是计算式"）
- **伏安法测电阻**（中考实验核心）：滑动变阻器作用 = ①保护电路 ②改变电压电流多次测量取平均
- 滑动变阻器接法："一上一下"；移动滑片 → R 变 → I、U 变（动态分析基础）

## 📌 电路识别三板斧

1. 电流表视为导线、电压表视为断路 → 画出等效简化图
2. 判断串并联：电流路径唯一=串联；分叉=并联
3. 换滑片/开关动作后重画等效电路再分析

## 🔥 易错点

- 电流表、电压表位置接反的后果（电流表并联=短路烧表；电压表串联=电路不通）
- 并联总电阻**小于任一支路**电阻
- 变阻器"同上同下"接法不起变阻作用
- 读数先看量程再算分度值（0-0.6A 每小格 0.02A）
- 故障判断见 [[04-物理/专题/电学四大题型]]
