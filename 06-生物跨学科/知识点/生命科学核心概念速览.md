# 生命科学核心概念速览（跨学科案例够用版）

## 一、细胞与生物体结构层次

- 细胞是生物体结构和功能的基本单位；动植物细胞都有：细胞膜、细胞质、细胞核；植物细胞多：**细胞壁、液泡、叶绿体**
- 结构层次：细胞 → 组织 → 器官 → （系统）→ 个体；**植物没有"系统"**
- 光合作用：$二氧化碳+水 \xrightarrow[\text{叶绿体}]{光能} 有机物（储存能量）+氧气$——意义：物质与能量的源头、维持碳氧平衡
- 呼吸作用：有机物 + 氧气 → 二氧化碳 + 水 + 能量（所有活细胞，昼夜不停）

**情境应用**：温室增产（提高 CO₂ 浓度、延长光照）、果蔬保鲜（低温抑制呼吸作用）、农田松土（促进根呼吸）

## 二、人体生理（八大系统）

| 系统 | 核心概念 | 情境关键词 |
| ---- | ---- | ---- |
| 消化 | 淀粉→麦芽糖→葡萄糖（唾液/胰肠）；小肠是吸收主场所（长+绒毛） | 营养均衡、慢病膳食 |
| 循环 | 心脏四腔；体循环/肺循环；动脉静脉血管区别 | 运动心率、血压 |
| 呼吸 | 肺泡气体交换：氧气→血液，CO₂ 排出；呼吸运动原理 | 有氧运动、空气质量 |
| 泌尿 | 肾单位：滤过（原尿）+ 重吸收（尿液） | 水盐平衡、健康饮水 |
| 神经 | 反射弧：感受器→传入神经→神经中枢→传出神经→效应器；条件反射 vs 非条件反射 | 反应速度、用脑卫生 |
| 内分泌 | 激素调节：胰岛素（血糖）、生长素、甲状腺激素 | 糖尿病、生长发育 |
| 运动 | 骨骼肌牵动骨绕关节活动；需能量 | 体育锻炼、运动损伤 |
| 生殖免疫 | 特异性/非特异性免疫；疫苗原理 | 传染病预防 |

## 三、生态与环境 ★最高频

- **生态系统的组成**：生物部分（生产者-植物、消费者-动物、分解者-细菌真菌）+ 非生物部分（阳光、水、空气、温度）
- **食物链**：生产者 → 消费者（只含捕食关系、不写分解者和非生物、箭头指向捕食者）
- 物质循环 + 能量流动（**单向递减**，营养级越多能量损耗越多）
- 生态平衡：数量比例相对稳定（自动调节能力有限）；**营养结构越复杂，调节能力越强**
- 有害物质沿食物链**富集**（营养级越高浓度越大）

**情境应用**：湿地保护（净化水质、蓄洪）、外来物种入侵（破坏平衡）、农药残留（食物链富集）、退耕还林

## 四、生物多样性

- 三个层次：物种多样性、基因（遗传）多样性、生态系统多样性
- 保护措施：就地保护（自然保护区最有效）、迁地保护（动物园植物园）、法律法规

## 五、遗传（简要）

- DNA→基因→控制性状；遗传物质在细胞核
- 相对性状、显性隐性（Aa×Aa → 3:1）
- 变异：可遗传/不可遗传
