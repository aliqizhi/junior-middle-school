# 跨学科案例分析 · 题型方法（15 分 → 12+）

## 审题三步

1. **读标题和情境**：先看"这是什么地方、什么问题"（农业？生态？健康？）
2. **读图表**：图名 → 图例 → 坐标轴 → 数据极值点（材料里每个图表必然被某道小题用到）
3. **圈两学科关键词**：地理词（气候/地形/河流/位置）+ 生物词（光合/生态/消化/遗传）

## 四类小题打法

### ① 信息提取题（读图表直接答）

- 答案就在材料里，**用材料原话/数据回答**，别自由发挥
- 图像题写"变化趋势 + 具体数值区间"

### ② 单学科解释题（"为什么"）

- 先定位学科：问"产地/降水/地形" → 地理模板；问"生理/生态原理" → 生物概念
- 套模板：地理区位五要素 / 光合呼吸 / 生态平衡

### ③ 跨学科综合题（最拉分）

**固定桥接模型**（背下来）：

| 情境 | 桥接逻辑 |
| ---- | ---- |
| 瓜果甜/优质农产品 | 地理（昼夜温差大、光照足）→ 生物（光合积累多、呼吸消耗少） |
| 某地适合种 X | 地理（气候雨热同期+地形土壤）→ 生物（X 的习性喜…） |
| 生态系统破坏 | 地理（人类活动改变环境）→ 生物（食物链断裂、调节能力有限） |
| 保护措施 | 生物（保护生物多样性/栖息地）+ 地理（退耕还林/划保护区/治污） |
| 健康与运动 | 生物（循环/呼吸系统原理）→ 提出合理化建议 |

### ④ 措施/建议题

- 分主体答：政府（政策、保护区）、个人（行为）、科技（技术）
- 每条 = 做什么 + 为什么能解决（半句原理）

## 答题规范

- 分点书写：①②③，每点"结论 + 依据"结构
- 用术语不用口语："雨热同期"≠"夏天热雨水多"；"自动调节能力有限"≠"受不了破坏"
- 15 分约 3-4 小问，时间控制在 15 分钟内（综合测试 120 分钟里它的预算）

## 训练计划

- 每两周 1 套（一模卷的跨学科部分）→ 错题卡归因（多为"表达不规范"或"学科定位错误"）
- 寒假集中刷各区真题的跨学科小题，总结高频情境清单（贴到本页下方）
