# 地理核心概念速览（跨学科案例够用版）

> 📖 本文是概要版（考前速查）；第一次学或没学懂 → 详细版：[[06-生物跨学科/知识点详解/地理核心概念速览]]

> 与"农业、气候、人口、资源"相关的高频概念。跨学科案例里的地图/气候图就是靠这些读。

## 一、地球与地图（读图工具）

- 经纬网：经线定东西（本初子午线 0°），纬线定南北（赤道 0°）；**纬度定热量带**（低/中/高纬；五带：热带、南北温带、南北寒带）
- 比例尺、方向、图例——读图三件套
- 海拔与相对高度；等高线：密=陡、疏=缓；山脊（凸低）、山谷（凸高，可能发育河流）

## 二、气候 ★最高频

- **影响气候的主要因素**：纬度位置（太阳辐射，根本因素）、海陆位置（温差/降水差异）、地形（海拔每升 100m 降温约 0.6℃；迎风坡降水多）、洋流
- 气温曲线与降水柱状图判读（最冷月/最热月气温 + 雨季分布 → 定气候类型）：
  - 热带雨林（全年高温多雨）、热带沙漠（全年炎热干燥）
  - 亚热带季风（雨热同期，上海所在类型）、地中海气候（夏干冬雨）
  - 温带季风（北京）、温带海洋性（全年湿润，伦敦）
- **季风气候**：夏季风（东南风）从海洋带来降水；雨热同期 → 利于农业；夏季风不稳定 → 旱涝灾害

## 三、农业区位 ★案例最爱

**"某地为什么适合种 X"的分析模板**：
1. 气候：热量（温度带）+ 降水（雨热同期？）
2. 地形：平原耕作/丘陵梯田/山地林业
3. 水源：河流灌溉
4. 土壤：黑土肥沃、红壤酸性（茶树喜酸）
5. 市场/交通/技术（人文因素）

- 中国四大地理区域：北方（旱地小麦）、南方（水田水稻）、西北（牧区/灌溉农业——昼夜温差大瓜果甜）、青藏（高寒河谷农业）
- **昼夜温差大 → 瓜果特别甜**（白天光合强积累多、夜间呼吸弱消耗少）——生物+地理经典联动考点

## 四、水资源与人口

- 中国水资源：南多北少、东多西少；夏秋多、冬春少 → 跨流域调水（南水北调）、兴修水库
- 人口分布：东多西少（胡焕庸线）；人口问题与资源环境承载力
- 土地资源：耕地林地比重小、后备不足 → 珍惜合理利用（18 亿亩耕地红线）

## 五、区域发展案例套路

"某区域发展某产业的优势/问题/措施"：
- 优势：资源/气候/交通/劳动力/政策
- 问题：生态脆弱（水土流失、荒漠化）、污染
- 措施：可持续发展（保护与开发并重、科技投入、产业链延伸）
