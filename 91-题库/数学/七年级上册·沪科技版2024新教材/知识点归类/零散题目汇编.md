解：\(\because |a| = 1\)，\(|b| = 2\)，\(|c| = 3\)，
\(\therefore a = \pm 1\)，\(b = \pm 2\)，\(c = \pm 3\)，
\(\because a > b > c\)，
\(\therefore a = - 1\)，\(b = - 2\)，\(c = - 3\)或\(a = 1\)，\(b = - 2\)，\(c = - 3\)，
则\(a + b - c = 2\)或0．
故答案为：2或0.
