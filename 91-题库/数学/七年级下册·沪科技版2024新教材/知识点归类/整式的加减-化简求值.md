## 3. （难度：适中）

化简与求值：

当\(5m - 3n = - 4\)时，求代数式\(2(m - n) + 4(2m - n) + 2\)的值。

已知\(A = {a^2} + 4a - 8\)，\(B = - \frac{1}{2}{a^2} - 3a + 4\)，当\(a = - \frac{3}{2}\)时，求\(A - 2(A - B) + 3\)的值。

已知多项式\((m{x^2} + nxy - 3x + y - 1) - (3{x^2} - mxy - 3x - 1)\)的差与\(x\)的取值无关，求\({( - 1)^{2008 + m + n}}[m - n + {( - n)^m}]\)的值。

【答案】<div><p style="text-align: justify;">原式$ = 2m - 2n + 8m - 4n + 2 = 10m - 6n + 2 = 2(5m - 3n) + 2$，</p><p style="text-align: justify;">当$5m - 3n =  - 4$时，原式$ =  - 8 + 2 =  - 6$</p></div>，<div><p style="text-align: justify;">$\because A = {a^2} + 4a - 8$，$B =  - \frac{1}{2}{a^2} - 3a + 4$，</p><p style="text-align: justify;">$\therefore $原式$ = A - 2A + 2B + 3 =  - A + 2B + 3 =  - {a^2} - 4a + 8 - {a^2} - 6a + 8 + 3 =  - 2{a^2} - 10a + 19$，</p><p style="text-align: justify;">当$a =  - \frac{3}{2}$时，原式$ =  - \frac{9}{2} + 15 + 19 = 29\frac{1}{2}$</p></div>，<div><p style="text-align: justify;">原式$ = (m - 3){x^2} + (m + n)xy + y$，</p><p style="text-align: justify;">结果与$x$的取值无关，得到$m - 3 = 0$，且$m + n = 0$，</p><p style="text-align: justify;">解得：$m = 3$，$n =  - 3$，</p><p style="text-align: justify;">则原式$ = 33$</p></div>
