## 知识点·分式何时有意义,分式的值何时为0



## 1. 

分式中的字母满足什么条件时分式有意义？何时分式值为0？

\( \frac{\left|x\right|-2}{x-2}\)

\( \frac{x+2}{(x-3)(1-x)}\)

\( \frac{x-3}{{x}^{2}-9}\)     ​

\( \frac{x-y}{x+y}\)

【答案】<div><p style="text-align: justify;">要使分式$ \frac{\left|x\right|-2}{x-2}$分式有意义，则分母$ x-2\ne 0$，即$ x\ne 2$；要使分式$ \frac{\left|x\right|-2}{x-2}$分式值为0，则分子$ \left|x\right|-2$=0且分母$ x-2\ne 0$，即$ x=-2$。</p></div>，<div><p style="text-align: justify;">要使分式$ \frac{x+2}{(x-3)(1-x)}$有意义，则分母$ (x-3)(1-x)\ne 0$，即$ x\ne 3$且$ x\ne 1$； 要使分式$ \frac{x+2}{(x-3)(1-x)}$分式值为0，则分子$ x+2=0$且分母$ (x-3)(1-x)\ne 0$，即$ x=-2$。</p></div>，<div>
<p style="text-align: justify;">要使分式$ \frac{x-3}{{x}^{2}-9}$有意义，则分母$ {x}^{2}-9\ne 0$，即$ x\ne \pm 3$；要使分式$ \frac{x-3}{{x}^{2}-9}$分式值为0，则分子$ x-3=0$且分母$ {x}^{2}-9\ne 0$，可见$ x$无解。​​</p>
</div>
，<p>要使分式$ \frac{x-y}{x+y}$有意义，则分母$ x+y\ne 0$，即$ x\ne -y$；要使分式$ \frac{x-y}{x+y}$分式值为0，则分子$ x-y=0$且分母$ x+y\ne 0$，即$ x=y\ne 0$。</p>

## 2. （难度：适中）

已知在\(△ABC\)​中，AE平分∠BAC（∠C>∠B），F为直线AE上一点，且FD⊥BC于D。

如图1，若∠B=40°，∠C=60°，点F在AE上，求∠EFD的度数；

如图2，当点F在AE的延长线上时，请猜想∠EFD与∠B，∠C之间的数量关系，并加以证明。

![](https://basic.smartedu.cn/nb_document_parser_api/question_resource/fca9c405-812c-11ed-aae6-fa20201b4500/resources/img-8fff6638-6d8f-4cc1-8fac-e4a5a5f09e53.png)

![](https://basic.smartedu.cn/nb_document_parser_api/question_resource/fca9c405-812c-11ed-aae6-fa20201b4500/resources/img-1c594766-65dd-4613-8239-25c87aa04fdd.png)

【答案】<div><p style="text-align: justify;">10&deg;，</p></div>，<div><p style="text-align: justify;">$\angle EFD = \frac{1}{2}(\angle C - \angle B)$</p><p style="text-align: justify;">（1）$\because AE$平分$\angle BAC$，</p><p style="text-align: justify;">$\therefore $$\angle BAE = \frac{1}{2}\angle BAC = \frac{1}{2}(180^\circ  - \angle B - \angle C) = 90^\circ  - \frac{1}{2}(\angle B + \angle C)$，</p><p style="text-align: justify;">$\because \angle FEC = \angle B + \angle BAE$，</p><p style="text-align: justify;">则$\angle FEC = \angle B + 90^\circ  - \frac{1}{2}(\angle B + \angle C) = 90^\circ  + \frac{1}{2}(\angle B - \angle C)$，</p><p style="text-align: justify;">$\because FD \bot EC$，</p><p style="text-align: justify;">$\therefore \angle EFD = 90^\circ  - \angle FEC$，</p><p style="text-align: justify;">则$\angle EFD = 90^\circ  - [90^\circ  + 2(\angle B - \angle C)] = \frac{1}{2}(\angle C - \angle B)$，</p><p style="text-align: justify;">$\because \angle B = 40^\circ $，$\angle C = 60^\circ $，</p><p style="text-align: justify;">$\therefore \angle EFD = \frac{1}{2}(60 - 40) = 10^\circ $；</p><p style="text-align: justify;">（2）猜想：$\angle EFD = \frac{1}{2}(\angle C - \angle B)$．</p><p style="text-align: justify;">证明：同（1）可证：$\angle AEC = 90^\circ  + \frac{1}{2}(\angle B - \angle C)$，</p><p style="text-align: justify;">$\therefore \angle DEF = \angle AEC = 90^\circ  + 2(\angle B - \angle C)$，</p><p style="text-align: justify;">$\therefore $$\angle EFD = 90^\circ  - [90^\circ  + \frac{1}{2}(\angle B - \angle C)] = \frac{1}{2}(\angle C - \angle B)$．</p></div>
