# 数学 · 学科总览

> 中考 150 分，25 题，时间 100 分钟。**得分结构决定策略：基础题（1-22 题，112 分）是生命线，压轴题（23-25 题 + 17-18 填空，38 分）决定上限。**

## 🎯 考情速览

### 题型与分值（以市教委样卷为准，2026 真题已核对）

| 题号 | 题型 | 分值 | 内容 |
| ---- | ---- | ---- | ---- |
| 1-6 | 选择 | 4×6=24 | 实数、代数式、方程、函数图象、统计、圆/四边形性质判断 |
| 7-16 | 填空（基础） | 4×10=40 | 同上范围，含统计图、概率、向量、图形变换 |
| 17-18 | 填空（压轴） | 4×2=8 | 图形运动（翻折/旋转）、新定义 |
| 19-20 | 解答 | 10×2=20 | 实数混合运算、解方程（组）/不等式 |
| 21 | 解答 | 10 | 函数（一次/反比例）或解直角三角形或圆的计算 |
| 22 | 解答 | 10 | 实际应用题（一次函数建模、方案选择） |
| 23 | 解答 | 12 | 几何论证（相似三角形为主，综合四边形/圆） |
| 24 | 解答 | 12 | 二次函数综合（存在性、平移、角度、面积） |
| 25 | 解答 | 14 | 压轴：相似 + 圆/四边形 + 函数 + 动点 |

### 老师策略（家长会纪要）

- **每周多两套一模题，重点关注压轴题**；"抬头认真听课胜过埋头记笔记"。
- 新中考方向：题型更灵活、重思维；基础题占比保障基准分，高分段靠中高档题拉开。
