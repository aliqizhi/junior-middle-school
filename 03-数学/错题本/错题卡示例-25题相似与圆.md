# 错题：第 25 题动点 + 相似求函数关系，定义域漏了

> ⭐ 这是一张**示例卡**：展示错题卡该写成什么样。自己录入错题时，用 `_templates/模板-错题卡` 新建。

## 📝 原题

已知在 △ABC 中，AB=5，BC=3，动点 P 从 B 出发沿 BA 以每秒 1 个单位移动，Q 从 C 出发沿 CA 移动，速度相同，设时间为 t。当 PQ∥BC 时，求 △APQ 与 △ABC 的面积之比 y 关于 t 的函数关系式并写定义域。

## ❌ 我的错解

写了 $y=\left(\dfrac{5-t}{5}\right)^2$，**没有写定义域**；并且把相似比方向写反（用了 $\dfrac{AB}{AP}$）。

## 🔍 错因分析

- 表面原因：漏写定义域、比例方向反。
- 根本原因：**方法不会（压轴题套路不熟）**——没有先定"相似比 = 对应边比 = $\dfrac{AP}{AB}$"这个书写模板，也没有检查"动点能走到哪"。

## ✅ 正确思路（自己捋）

1. PQ∥BC → 8 字型/A 字型相似 → △APQ ∽ △ABC（对应顶点顺序：A 对 A）
2. 相似比 = $\dfrac{AP}{AB}=\dfrac{5-t}{5}$（t 秒后 P 走了 t，AP=5-t）
3. 面积比 = 相似比平方：$y=\left(\dfrac{5-t}{5}\right)^2$
4. 定义域：P 在 BA 上（不含端点 A、B 时三角形才存在）→ $0<t<5$

## 🎯 同类变式（重做 3 道）

- [ ] 变式 1：把"PQ∥BC"改为"PQ⊥AB"，求 y 关于 t 的关系（需作高，用相似+勾股）
- [ ] 变式 2：Q 速度与 P 不同，问 t 为何值时 △APQ ∽ △ABC（注意对应关系两种）
- [ ] 变式 3：25 题真题同型：动点 + 圆（选 2026 各区一模卷第 25 题）
