# 第 24 题 · 二次函数综合（12 分）

> 固定结构：第 1 小题求解析式（必拿 4 分）→ 第 2 小题图象与平移 → 第 3 小题存在性/角度/新定义（区分度所在）。

## 解析式三件套

- 一般式 / 顶点式（沪教版记号 $y=a(x+m)^2+k$）/ 交点式 → 详见 [[03-数学/知识点/九年级/二次函数]]
- 平移：**左加右减、上加下减**（对 x 加减 → m 变；整体加减 → k 变）

## 五大题型与固定打法

### 1. 平移 + 交点

先写新解析式 → 联立新旧解析式求交点 → 判别式定个数 → 求面积。

### 2. 面积最值

- 割补法：$S = S_{大} - S_{小1} - S_{小2}$
- 铅垂法：$S=\dfrac{1}{2}\times 水平宽 \times 铅垂高$（水平宽 = 两交点横坐标差，铅垂高 = 铅垂线段长）
- 设动点坐标 → 表示面积 → 二次函数最值（别忘了 a 的符号）

### 3. 等腰三角形存在性（三分类）

以 A、B 为顶点 + 顶角顶点待定：
- AB = AC（A 为顶）：圆规画弧找 C
- BA = BC（B 为顶）
- CA = CB（C 为顶）：C 在 AB 中垂线上
用两点间距离公式列方程。**每类都要验证是否在抛物线上/是否与已知重合。**

### 4. 直角三角形存在性（三分类 + 斜率法）

- 斜率乘积 = -1（若 A 为直角顶点：$k_{AB}\cdot k_{AC}=-1$）
- 或向量点积 = 0；或勾股逆定理

### 5. 角度 / 新定义

- 角相等：构造直角三角形用 tan 比较，或平行转化，或相似对应角
- 新定义（回归抛物线、优雅抛物线、不动点）：**逐字翻译定义**为方程

## 🔥 易错点

- 分类讨论漏解：等腰 3 类、直角 3 类，逐类打勾。
- **定义域**：动点限定在线段/射线/抛物线某段上。
- 顶点式记号：沪教版 $(x+m)$，顶点横坐标是 $-m$。
- 求出坐标后代回检验（是否满足题设的所有几何条件）。
