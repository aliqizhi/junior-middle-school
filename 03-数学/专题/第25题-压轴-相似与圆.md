# 第 25 题 · 压轴（14 分）：相似 + 圆/四边形 + 函数

> 固定结构：第 1 小题证明（4-5 分，人人能拿）→ 第 2 小题求值/表示 → 第 3 小题存在性或求函数关系及定义域（拉差距）。

## 三大主题

### 一、四边形与相似综合

- 平行四边形/菱形/正方形性质作骨架，相似作桥
- 中点套路：中位线、斜边中线、倍长中线
- 梯形辅助线三板斧：平移腰、作高、延长两腰

### 二、圆与相似综合

- 直径 → 直角；同弧 → 等圆周角 → 相似（AA）
- 切线 → 垂直 → 半径三角形
- **圆幂三定理**：相交弦、切割线、割线定理（本质都是相似）
- 动圆问题：半径、弦心距、弦长的勾股关系 + 圆心距分类

### 三、函数关系（压轴终点的固定姿势）

1. 设动点（或动线段）为 $x$
2. 用**相似比例式**把目标线段表示成 x 的式子（或用等积/勾股）
3. 写出 $y = f(x)$
4. **求定义域**：几何约束（线段非负、点在给定范围内、相切临界）
5. 若问最值/范围：配方或图象

## 拿分策略（按小题）

- 第 1 题：稳写证明，依据句完整 → 4 分入袋
- 第 2 题：设参 + 相似表示 → 能算几步写几步
- 第 3 题：至少写出函数关系式拿过程分；定义域写对再拿 1-2 分
- **时间预算：18 分钟封顶，超时先保检查前面大题**

## 🔥 易错点

- 动点分类：动点可能有两个位置（圆/角平分线对称）；相切分外切内切。
- 定义域漏端点、漏"≠"情形（退化成三角形/线段时）。
- 相似对应关系不唯一时（镶嵌相似/存在性），逐个对应写，不要默认一种。
- 黄金分割比值别记混：$\dfrac{\sqrt5-1}{2}\approx0.618$（长/全）。
