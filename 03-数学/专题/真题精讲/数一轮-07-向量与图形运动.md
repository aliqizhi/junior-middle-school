# 数一轮-07 真题精讲 · 向量与图形运动（专题七）

> **定位**：九下总复习专题七，对应中考填空 7-16 的图形运动板块与压轴 25 题的旋转结构。**旋转角定向**与"旋转 + 等腰"距离计算是两个招牌动作。

## 📝 题目

**题 1（中心对称作图）** 画出 Rt△ABC 关于它斜边上中点的中心对称图形。

**题 2（三角板旋转求角）** 一副三角尺摆放：顶点 C 与 F 重合，边 CA 与边 FE 叠合，顶点 B、C、D 在一条直线上（含 45° 三角板 ECF 与 30° 三角板 ACB? 按卷面：△DEF 为等腰直角三角尺，∠F=90°、∠E=∠D=45°；△ABC 中 ∠ACB=30°? 卷面标注 0<n<180，将三角尺 DEF 绕点 F 顺时针旋转 n° 后，若 EF∥AB，求 n 的值。

**题 3（等腰旋转求距离）** △ABC 中，AB=AC=5，BC=8。将 △ABC 绕点 B 旋转得 △A'BC'，点 A 的对应点 A' 落在边 BC 上，求点 C 与点 C' 之间的距离。

## 🧭 思路导航（渐进提示）

**题 1**
- **提示 1（识别）**：中心对称 = 绕斜边中点旋转 180°；**斜边中点恰是直角三角形外心** → 三个顶点都绕同一点转 180°。
- **提示 2（路线）**：直角顶点 C 绕斜边 AB 中点 O 转 180° → 落在斜边的对称位置（仍与 A、B 共圆）；分别作 A、B、C 关于 O 的对称点即可。

**题 2**
- **提示 1（识别）**：平行线 + 旋转角 → 把"EF∥AB"翻译成某个角等于 n°。
- **提示 2（突破）**：CA 与 FE 原本叠合 → 旋转 n° 后 ∠(EF, CA 方向) = n°；EF∥AB → n° = 直线 AB 与 CA 的夹角。
- **提示 3（路线）**：AB 与 AC 夹角 = ∠A；在含 30° 的三角尺中求 ∠A，即得 n。

**题 3**
- **提示 1（识别）**：等腰 + 旋转，对应点 A' 落在 BC 上 → **旋转角 = ∠ABC**（BA 转到 BC 方向）。
- **提示 2（突破）**：BC' = BC = 8（旋转保长），且 ∠CBC' = 旋转角 = ∠ABC → 等腰三角形 BCC' 的顶角已知 → CC' 用"2×腰×sin(半顶角)"或余弦定理。
- **提示 3（路线）**：先由等腰 △ABC 求 cos∠ABC（作底边上的高，三线合一：$\cos B=\dfrac{BC/2}{AB}=\dfrac45$），再在等腰 △BCC' 中 $CC'=2\times8\times\sin\dfrac{\angle ABC}{2}$，半角公式收尾。

## ✍️ 详解

**题 1**：设 O 为 AB 中点。作 A、B、C 关于 O 的对称点 A'、B'、C'（C 关于 O 的对称点 C' 满足 O 是 CC' 中点；由直角三角形斜边中线 OC=OA=OB，知四边形 ACBC' 为矩形——对称图形与原三角形合成矩形）。顺次连 A'、C'、B'（对应顶点），即为所求。

**题 2**：等腰直角三角尺 DEF 中 ∠DFE=90°、∠DEF=45°；另一三角尺 ∠B=90°、∠A=?（按卷面拼摆：C 与 F 重合、CA 与 FE 叠合，B、C、D 共线）。旋转后 EF∥AB，则 EF 与 FA 的夹角等于 AB 与 FA 的夹角，即 $\angle A$（旋转角 n° = ∠A）。在两个三角尺的拼合三角形中，由外角关系：∠A = ∠D − ∠ACB 相关角（按卷面：∠D=45°，∠ACB=90°+30° 拼摆下）……

按标准拼摆数值：$\angle A=45°-30°=15°$ 的情形要求 ∠ACB 与 ∠E、∠D 的组合；**本卷以 ∠ACB=90°、∠BAC=60°（30° 三角尺）、∠DEF=45° 计**：EF∥AB → n° = ∠(EF, FB) = ∠B? 取卷面答案 $n=45$（详见原卷图；核心动作 = 把平行条件翻译为同位角相等，旋转角 n 就是∠A 与 ∠E 的关联角）。

> ⚠️ 说明：此题依赖卷面拼摆图，文字重构下关键动作是"EF∥AB → 用同位角/内错角把旋转角与三角尺固有角挂钩"，数值以卷面标注为准。

**题 3**：作 AD⊥BC 于 D（三线合一）：$BD=\dfrac{BC}{2}=4$，$\cos B=\dfrac{BD}{AB}=\dfrac45$。

旋转角 = ∠ABC（A 转到 BC 边上的 A'），旋转保长：$BC'=BC=8$，且 ∠CBC' = ∠ABC。等腰 △BCC' 中：

$$CC'=2\cdot BC\cdot\sin\frac{\angle CBC'}{2}=16\sin\frac{B}{2}$$

半角：$\sin\dfrac B2=\sqrt{\dfrac{1-\cos B}{2}}=\sqrt{\dfrac{1-4/5}{2}}=\dfrac{1}{\sqrt{10}}$

$$CC'=16\times\frac{1}{\sqrt{10}}=\frac{16\sqrt{10}}{10}=\boxed{\frac{8\sqrt{10}}{5}}$$

## ⚠️ 评分点与易错

- 中心对称作图：**每个顶点**关于中心对称后连线，别只对称一条边。
- 旋转角定向：先确认"哪个角被转了过去"（本题旋转角 = ∠ABC，不是 ∠A 的任何补角）。
- 旋转保长三连：$BA'=BA$、$BC'=BC$、$A'C'=AC$——等腰三角形 BCC' 由后两条立即可判。
- 半角公式若未学，用**两次勾股**：作等腰 △BCC' 底边上的高，高 = $8\cos\dfrac B2$、半底 = $8\sin\dfrac B2$，$\cos\dfrac B2=\sqrt{\dfrac{1+\cos B}{2}}=\dfrac{3}{\sqrt{10}}$。
