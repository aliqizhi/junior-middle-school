# 精讲库写作规范（内部维护文档，不进 MOC）

> 新增讲义必须遵守本规范。现有讲义升级时也按此执行。**本规范同样适用于物理、化学精讲库**（差异见文末"物理/化学适配"）。

## 文件命名

- **24/25 题库**：`{24|25}-{讲义流水号}-{题型slug}.md`（流水号与 MOC 表格一致，不等于题库题号；frontmatter 里写 `题库题号`）。
- **21/22/23 题库**：`{21|22|23}-{两位题库题号}-{题型slug}.md`——**文件名序号 = 题库题号**（21 题库 1-23、22 题库 1-18、23 题库 1-20）。
- 配图在 `figs/{21|22|23|24|25}-{题库题号}-N.png`（N 为该题第几张图；24/25 题库的讲义配图按题库题号取用）。

## 题源 OCR 讹误解码规则（务必自查）

题源 docx 提取文本中，**根号与分数线常丢失**，只能靠数学一致性解码，例如：
- `62`→$6\sqrt2$ 或 $\frac{\sqrt6}{2}$（看语境）；`522`→$\frac{5\sqrt2}{2}$；`105`→$\frac{\sqrt{10}}{5}$；`210`→$\frac{\sqrt{10}}{10}$ 或 $2\sqrt{10}$
- `5−12`→$\frac{\sqrt5-1}{2}$；`13`→$\frac13$；`35`→$\frac35$；`23`→$\frac23$；`125`→$\frac{12}5$；`22`→$2\sqrt2$ 或 $\sqrt2$
- 个别题干有笔误（如 24 题库典例 2 的 B(3,0) 应为 B(5,0)），**必须用解答反推核对题干**。

## 质量要求（硬性）

1. **每个数值结果自己重算一遍**；算不通就回头查转录，仍存疑则在 `⚠️ 待核对` 标注并写明疑点。
2. 不得省略"设参→列式→求解→舍根→定义域"中任何一环。
3. 分类讨论必须列全并逐一给出取舍理由。
4. 单文件 90~160 行；不写与本题无关的扩展。

## 物理/化学适配

- **位置与命名**：物理讲义在 `04-物理/专题/真题精讲/`，文件名 `物-{两位序号}-{模块slug}.md`；化学在 `05-化学/专题/真题精讲/`，文件名 `化-{两位序号}-{slug}.md`。
- **frontmatter**：`学科: 物理/化学`、`题源: 51jiaoxi 一轮训练·{专题名}`、`题号: 原卷第N题`（或"举一反三·专题x.x 题型N"）、其余 tags/难度/updated 同上。
- **物理详解**：计算题按"设列算验答"五步（见 [[04-物理/专题/大题规范书写-设列算验答]]）；选择题逐项给排除理由；实验题写"结论句规范表述"。
- **化学适配**：举一反三系列按**旧教材**专题编号（1.1~4.4），讲义必须在开头注明新教材对应专题（对照表见 [[05-化学/学科总览]]）；说理题详解采用"判断→依据→回扣情境"三段式。
- **渐进提示**：提示 1 = 识别考点；提示 2 = 关键公式/方程/排除思路；提示 3 = 完整解题路线。
