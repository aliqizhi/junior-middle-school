# 25 题精讲 07 · 新定义：镶嵌相似形

## 📝 题目

定义：如果一个三角形的三个顶点分别在另一个三角形的三边上，且这两个三角形相似，那么称这个三角形为另一个三角形的**镶嵌相似形**。已知 △$ABC$ 中，$P$、$D$、$E$ 分别在 $BC$、$AB$、$AC$ 上，联结 $PD$、$DE$、$PE$。
(1) 如图 1，$P$ 是 $BC$ 中点，$PD\parallel AC$，$PE\parallel AB$，求证：△$PDE$ 是 △$ABC$ 的镶嵌相似形；
(2) 如图 2，$AB=AC$，$BP=2PC$，△$PDE$ 是 △$ABC$ 的镶嵌相似形，且 $\angle A=\angle PDE$，求 $\dfrac{AD}{AB}$ 的值；
(3) 如图 3，$\angle A=\angle DPE=90°$，$BP=2$，$PC=3$，△$PDE$ 是 △$ABC$ 的镶嵌相似形，且 $PE$ 与 $AB$ 不平行，求 $AB$ 的长。

## 🧭 思路导航

- 新定义 = **顶点在边上 + 相似**两个条件；解题时先问"对应关系是哪一种"。
- (2) 等腰 + 等角 → 一线三等角模型：△BDP∽△CPE 把 $BD$ 与 $CP$ 挂钩，比例立刻出来。
- (3) 双垂直下的 $\angle DPE=90°$ 是"**一线三垂直（K 型）**"相似：△DHP∽△EIP 给出 $DP:EP=HP:IP$，再设双参数 $a,k$ 用勾股收口；对应关系要分 △PDE∽△ABC 与 △PDE∽△ACB 两类。

## ✍️ 详解

**(1)** $PD\parallel AC$ → $\dfrac{BD}{BA}=\dfrac{BP}{BC}=\dfrac{DP}{AC}=\dfrac12$；$PE\parallel AB$ → $\dfrac{CE}{CB}=\dfrac{PE}{AB}=\dfrac12$；$D$、$E$ 分别为 $AB$、$AC$ 中点 → $DE\parallel BC$ 且 $\dfrac{DE}{BC}=\dfrac12$。

三边对应成比例、顶点分别在三边上 → △$PDE$ 是 △$ABC$ 的镶嵌相似形。$\blacksquare$

**(2)** △$PDE$ 与 △$ABC$ 相似且 $\angle A=\angle PDE$ → △$PDE$ 也是等腰三角形（$PD=PE$），$\angle DPE=\angle B=\angle C$。

一线三等角：$\angle DPC=\angle DPE+\angle CPE=\angle B+\angle BDP$ → $\angle CPE=\angle BDP$；加 $\angle B=\angle C$：

$$\triangle BDP\backsim\triangle CPE\ \Rightarrow\ \frac{DP}{PE}=\frac{BD}{CP}=1\ \Rightarrow\ BD=CP$$

$BP=2CP$ → $BC=3CP$，所以 $\dfrac{BD}{AB}=\dfrac{CP}{BC}=\dfrac13$，

$$\boxed{\dfrac{AD}{AB}=1-\dfrac13=\dfrac23}$$

**(3)** $BC=BP+PC=5$，$\angle A=90°$。对应关系分类：

**情形①：△$PDE\backsim$△$ABC$**（$DP:EP=AB:AC$）。

作 $PH\perp AB$ 于 $H$、$PI\perp AC$ 于 $I$，则 $\angle DHP=\angle EIP=90°$。由 $\angle DPE=\angle HPI=90°$ 得 $\angle DPH=\angle EIP$（同余角）→ $\triangle DHP\backsim\triangle EIP$ →

$$\frac{DP}{EP}=\frac{HP}{IP}$$

$HP\parallel AC$ → $\dfrac{HP}{AC}=\dfrac{BP}{BC}=\dfrac25$，设 $HP=2k$、$AC=5k$；$IP\parallel AB$ → $\dfrac{IP}{AB}=\dfrac{CP}{BC}=\dfrac35$，设 $IP=3a$、$AB=5a$。

由 $\dfrac{AB}{AC}=\dfrac{DP}{EP}=\dfrac{HP}{IP}$：$\dfrac{5a}{5k}=\dfrac{2k}{3a}$ → $3a^2=2k^2$。勾股：$AB^2+AC^2=BC^2$ → $25a^2+25k^2=25$，即 $a^2+k^2=1$。代入 $a^2=\dfrac23k^2$：$\dfrac53k^2=1$，$k^2=\dfrac35$，则

$$AB^2=25a^2=25\cdot\frac23\cdot\frac35=10\ \Rightarrow\ AB=\sqrt{10}$$

**情形②：△$PDE\backsim$△$ACB$**。此时 $\angle PED=\angle APC=\angle PAB$ → $AP=BP=CP$（直角三角形斜边中线等于斜边一半的逆用），与 $BP=2\ne3=PC$ 矛盾，舍去。

$$\boxed{AB=\sqrt{10}}$$

## ⚠️ 评分点与易错

- (3) 的"**两个设参方向**"（沿平行线截比例设 $HP:AC$、$IP:AB$）+ "勾股闭合"（$AB^2+AC^2=BC^2$）是标准组合拳；参数一多就要在图上全部标出。
- 对应关系**必须分类**且逐一检验（情形②的矛盾点是 $BP\ne PC$）——"且 $PE$ 与 $AB$ 不平行"这句题设就是在提醒存在另一类。
- (2) 中"一线三等角"的识别依据写法：用 $\angle DPC$ 的两种拆法引出 $\angle CPE=\angle BDP$，这一步是步骤分。
