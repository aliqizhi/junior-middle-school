# 数一轮-05 真题精讲 · 相似与锐角三角比（专题五）

> **定位**：九下总复习专题五，合并复习两大主线：比例（相似的前置语言）+ 三角比。比例中项、合比消参是本专题的两个招牌动作。

## 📝 题目

**题 1（合比求连比）** 若 $3x-3z=0$，$x-y+z=0$，则 $x:y:z=$（　）
A．1∶3∶2　B．3∶2∶1　C．1∶2∶1　D．3∶1∶2

**题 2（梯形过对角线交点的平行线）** 梯形 ABCD 中，AD∥BC，O 为对角线 AC 与 BD 的交点，MN 过点 O 交 AB 于 M、交 DC 于 N，且 MN∥BC。则 OM 与 ON 的大小关系为（　）
A．OM=ON　B．OM>ON　C．OM<ON　D．OM≠ON

**题 3（比例中项）** 线段 $a=4$ cm，$b=9$ cm，则它们的比例中项等于＿＿ cm。

**题 4（比例尺换算）** 比例尺为 1∶40000 的地图上，量得 A、B 两地距离 37 cm，求 A、B 两地实际距离。

## 🧭 思路导航（渐进提示）

**题 1**
- **提示 1（识别）**：两个方程三个未知数 → 求连比 = 把 x、z 都用 y（或 x）表示。
- **提示 2（突破）**：第一式即 $x=z$（两边除 3）；代回第二式 $y=x+z=2x$。
- **提示 3（路线）**：令 $x=1$ → $z=1$、$y=2$ → 连比 1∶2∶1（对照选项，原卷 C 项排版误作 1∶3∶2，以计算为准）。

**题 2**
- **提示 1**：梯形中"过对角线交点且平行于底"的线段——熟结论：**被交点平分**。
- **提示 2**：证明靠双相似：MO∥AD 且 MO∥BC → 用 $\triangle BMO$ 与对应三角形两轮相似，导出 $OM=ON$。
- **提示 3（路线）**：$AD∥MN∥BC$ → $\dfrac{OM}{AD}=\dfrac{BM}{BA}$，$\dfrac{ON}{BC}=\dfrac{CN}{CD}$……再用 $\dfrac{BM}{MA}=\dfrac{BN}{NC}$（O 在对角线上）串起来。

**题 3**
- **提示 1**：比例中项定义：$a:c=c:b$ 即 $c^2=ab$。
- **提示 2（路线）**：$c^2=4\times9=36$ → $c=6$（线段取正值）。

**题 4**
- **提示 1**：比例尺 = 图距∶实距 → 实距 = 图距 × 40000。
- **提示 2（路线）**：$37\times40000=1\,480\,000$ cm → 化 km。

## ✍️ 详解

**题 1**：$3x-3z=0 \Rightarrow x=z$。代入 $x-y+z=0$：$y=x+z=2x$。令 $x=1$：$y=2$，$z=1$ →

$$x:y:z=1:2:1\qquad\text{（选 C；原卷选项排版有误，按推导结果作答）}$$

**题 2**：由 $AD∥MN∥BC$：
- 在 △ABC 中（M 在 AB 上、O 在 AC 上）：$\dfrac{OM}{BC}=\dfrac{AM}{AB}$
- 在 △BAD 中（M 在 AB 上、O 在 BD 上）：$\dfrac{OM}{AD}=\dfrac{BM}{BA}$
- 同理对 N：$\dfrac{ON}{BC}=\dfrac{CN}{CD}$，$\dfrac{ON}{AD}=\dfrac{AN}{AD+…}$——用 O 是对角线交点得 $\dfrac{AM}{AB}=\dfrac{DN}{DC}$ 与平行线分线段成比例，两轮导出 $\dfrac{OM}{BC}=\dfrac{ON}{BC}$ →

$$OM=ON\qquad\text{（选 A）}$$

**题 3**：$c^2=ab=36$，线段长取正 → $c=6$ cm。（对比：若问"4、9、c 成比例第三比例项"，则是 $b^2=ac$? 不——第三比例项 $x$ 满足 $4:9=9:x$ → $x=20.25$；**比例中项**与**第三比例项**是两个不同问法，别混。）

**题 4**：实际距离 $=37\times40000=1\,480\,000$ cm $=14.8$ km。

## ⚠️ 评分点与易错

- **连比题**：两条线性方程三个未知数是"定比"信号——设参（令 x=1）最稳。
- **比例中项 $c=\sqrt{ab}$**：线段取正；若换成"方程 $x^2=ab$ 的根"则 ± 都要。
- 比例尺三换算：图距×分母 = 实距；单位最后统一成 km（错单位是本题唯一丢分点）。
- 梯形"过交点平行线"结论值得记：**这条线段被对角线交点平分**（等腰梯形里它同时垂直于底/平分高时另有结论，注意区分）。
