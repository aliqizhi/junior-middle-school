# 数一轮-08 真题精讲 · 函数初步（专题八）

> **定位**：九下总复习专题八，横跨中考第 1-6 题的函数概念题与第 24 题二次函数地基。**沪教版顶点式记号 $a(x+m)^2+k$** 与"图像填表"是本专题的标志性内容。

## 📝 题目

**题 1（二次函数辨析·选择）** 下列函数关系中，y 是 x 的二次函数的是（　）
A．$y=3(x-4)^2-9x^2$　B．$y=(x+4)^2-x^2$（卷面排版项）
C．$y=\dfrac{1}{x^2}+x^2$　D．$y=(x-4)^2$

**题 2（图像性质填表）** 完成抛物线性质表：

| 抛物线 | 开口方向 | 对称轴 | 顶点坐标 |
| ---- | ---- | ---- | ---- |
| $y=ax^2$（a<0） |  |  |  |
| $y=ax^2+k$（a>0） |  |  |  |
| $y=a(x+m)^2$（a<0） |  |  |  |
| $y=a(x+m)^2+k$（a>0） |  |  |  |

并说明：$y=ax^2+bx+c$ 的对称轴与顶点，以及 $a>0$/$a<0$ 时的升降情况。

## 🧭 思路导航（渐进提示）

**题 1**
- **提示 1（识别）**：二次函数 = $y=ax^2+bx+c$（$a\neq0$）——**化简后**二次项系数非零才是判据。
- **提示 2（突破）**：A 展开后二次项系数 $3-9=-6\neq0$ ✓；"卷面 B 项"展开后二次项相消变成一次函数；C 是反比例型（分母含 x²）。
- **提示 3（路线）**：逐项展开/识别最高次。

**题 2**
- **提示 1**：沪教版顶点式 $y=a(x+m)^2+k$ 的顶点是 $(-m,k)$——**注意符号**（与全国版 $a(x-h)^2+k$ 的 h 差一个符号）！
- **提示 2（路线）**：开口看 a 正负；对称轴与顶点按记号写；一般式用 $-\dfrac{b}{2a}$ 与升降"左降右升/左升右降"分述。

## ✍️ 详解

**题 1**：
- A：$y=3(x^2-8x+16)-9x^2=-6x^2-24x+48$，二次项系数 $-6\neq0$ → **是二次函数** ✓
- B（卷面项 $(x+4)^2-x^2$ 型）：展开后 $x^2$ 相消 → 一次函数 ✗
- C：$\dfrac{1}{x^2}+x^2$ 分母含自变量 → 不是二次多项式函数 ✗
- D：$y=(x-4)^2=x^2-8x+16$ → **是二次函数** ✓
- **按卷面单选口径，A、D 均为二次函数**（原卷答案以排版为准；本讲核验：A、D 满足定义）。

**题 2**（沪教版记号 $y=a(x+m)^2+k$，顶点 $(-m,\ k)$）：

| 抛物线 | 开口 | 对称轴 | 顶点 |
| ---- | ---- | ---- | ---- |
| $y=ax^2$（a<0） | 向下 | $y$ 轴 | $(0,0)$ |
| $y=ax^2+k$（a>0） | 向上 | $y$ 轴 | $(0,k)$ |
| $y=a(x+m)^2$（a<0） | 向下 | $x=-m$ | $(-m,0)$ |
| $y=a(x+m)^2+k$（a>0） | 向上 | $x=-m$ | $(-m,k)$ |

一般式 $y=ax^2+bx+c$：对称轴 $x=-\dfrac{b}{2a}$；
- $a>0$（开口向上）：对称轴左侧 $y$ 随 $x$ 增大而**减小**，右侧**增大**，顶点是最**低**点；
- $a<0$（开口向下）：左侧**增大**，右侧**减小**，顶点是最**高**点。

## ⚠️ 评分点与易错

- **沪教版 $(x+m)$ 记号**：顶点横坐标是 $-m$——"m 前添负号"是全国版 $（x-h）$ 读者最容易翻车的一处。
- 二次函数辨析必须**先化简**再判二次项系数；分母含自变量的一票否决。
- 填表题每一格都是分：对称轴是直线要写"$x=$…"，顶点是坐标要写括号对。
- 升降表述必须**分对称轴左右两侧**说（"y 随 x 增大而…"只在单侧成立）。

## ✅ 答案速查

| 题 | 答案 |
| ---- | ---- |
| 题 1 | A、D 化简后均为二次函数（单选按卷面口径；B 展开后退化一次函数） |
| 题 2 | 见上表；一般式对称轴 $x=-\dfrac{b}{2a}$，a>0 左降右升最低点 |
