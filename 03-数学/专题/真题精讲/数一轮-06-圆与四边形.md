# 数一轮-06 真题精讲 · 圆与四边形（专题六）

> **定位**：九下总复习专题六，对应中考选择第 5-6 题与第 23 题论证地基。命题判断题的"缺前提"陷阱与两圆位置的"排除法"是本讲两个招牌动作。

## 📝 题目

**题 1（圆的命题判断）** 下列命题正确的有（　）
(A) 在同圆或等圆中，等弦所对的弧相等；
(B) 圆的两条不是直径的相交弦，不能互相平分；
(C) 垂直于弦的直线平分弦；
(D) 圆内直径平分弦，则此直径垂直这条弦。

**题 2（两圆位置·排除法）** 两圆圆心距为 2，其中一个圆半径为 3，另一个圆半径大于 1，那么两圆位置关系**不可能**的是（　）
A．外切　B．相交　C．内切　D．内含

**题 3（正方形判定补条件）** 四边形 ABCD 中，∠A=∠B=∠C=90°，添加一个条件即可推出它是正方形，这个条件可以是（　）
A．∠D=90°　B．AB=CD　C．AC=BD　D．BC=CD

**题 4（菱形证明）** 菱形 ABCD 中，E 为 AD 的中点，EF⊥AC 交 CB 的延长线于 F，EF 分别交 AB、AC 于点 G、H。求证：AB 与 EF 互相平分。

## 🧭 思路导航（渐进提示）

**题 1**
- **提示 1（识别）**：四句话逐个找反例——命题判断题=找反例游戏。
- **提示 2（突破）**：(A) 缺"所对的是**优弧还是劣弧**"的前提；(C)(D) 是垂径定理的"伪推论"——垂直→平分成立，平分→垂直要看"是否过圆心"且弦非直径。
- **提示 3（路线）**：同圆等圆中，一条弦对两条弧（优+劣）→ 等弦对的是"等弧组"，直接说"弧相等"不严谨 ✗；(B) 举两垂直弦（非直径）互相平分的反例（菱形中心对称的两条弦）✗……

**题 2**
- **提示 1**：设另一圆半径 r>1，圆心距 d=2，逐个位置关系列式看是否矛盾。
- **提示 2（突破）**：外切 d=R+r → 2=3+r → r=−1 无解。
- **提示 3（路线）**：相交 |3−r|<2<3+r → r>1 ✓ 存在；内切 d=3−r=2 → r=1 与 r>1 矛盾 ✗ 但内切需 r<3……内含 |3−r|<2 → 1<r<5 ✓。综合排除后答案唯一。

**题 3**
- **提示 1**：三个 90° → 已是**矩形**；补"邻边相等"= 正方形。
- **提示 2（路线）**：D 选项 BC=CD 是邻边相等 ✓；C 对角线相等矩形已有；B 对边相等无用。

**题 4**
- **提示 1（识别）**："互相平分"= 证四边形 AGBF（或 A、G、H、E 相关四边形）是平行四边形——用"两组对边平行"。
- **提示 2（突破）**：菱形 → AB∥CD 且 AD∥BC；E 是 AD 中点 → **比例中转站**；EF⊥AC → 构造 Rt△ 中斜边中线或相似转移。
- **提示 3（路线）**：AD∥BC + E 为 AD 中点 → 过 E 的平行线在"梯形 AFCD"框架里用全等/比例证 EG=HF 与 AG=…，再证平行四边形。

## ✍️ 详解

**题 1**：
- (A) ✗：等弦在同圆等圆中对着**优弧与劣弧各一**，只能说"所对的劣弧相等（或优弧相等）"，缺前提不成立。
- (B) ✗：反例——过圆心 O 作两条互相垂直的弦（非直径），关于 O 中心对称时可互相平分（如菱形对称位置的两条等弦），故"不能互相平分"错误。
- (C) ✗：**平分弦的直线必须过圆心才垂直于弦**；随便一条垂直于弦的直线只平分该弦所在位置，不平分……（准确表述：过圆心垂直于弦的直线平分弦——(C) 反过来说"垂直于弦的直线平分弦"缺"过圆心"）。
- (D) ✓：**直径平分弦（弦非直径）**，由垂径定理逆用 → 垂直于弦。
- **答案：(D)**（原卷单选；(A) 若按"同圆等圆中劣弧"口径亦可判对——判卷以教材表述为准，此处按最严口径选 D）

**题 2**：设 r>1，d=2，R=3：
- 外切：d=R+r → 2=3+r → r=−1 ✗ 不可能；
- 相交：|3−r|<2<3+r → r>1 时成立 ✓；
- 内切：d=|3−r|=2 → r=1 或 r=5；r=1 与"r>1"矛盾 ✗，r=5>3 时 d=2? |3−5|=2 ✓ 成立；
- 内含：d<|3−r|? 2<|3−r| → r<1 或 r>5；r>5 时 d=2<5−r? 需 r<1 矛盾——r>5 时 |3−r|=r−3>2 ✓ 内含成立。
- **不可能的是外切（A）**。

**题 3**：三角直角已保证是**矩形**；正方形 = 矩形 + 一组邻边相等 → **D（BC=CD）**。A ∠D=90° 是矩形应有；C 对角线相等是矩形自带；B 对边相等不改变形状。

**题 4**：EF⊥AC 于 H，且 AD∥BC（菱形对边）：
1. ∠AEH=∠CFH（平行线的内错角，因 EF⊥AC 连线……严格证：过 E 作 EF 交 CB 延长线于 F，且 AD∥BF → ∠EAG=∠FCG（AC 截平行线 AD、CB 的内错角），∠EG A=∠…构造 △AEG 与 △CFH? —— 标准路径：
2. 由 E 为 AD 中点、AD∥BC，取 AC 为轴：EF⊥AC → A、C 关于 EF 对称（AH=CH）→ **AG=CF** 且 ∠EGA=∠CFE……
3. 规范书写（结论链）：AH=CH（三线合一，因 EA=EC? ——菱形对角线互相平分：O 为 AC∩BD，**OA=OC**；EH∥? …）。
   
**命题正确答案（卷面口径）**：先证 △AEG ≌ △CFH? 卷面给证：AG=CF 且 AG∥CF（AD∥BC）→ 四边形 AFCG 是平行四边形 → 对角线 AC 与 GF 互相平分 → 交点 H 平分 AC 亦平分 GF；而 AB 与 EF 分别过该对角线的两端（A 与 E、G 与 F 构成的四边形 ABFE 中）——**按卷面答案：AB 与 EF 互相平分即证四边形 AEBF 为平行四边形**：AG=CF → EG=BF（因 CF=FB? 由 F 在 CB 延长线且 EH∥BC? ——卷面利用 ∠EFB=∠…与 BE=BF 的等腰结构完成。**本讲建议按"证四边形 AEBF 对角线互相平分"或"一组对边平行且相等"的任一路径规范书写，关键支撑 = 菱形对角线 OA=OC + E 中点 + EF⊥AC 的对称性。**）

> 说明：此题原卷证明依赖图形细节，文字重构后建议按上述两条路径之一规范书写，步骤分在"平行 + 中点 + 垂直"三要素齐全。

## ⚠️ 评分点与易错

- 垂径定理正向/逆向**前提差一字**：过圆心+垂直+弦（非直径）三者中缺一不推另一。
- 等弦对弧：**同圆等圆 + 指明劣弧（或同为优弧）** 两个前提缺一不可。
- 两圆位置用"排除+验证"：列出 |R−r| 与 R+r 的两个临界即可，别背五种关系。
- 正方形判定链：矩形 + **邻边相等**（或对角线垂直）；别选"对角线相等"（矩形自带）。
