# 25 题精讲 03 · 菱形判定、重心与相交两圆

## 📝 题目

▱$ABCD$ 中，$P$ 是 $BC$ 中点，联结 $BD$ 交 $AP$ 于 $E$，联结 $CE$。
(1) 若 $AE=CE$：
ⅰ. 求证：▱$ABCD$ 为菱形；
ⅱ. 若 $AB=5$，$CE=3$，求 $BD$ 的长；
(2) 分别以 $AE$、$BE$ 为半径，$A$、$B$ 为圆心作圆，两圆交于 $E$、$F$，$F$ 恰在射线 $CE$ 上。若 $CE=\sqrt2\,AE$，求 $\dfrac{AB}{BC}$ 的值。

> 注：题源文本此处印作"CE=2AE"，但经重心构形坐标检验（$AG^2=AE^2-\frac{CE^2}{4}>0$ 的要求），条件应为 $CE=\sqrt2\,AE$，与标准答案 $\frac{\sqrt{10}}{5}$ 自洽。

## 🧭 思路导航

- ⅰ 菱形判定的上海标准路径：对角线互相垂直（连 $AC$ 交 $BD$ 于 $O$，证 $\angle COE=90°$）。
- ⅱ 认出 $E$ 是 **△ABC 的重心**（$AP$、$BO$ 都是中线）→ 重心分中线 $2:1$ → 两个直角三角形共享 $OA$ 列方程。
- (2) 相交两圆的**连心线垂直平分公共弦**（$AB\perp EF$）是隐形条件；配合重心性质 $EG=\frac12CE$（$G$ 为 $AB$ 与 $CE$ 交点）即可全盘代数化。

## ✍️ 详解

**(1)ⅰ.** 连 $AC$ 交 $BD$ 于 $O$。▱ 中 $OA=OC$；又 $AE=CE$、$OE=OE$ → $\triangle AOE\cong\triangle COE$（SSS）→ $\angle AOE=\angle COE$，而两角互补 → $\angle COE=90°$ → $AC\perp BD$ → ▱$ABCD$ 为菱形。$\blacksquare$

**(1)ⅱ.** $OB$ 是 △$ABC$ 的中线（$O$ 为 $AC$ 中点），$AP$ 也是中线（$P$ 为 $BC$ 中点）→ $E$ 是**重心**：

$$BE=2OE$$

设 $OE=x$，则 $BE=3x$（因 $BE=2OE$，$BO=3x$）。两个直角三角形：

$$\text{Rt}\triangle AOE:\ OA^2=AE^2-OE^2=9-x^2;\qquad \text{Rt}\triangle AOB:\ OA^2=AB^2-OB^2=25-9x^2$$

$$9-x^2=25-9x^2\ \Rightarrow\ x=\sqrt2,\qquad BD=2OB=6\sqrt2$$

**(2)** 两圆交于 $E$、$F$ → 连心线 $AB$ **垂直平分公共弦** $EF$ → $AB\perp$ 直线 $CEF$。设直线 $CEF$ 交 $AB$ 于 $G$：因 $E$ 是 △$ABC$ 的重心（$AP$、$BO$ 是两条中线），$CG$ 是第三条中线 → $AG=BG$，且 $CE:EG=2:1$，$EG=\dfrac12CE=\dfrac{\sqrt2}{2}AE$。

在 Rt$\triangle AGE$ 中（$\angle AGE=90°$）：

$$AG^2=AE^2-EG^2=AE^2-\frac12AE^2=\frac12AE^2\ \Rightarrow\ AG=\frac{\sqrt2}{2}AE,\qquad AB=2AG=\sqrt2\,AE$$

在 Rt$\triangle BGC$ 中（$G$ 为 $AB$ 中点）：

$$BC^2=BG^2+CG^2=AG^2+(CE+EG)^2=\frac12AE^2+\left(\sqrt2AE+\frac{\sqrt2}{2}AE\right)^2=\frac12AE^2+\frac92AE^2=5AE^2$$

$$\boxed{\dfrac{AB}{BC}=\dfrac{\sqrt2AE}{\sqrt5AE}=\dfrac{\sqrt{10}}{5}}$$

## ⚠️ 评分点与易错

- **重心条件是"免费礼物"**：看到两条中线交点就说"重心"，$BE=2OE$ 一句话拿分；反过来若忘了，ⅱ 无法化简。
- 相交两圆 → **连心线垂直平分公共弦**，这一条在 (2) 里就是"$AB\perp EF$"，漏写扣步骤分。
- (2) 出现 $45°$ 时果断用等腰直角三角形转移线段（$EQ=ED$）。
