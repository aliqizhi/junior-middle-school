# 第 21-22 题 · 函数与三角比应用（10+10 分）

> 21 题三种轮换考法：①一次/反比例函数 ②解直角三角形应用 ③圆的基本计算。22 题固定是**实际应用建模**。

## 第 21 题 · 三种考法

### 考法① 一次函数 + 反比例函数

- 待定系数法求解析式（代点进方程组）
- 交点 = 联立两解析式；由点坐标求线段长、三角形面积
- 反比例函数上点向坐标轴作垂线 → 矩形面积 |k|
- **定义域**：几何约束（线段长度>0）或实际意义

### 考法② 解直角三角形应用

- 仰俯角测高 / 坡度 / 方向角三大场景 → 详见 [[03-数学/知识点/九年级/锐角的三角比与解直角三角形]]
- 口诀：有弦用弦，无弦用切；宁乘毋除，取原避中
- 双直角三角形：公共边设 x 列方程

### 考法③ 圆的基本计算

- 垂径定理十字架：$r^2=(\dfrac{弦}{2})^2+弦心距^2$
- 圆周角定理 → 求角；切线性质 → 直角
- 扇形弧长/面积公式

## 第 22 题 · 实际应用（固定题型）

**四步框架：设（设未知数+单位）→ 列（找等量关系）→ 解（含定义域）→ 答（完整答句）**

常考模型：

1. **一次函数建模**：费用/油量/水量随时间变化；分段函数注意每段范围
2. **方案选择**：列两种方案的费用表达式 → 不等式比较 → 分情况答"当…时选…"
3. **增长率**：$a(1+x)^2=b$（一元二次方程，注意 x 的取舍）
4. **交通/密度/最优**：一次函数 + 不等式组

## 🔥 易错点

- 忘写定义域（尤其分段函数转折点归属哪段）
- 答句不完整（"选择方案 A"这类结论句值 1 分）
- 解直角三角形开头忘写"在 Rt△ 中"；结果忘带单位
- 方案比较漏"等于"情形（两方案一样贵）
