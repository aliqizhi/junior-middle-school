# 第 23 题 · 几何论证（12 分）

> 以**相似三角形**为主角，常与特殊四边形、圆结合。第 1 小题证相似/全等，第 2 小题算比例或证比例中项。**12 分里约 8 分是"写对依据"的分。**

## 三大主题

### 一、圆的基本性质与相似综合

- 垂径定理 → 构造直角三角形、中点、等线段
- 圆周角定理：同弧等角 → 相似（AA）；直径 → 直角
- 切线：垂直半径 → 直角 → 相似；**切割线定理、相交弦定理**（由相似导出乘积式）
- 圆内接四边形：对角互补、外角 = 内对角

### 二、特殊四边形与相似

- 矩形：对角线相等 + 直角 → 勾股
- 菱形：对角线垂直平分且平分内角；面积 = 对角线积一半（等积法常考）
- 正方形：旋转 90° 构造全等（手拉手模型）
- 等腰梯形：平移腰 / 作高 / 延长两腰化三角
- **黄金分割**：$\dfrac{AC}{AB}=\dfrac{\sqrt5+1}{2}$ 型比例计算

### 三、常用证明工具箱

- **平行线分线段成比例**（A 字、8 字）
- 比例中项 / 射影定理：Rt△ 斜边上的高 $CD^2=AD\cdot BD$
- 中点套路：中位线 / 直角三角形斜边中线 / 倍长中线
- 旋转构造全等（等腰、正方形必想旋转）

## 相似模型速查

| 模型 | 识别特征 |
| ---- | ---- |
| A 字型 | 一条平行线截两边 |
| 8 字型 | 两平行线交于一点两侧 |
| 母子型 | 直角三角形斜边上的高 |
| 一线三等角 | 直线上三个相等的角（K 型） |
| 旋转相似 | 共端点的两个相似三角形 |

## 🔥 易错点

- 依据句写不全："两角对应相等"后面还有"的两个三角形相似"。
- 对应顶点顺序写反 → 比例式全错。
- 第 2 问常需"设参"：设未知线段为 x，用比例表示其他线段再列方程。
- 证"比例中项"要写出 $x^2=ab$ 形式的结论句。
