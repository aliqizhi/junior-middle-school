## 特殊角三角比

// sin30°、sin45°、sin60° = ? #card
?
sin30°=1/2，sin45°=√2/2，sin60°=√3/2

// cos30°、cos45°、cos60° = ? #card
?
cos30°=√3/2，cos45°=√2/2，cos60°=1/2

// tan30°、tan45°、tan60° = ? #card
?
tan30°=√3/3，tan45°=1，tan60°=√3

## 方程

// 一元二次方程求根公式 #card
?
$x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$（a≠0，Δ≥0 时有实根）

// 判别式 Δ 的三种情况 #card
?
Δ>0 两个不相等实根；Δ=0 两个相等实根；Δ<0 无实根

// 韦达定理 #card
?
$x_1+x_2=-\dfrac{b}{a}$，$x_1x_2=\dfrac{c}{a}$

// 增长率模型 #card
?
$a(1+x)^2=b$；x 的负解通常舍去

## 函数

// 反比例函数 k 的几何意义 #card
?
图象上任一点向两坐标轴作垂线，围成矩形面积 = |k|

// 一次函数图象平移口诀 #card
?
左加右减（自变量 x），上加下减（常数项/整体）

// 沪教版二次函数顶点式及顶点 #card
?
$y=a(x+m)^2+k$，顶点 $(-m,\ k)$，对称轴 $x=-m$

## 几何

// 直角三角形斜边上的中线性质及逆定理 #card
?
等于斜边的一半；逆定理：一边上的中线等于这边一半 ⟺ 直角三角形

// 三角形中位线定理 #card
?
平行于第三边且等于第三边的一半

// 重心分中线 #card
?
顶点到重心 : 重心到对边中点 = 2 : 1

// 相似三角形面积比与相似比的关系 #card
?
面积比 = 相似比的平方（周长比、对应高/中线/角平分线比 = 相似比）

// 垂径定理及常用勾股关系 #card
?
垂直于弦的直径平分弦、且平分弦所对的两条弧；$r^2=(\frac{弦}{2})^2+弦心距^2$

// 直线与圆位置关系（d 为圆心距，r 为半径） #card
?
d>r 相离；d=r 相切；d<r 相交

// 两圆五种位置关系（R>r） #card
?
外离 d>R+r；外切 d=R+r；相交 R-r<d<R+r；内切 d=R-r；内含 d<R-r

// 扇形弧长与面积公式 #card
?
$l=\dfrac{n\pi R}{180}$；$S=\dfrac{n\pi R^2}{360}=\dfrac{1}{2}lR$

// 黄金分割比 #card
?
较长段/全长 = $\dfrac{\sqrt5-1}{2}\approx0.618$

// 正多边形中心角与内角 #card
?
中心角=360°/n；内角=(n-2)·180°/n

// 中点四边形结论 #card
?
顺次连接任意四边形各边中点得平行四边形；原对角线相等→菱形；垂直→矩形

## 统计与向量

// 方差公式及含义 #card
?
$S^2=\dfrac{1}{n}\sum(x_i-\bar x)^2$，方差越小越稳定

// 向量加法三角形法则与减法 #card
?
$\vec{AB}+\vec{BC}=\vec{AC}$；$\vec{AB}-\vec{AD}=\vec{DB}$

// 解直角三角形十六字口诀 #card
?
有弦用弦，无弦用切；宁乘毋除，取原避中
