## 📌 有理数的概念与分类（5.1）

- **正数与负数**：大于 0 的数是正数（前面可放"＋"号）；在正数前加"−"号的数是负数。用正负数表示**具有相反意义的量**（收入/支出、向东/向西、零上/零下、盈/亏）。
- **0 的特殊地位**：0 既不是正数，也不是负数；它是正数与负数的分界。`非负数` = 正数和 0；`非正数` = 负数和 0。
- **有理数**：整数和分数统称有理数。分类有两种口径，**别混着用**：

| 分类口径 | 类别 | 举例 |
| ---- | ---- | ---- |
| 按"整数 / 分数"分 | 整数：正整数、0、负整数；分数：正分数、负分数 | $-2\in$ 整数，$0.67=\frac{67}{100}\in$ 分数 |
| 按"正 / 零 / 负"分 | 正有理数、0、负有理数 | 有限小数与无限循环小数都算分数 |

> [!warning] 🔥 易错点（概念类）
> - **0 的判断三连**：0 不是正数也不是负数；0 是整数（不是分数）；0 有相反数（是它自己）、有绝对值（是 0）、**没有倒数**。
> - "一个有理数不是正数就是负数"——**错**（还有 0）；"非负数是零和正数的统称"——**对**。
> - 相反意义的量要先**规定哪个为正**：如"向东为正"，则向西 4 千米记作 $-4$ 千米。
> - 带百分号的数（如 $-34\%$）、有限小数（如 $-2.8$）都是**分数**，属于有理数。

## 📏 数轴、相反数与绝对值（5.2 / 5.3）

### 数轴

**规定了原点、正方向和单位长度的直线**叫做数轴——三要素缺一不可。任何一个有理数都可以用数轴上的点表示。

- **大小比较**：数轴上，**右边的点表示的数总比左边的点表示的数大**；正数都大于 0，负数都小于 0，正数大于一切负数。
- 两个负数比较大小时，先看绝对值：==绝对值大的反而小==（如 $\lvert-4\rvert>\lvert-3\rvert$，但 $-4<-3$）。

![数轴上表示数与相反数（5.2 例题情境）](figs/六年级/有理数-q2.png)

### 相反数

- **只有符号不同的两个数**互为相反数；数 $a$ 的相反数是 $-a$；0 的相反数是 0。
- 表示一个数的相反数，也可以在这个数前添加一个"−"号，所以 $-(+3)=-3$、$-(-3)=3$。
- 几何意义：互为相反数的两个数所对应的点**关于原点对称**（到原点距离相等，分居两侧）。
- **$-a$ 不一定是负数**：$a$ 是正数时 $-a$ 是负数；$a$ 是负数时 $-a$ 是正数；$a=0$ 时 $-a=0$。

### 绝对值

**数轴上表示数 $a$ 的点与原点的距离**叫做数 $a$ 的绝对值，记作 $\lvert a\rvert$。

![绝对值=数轴上的点到原点的距离（5.3 情境：小明家到学校 3 个单位，小丽家到学校 5 个单位）](figs/六年级/有理数-q1.png)

| 数的类型 | 绝对值 | 举例 |
| ---- | ---- | ---- |
| 正数 $a>0$ | $\lvert a\rvert=a$（是它本身） | $\lvert3.7\rvert=3.7$ |
| $a=0$ | $\lvert0\rvert=0$ | 绝对值最小的数 |
| 负数 $a<0$ | $\lvert a\rvert=-a$（是它的相反数） | $\lvert-3.9\rvert=3.9$ |

- **互为相反数的两个数绝对值相等**：$\lvert a\rvert=\lvert-a\rvert$。
- 距离意义：数轴上到原点距离等于 $3.5$ 个单位长度的点表示 $\pm3.5$（两个答案，别漏）。

## ➕ 有理数的运算（5.4～5.10）

### 加减法（5.4 / 5.5）

**加法法则**：

| 两数关系 | 和的符号 | 和的绝对值 | 例 |
| ---- | ---- | ---- | ---- |
| 同号（同正/同负） | 取相同的符号 | 绝对值相加 | $(-3)+(-4)=-7$ |
| 异号 | 取绝对值较大的加数的符号 | 用较大的绝对值减去较小的绝对值 | $(-8)+3=-5$ |
| 互为相反数 | — | 和为 0 | $3+(-3)=0$ |
| 与 0 相加 | — | 仍得这个数 | $0+(-3.5)=-3.5$ |

**减法法则**：减去一个数，等于加上这个数的相反数，即 $a-b=a+(-b)$——减法**转化**为加法（化归思想）。

### 乘除法（5.6 / 5.7）

**乘法符号法则**：两数相乘，同号得正，异号得负，并把绝对值相乘；任何数与 0 相乘，积为 0。

| 算式 | 符号 | 例 |
| ---- | ---- | ---- |
| $(+)\times(+)$ | 得正 | $2\times3=6$ |
| $(-)\times(-)$ | 得正 | $(-2)\times(-3)=6$ |
| $(+)\times(-)$、$(-)\times(+)$ | 得负 | $(-4)\times3=-12$ |

- **倒数**：乘积是 1 的两个数互为倒数；$a$ 的倒数是 $\frac1a$（$a\ne0$）；**0 没有倒数**。
- **除法法则**：除以一个数等于乘以这个数的倒数（0 不能作除数）；两数相除，同号得正、异号得负，并把绝对值相除。

### 乘方（5.8）

**求 $n$ 个相同因数 $a$ 的积的运算**叫做乘方，记作 $a^n$：$a$ 叫底数，$n$ 叫指数，乘方的结果叫**幂**。特殊地：$1^n=1$，$0^n=0$（$n$ 为正整数）。

**幂的符号法则**：正数的任何次幂都是正数；**负数的奇数次幂是负数，负数的偶次幂是正数**。

| 底数 | 奇数次幂 | 偶数次幂 |
| ---- | ---- | ---- |
| 正数 | 正 | 正 |
| 负数 | 负 | 正 |

### 混合运算（5.9）

运算顺序：**先乘方，再乘除，后加减**；同级运算从左到右依次进行；有括号先算括号里的（先小括号，再中括号，后大括号）。

### 科学记数法（5.10）

把一个数写成 $a\times10^{n}$ 的形式（其中 $1\le\lvert a\rvert<10$，$n$ 是正整数），叫做科学记数法。负数先提负号，再对绝对值用科学记数法：$-10\,200\,000=-1.02\times10^{7}$；带"万""亿"的先还原成原数：$5107$ 万 $=5.107\times10^{7}$。

> [!warning] 🔥 易错点（运算类）
> - **符号先行**：每一步先定符号、再算绝对值；异号相加取"绝对值较大者"的符号，别取成第一个数的符号。
> - **减号变加号要连符号一起变**：$6-(-6)=6+6=12$；只把减号改加号不改相反数是高频错误。
> - **乘方看清楚底数**：$(-2)^4=16$，而 $-2^4=-16$；$2^3=2\times2\times2=8$，不是 $2\times3$；$2+2+2=2\times3\ne2^3$。
> - **去括号漏变号**：$\dfrac35-\left(\dfrac35-\dfrac14\right)=\dfrac35-\dfrac35+\dfrac14=\dfrac14$——括号前的"−"要变到括号内**每一项**；混合运算先算括号内。
> - **除法转乘法要取倒数**而不是"颠倒分子分母后忘记变运算"：$(-\frac12)\div(-\frac23)=(-\frac12)\times(-\frac32)=\frac34$。
> - **科学记数法的 $a$ 必须在 $[1,10)$**：$600\,000=0.6\times10^{6}$（错，$0.6<1$）、$7\,030\,000=703\times10^{4}$（错，$703\ge10$）都违反条件。
> - **混合运算顺序错**：如 $6\div(2\times3)$ 拆成 $6\div2\times3=9$ 是错的——括号内先算，得 $6\div6=1$。

## 📝 本讲小结

- **概念**：正负数表示相反意义的量；0 特殊（非正非负、无倒数）；有理数 = 整数 + 分数，两种分类口径。
- **三件套**：数轴（三要素、右大左小）、相反数（只有符号不同、关于原点对称）、绝对值（到原点的距离，$\lvert a\rvert\ge0$）。
- **运算**：加法同号相加取同号、异号取大绝对值的符号；减法转化加法；乘除同号得正异号得负、除转乘倒数；乘方负奇负偶；混合运算先乘方再乘除后加减。
- **记数**：科学记数法 $a\times10^n$，$1\le\lvert a\rvert<10$。
- **思想**：数形结合（数轴）、化归（减转加、除转乘）、类比与归纳。

## 📮 例题速递

**1.**（5.4 课后练习 第 4 题，题源：5.4 课后练习 PDF 第 2 页）一家商店一星期七天的盈亏情况如下（盈利为正，亏损为负，单位：元）：

$$-250,\ 1000,\ 1300,\ -200,\ 1800,\ -700,\ 700$$

问：这家商店这星期盈利或亏损多少元？

> [!tip]- 💡 思路导航
> 七天盈亏的**总和**就是这星期的净盈亏——把所有数按顺序相加，正负数分段凑整更快。

> [!success]- ✅ 简解
> $(-250)+1000+1300+(-200)+1800+(-700)+700$
> $=[(-250)+(-200)+(-700)]+[1000+1300+1800+700]=(-1150)+4800=3650$（元）。
> 答：这家商店这星期盈利 3650 元。
> **考点**：多个有理数相加，正负分组凑整（加法交换律、结合律）。

**2.**（本章小结课后练习 第 1 题，题源：有理数复习与小结课后练习 PDF 第 1 页）下列说法中正确的是（　）

- （A）$a$ 的倒数是 $\dfrac1a$
- （B）只有负数的绝对值等于它的相反数
- （C）两数平方后，原来较大的数仍较大
- （D）在数轴上，绝对值越大的数所表示的点离开原点的距离越远

> [!tip]- 💡 思路导航
> 逐项找反例：倒数为 0、绝对值为 0、负数平方变号，各淘汰一个选项。

> [!success]- ✅ 简解
> 选（D）。绝对值的几何意义就是"到原点的距离"，绝对值越大离原点越远。
> - （A）错：$a=0$ 时没有倒数；
> - （B）错：0 的绝对值等于它的相反数（都是 0）；
> - （C）错：$-2<-1$，但 $(-2)^2=4>(-1)^2=1$——负数绝对值大的平方反而大。
> **考点**：倒数、绝对值、乘方三个概念的边界（0 与负数情形）。
