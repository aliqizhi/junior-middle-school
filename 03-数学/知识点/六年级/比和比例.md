# 比和比例（六年级上）

> [!note] 📖 使用导航
> 本文是概要版（初三基础回炉·概念速查）。公式总表：[[03-数学/知识点/00-六至八年级核心公式定理总表]]；同册章节：[[03-数学/知识点/六年级/数的整除]]、[[03-数学/知识点/六年级/分数]]、[[03-数学/知识点/六年级/圆和扇形]]。

> [!note] 中考地位
> **比值思想**贯穿初中：正反比例函数、相似三角形的对应边成比例、三角比本质都是"比"。百分比应用（增长率、打折盈亏、利率）是上海卷应用题与统计图表题的常客；等可能事件是八年级[[03-数学/知识点/八年级/概率初步]]的雏形。

## 📌 比的意义（3.1）

- **定义**：$a$ 和 $b$ 是两个数或两个**同类的量**，为了比较它们，将 $a$ 与 $b$ 相除，叫做 $a$ 与 $b$ 的比，记作 $a:b$ 或 $\dfrac ab$（$b\neq 0$）。$a$ 叫比的**前项**，$b$ 叫比的**后项**。
- **比值**：前项除以后项所得的**商**，即 $a:b=a\div b=\dfrac ab=$ 商。==比值是一个数，没有单位==（通常用整数、分数或小数表示）。
- 求比值时**同类量的单位要先统一**：45 克 ∶ 5 千克 = 45 ∶ 5000 = 9 ∶ 1000，比值为 0.009。

**比、分数、除法三者关系**（沪教版课件对照表）：

| | 记作 | "a" | 中间符号 | "b" | 结果 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 比 | $a:b$ | 前项 | 比号 | 后项 | 比值 |
| 分数 | $\dfrac ab$ | 分子 | 分数线 | 分母 | 分数值 |
| 除法 | $a\div b$ | 被除数 | 除号 | 除数 | 商 |

- **区别**：比是两个量（数）之间的一种**关系**；分数是一个**数值**；除法是一种**运算**。

## 🧮 比的基本性质与化简比（3.2）

- **基本性质**：比的前项和后项同时乘以或除以相同的数（0 除外），比值不变：
  $$a:b=am:bm=\frac an:\frac bn\quad(m\neq0,\ n\neq0,\ b\neq0)$$
- **最简整数比**：前项与后项都是**整数**，且这两个数**互素**。化简比的目标就是它。

| 比的类型 | 化简方法 | 例 |
| ---- | ---- | ---- |
| 整数比 | 前后项同除以最大公因数 | $48:64=3:4$ |
| 小数比 | 先化成整数比再约 | $0.65:1.3=65:130=1:2$ |
| 分数比 | 同乘各分母的最小公倍数 | $\frac65:\frac35=6:3=2:1$ |
| 带分数比 | 先化假分数再化简 | $1\frac15:1\frac35=\frac65:\frac85=3:4$ |
| 带单位比 | **先统一单位** | 1.25 升 ∶ 375 毫升 = 1250∶375 = 10∶3 |

- **化简比 vs 求比值**（最易混的一对）：

| | 化简比 | 求比值 |
| ---- | ---- | ---- |
| 依据 | 比的基本性质 | 比的意义（相除） |
| 结果 | 仍是一个**比**（含比号，如 $3:4$） | 一个**数**（无单位，如 $\frac34$） |

- **连比**：三个量的比（$a:b:c$）。已知两个"接力"的比时，用**中间量的最小公倍数**对齐：如 $a:b=5:8$、$b:c=10:9$，取 8 与 10 的最小公倍数 40，得 $a:b:c=25:40:36$。

## ⚖️ 比例（3.3）

- **比例的意义**：表示**两个比相等**的式子叫做比例，记作 $a:b=c:d$（也可写成 $\dfrac ab=\dfrac cd$）。组成比例的四个数叫比例的项，两端的两项叫**外项**，中间的两项叫**内项**。
- **比例的基本性质**：**两个外项的积等于两个内项的积**。若 $a:b=c:d$，则 $ad=bc$；反之亦然（这是解比例与检验比例的工具）。
- **解比例**：已知比例中的三项求第四项，用"外项积 = 内项积"转化为乘积式再求解。如 $x:4.8=5:2 \Rightarrow 2x=4.8\times5 \Rightarrow x=12$。
- **比例中项**：若 $a:b=b:c$，则 $b$ 叫做 $a$ 和 $c$ 的**比例中项**，此时 $b^2=ac$（六年级在正数范围内讨论，$b$ 取正值）。备课包练习：已知 $a:b=2:3$，$b$ 是 $a$ 和 $c$ 的比例中项，由 $a:b=b:c$ 直接得 $b:c=2:3$。
- 由乘积式写比例式：由 $90\times5=75\times6$，把积相等的两个乘积分别作外项积与内项积，可以写出多个比例式（如 $90:75=6:5$ 等）。
- **比例尺**：图上距离 ∶ 实际距离。1 ∶ 20000 的地图上 12 cm，实际 $12\times20000=240000$ cm $=2.4$ km。

## 📊 百分比的意义与互化（3.4）

- **定义**：把两个数量的比值写成 $\dfrac n{100}$ 的形式，称为**百分数**，也叫做百分比或百分率，记作 $n\%$，读作"百分之 $n$"；符号 "%" 叫百分号。百分数本质是**后项为 100 的比**，用来直观比较、表示部分与整体的关系。
- 百分号前的数可以是小数，也可以大于 100（如 $257.8\%$、$300\%$）。
- **互化三件套**：

| 转化 | 方法 | 例 |
| ---- | ---- | ---- |
| 小数 ⇄ 百分数 | 添 % 小数点**右移两位**；去 % **左移两位** | $0.7=70\%$；$0.52\%=0.0052$ |
| 分数 → 百分数 | 先化小数，再化百分数（分母是 100 的因数时可直接化成分母 100） | $\frac45=0.8=80\%$ |
| 百分数 → 最简分数 | 写成分母 100 再约分 | $37.5\%=\frac{375}{1000}=\frac38$ |

- 本章约定：除法除不尽时，商一般**保留三位小数**（算到第四位再四舍五入），百分号前通常保留一位小数。

## 💰 百分比的应用（3.5）

**常用百分率公式**（备课包归纳）：

| 百分率 | 公式 |
| ---- | ---- |
| 及格率 | 及格人数 ÷ 总人数 × 100% |
| 出勤率 | 实际出勤人数 ÷ 应出勤人数 × 100% |
| 合格率 | 合格产品数 ÷ 产品总数 × 100% |
| 增产率/增长率 | 增长的数 ÷ **原来的基数** × 100% |

- 比"多（少）百分之几"：差 ÷ **单位 1 的量**（作比的后项）。
- **百分点**：增长率从 6% 提高到 7%，说"提高了 1 个百分点"；"提高 1 个百分点"≠"在产值上再增长 1%"。
- **打折**：打八折 = 按原价的 80% 出售；几折就是十分之几。
- **盈利率**：(售价 − 成本) ÷ 成本 × 100%。
- **利息**（单利，教材口径）：
  $$\text{利息}=\text{本金}\times\text{利率}\times\text{期数},\qquad \text{本息和}=\text{本金}+\text{利息}$$
  备课包课件补充口径：利息税 = 利息 × 20%，税后利息 = 利息 × (1−20%)，税后本息和 = 本金 + 税后利息。注意期数与利率匹配（年利率配"年"作期数）。

## 🎲 等可能事件（3.6）

- **等可能事件**：一次试验中，各种结果发生的可能性相等的随机事件（抛硬币、抽签、转等分圆盘等）。
- **可能性大小的计算**：
  $$P=\frac{\text{发生的结果数 }m}{\text{所有等可能的结果数 }n}$$
- 例：一副 52 张扑克（无大小王）任抽一张，抽到黑桃 $P=\dfrac{13}{52}=\dfrac14$；抽到 K 的 $P=\dfrac4{52}=\dfrac1{13}$。
- 圆盘等分成 8 份，指针落在某一格 $P=\dfrac18$；落在"合数区域"（4、6、8 三格）$P=\dfrac38$。

> [!warning] 🔥 易错点（从备课包练习与讲评错型提炼）
> - **化简比 ≠ 求比值**：$6:15$ 化简得 $2:5$，求比值得 $0.4$——一个含比号、一个不含，答题看问的是哪个。
> - 单位不统一就求比：45 克 ∶ 5 千克 不是 45 ∶ 5；1.2 时 ∶ 40 分要先化成 72 ∶ 40。
> - **两个比不能直接"相加"合并**：果汁粉与水 1∶2 和 1∶3 混合，$(1+1):(2+3)=2:5$ 是错的；要按"粉共 2 份、水共 5 份、总量不同杯"折算，正确答案 $7:17$（备课包第 3 题原题错解）。
> - 连比要**借助中间量对齐**，$a:b=5:8$、$b:c=10:9$ 直接写 $5:8:9$ 是错的。
> - 比例中项 $b^2=ac$，求 $b$ 要开平方（六上取正）；解比例内外项位置放错就全错，先用"外项积=内项积"写成乘积式再解。
> - 百分比互化小数点方向：去 % 左移两位、添 % 右移两位，方向搞反整题错。
> - "提高了 1 个百分点"是增长率 +1%，不是产值只多 1%；"先提价 20% 再降价 20%"**回不到原价**（降 4%）。
> - 打八折是按原价的 80%，不是降价 80%；盈利率的分母是**成本**。
> - 等可能事件的分母必须是**所有等可能结果数**：抽"红桃 A"是 1/52，抽"A"是 4/52，抽"红桃"是 13/52——分子跟着事件变。

## 📝 本讲小结

- **比**：相除关系 $a:b$（$b\neq0$）；比值无单位；比、分数、除法一一对应。
- **化简**：目标最简整数比（整数且互素）；小数化整、分数乘分母 LCM、带单位先统一。
- **连比**：中间量取 LCM 对齐三者的份数。
- **比例**：两个比相等的式子；核心性质外项积 = 内项积；比例中项 $b^2=ac$。
- **百分比**：后项为 100 的比；互化靠小数点移位；应用抓公式（增长率、折扣、盈利率、利息）与单位 1。
- **等可能事件**：$P=\dfrac mn$，分子分母都数"结果个数"。
- **思想**：化归（比→除法→分数）、类比（分数性质→比、比例性质）。

## 📮 例题速递

**1.**（比和比例单元复习与小结 课后练习 第 5 题，题源：该课后练习 PDF 第 2 页）现有黑、白、红三种球共 125 个。如果白球个数 ∶ 红球个数 = 5 ∶ 6，红球个数 ∶ 黑球个数 = 4 ∶ 1，那么每种球各有多少个？

> [!tip]- 💡 思路导航
> 两个比在"红球"处接不上（6 对 4）——把红球份数化成 6 与 4 的最小公倍数 12，写出**连比**再按份数分配。

> [!success]- ✅ 简解
> 白 ∶ 红 = 5 ∶ 6 = 10 ∶ 12；红 ∶ 黑 = 4 ∶ 1 = 12 ∶ 3。所以白 ∶ 红 ∶ 黑 = 10 ∶ 12 ∶ 3，总份数 25。
> 白球 $125\times\dfrac{10}{25}=50$（个），红球 $125\times\dfrac{12}{25}=60$（个），黑球 $125\times\dfrac{3}{25}=15$（个）。

**2.**（比和比例单元讲评 课后练习 第 3 题，题源：该课后练习 PDF 第 2 页）一种商品的售价是 220 元，如果先提价 20%，再降价 20%，那么这种商品降价后的价钱是多少？该商品和原来相比较是提价还是降价，或者与原来一样？如果是提价或降价，那么求出提价或降价的百分比。

> [!tip]- 💡 思路导航
> 两次变化的**单位 1 不同**：提价时是 220 元，降价时是提价后的新价。设原价为 1，连乘两次系数即可。

> [!success]- ✅ 简解
> 提价后：$220\times(1+20\%)=264$（元）；降价后：$264\times(1-20\%)=264\times0.8=211.2$（元）。
> $211.2<220$，比原价降了：$(220-211.2)\div220=0.04=4\%$。
> 答：降价后 211.2 元，比原来**降价 4%**。
> **易错**：先 +20% 再 −20% 并不还原——因为第二次的 20% 比"原价的 20%"大（基数 264>220），这是百分比应用最高频的陷阱。
