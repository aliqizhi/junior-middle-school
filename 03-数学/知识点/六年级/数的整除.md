# 数的整除（六年级上）

> [!note] 📖 使用导航
> 本文是概要版（初三基础回炉·概念速查）。公式总表：[[03-数学/知识点/00-六至八年级核心公式定理总表]]；同册章节：[[03-数学/知识点/六年级/分数]]、[[03-数学/知识点/六年级/比和比例]]、[[03-数学/知识点/六年级/圆和扇形]]。

> [!note] 中考地位
> 中考几乎不单独出题，但它是**分数约分通分、因式分解、分式化简**的运算地基；上海卷常以实际情境（裁正方形、发车间隔、分东西）在填空里考**最大公因数/最小公倍数**的选用。

## 📌 整数与整除（1.1）

**整数的分类**（按符号分）：

| 类别 | 举例 | 说明 |
| ---- | ---- | ---- |
| 正整数 | 1，2，3，… | 自然数的一部分 |
| 零 | 0 | 最小的自然数 |
| 负整数 | −1，−2，… | 不属于自然数 |

- **自然数** = 零和正整数；整数包括正整数、零、负整数。
- **整除**（沪教版定义）：整数 $a$ 除以整数 $b$，如果除得的**商是整数而余数为零**，就说 $a$ 能被 $b$ 整除（或者说 $b$ 能整除 $a$）。
- 整除的三要素：**被除数、除数都是整数**（除数 $\neq 0$）、商是整数、余数为 0。

| 算式 | 是否整除 | 理由 |
| ---- | ---- | ---- |
| $24\div 2=12$ | ✓ | 被除数、除数、商都是整数 |
| $6\div 5=1.2$ | ✗ | 商不是整数 |
| $2.6\div 1.3=2$ | ✗ | 被除数、除数不是整数（只是**除尽**） |
| $35\div 6=5\cdots\cdots5$ | ✗ | 余数不为零 |

- 两种表述方向相反："$a$ 能被 $b$ 整除" ⇔ "$b$ 能整除 $a$" ⇔ $b$ 是 $a$ 的**因数**、$a$ 是 $b$ 的**倍数**。

## 🧩 因数和倍数（1.2）

- **定义**：整数 $a$ 能被整数 $b$ 整除，$a$ 就叫做 $b$ 的**倍数**，$b$ 就叫做 $a$ 的**因数**（也叫约数）。
- **相互依存**：因数与倍数是成对出现的，==不能单独说"15 是倍数""3 是因数"==，必须说"15 是 3 的倍数"。
- 找因数：**成对找**（$12=1\times12=2\times6=3\times4$）；找倍数：乘 1、2、3、…

| | 因数 | 倍数 |
| ---- | ---- | ---- |
| 个数 | **有限**个 | **无限**个 |
| 最小 | 1 | 它本身 |
| 最大 | 它本身 | 没有最大 |

- 推论：**一个数的最大因数 = 它的最小倍数 = 它本身**；1 是所有正整数的因数。

## 🔢 能被 2、5 整除的数与奇偶性（1.3）

| 整除对象 | 特征 |
| ---- | ---- |
| 能被 2 整除 | 个位是 0、2、4、6、8（**偶数**） |
| 能被 5 整除 | 个位是 0 或 5 |
| 同时被 2、5 整除 | 个位是 0 |

- **偶数**：能被 2 整除的数；**奇数**：不能被 2 整除的数。相邻的奇数（偶数）相差 **2**。
- 奇偶运算规律：奇 ± 奇 = 偶；偶 ± 偶 = 偶；奇 ± 偶 = 奇；乘法算式中**只要有一个偶数，积就是偶数**。
- 应用原理（备课包"转糖盘"问题）：指针格数（奇或偶）+ 向前数的格数，**奇+奇、偶+偶 都是偶数**，所以永远停在偶数格。

## 🔱 素数、合数与分解素因数（1.4）

**按因数个数给正整数分类**（每个正整数恰好归入一类）：

| 类别 | 因数个数 | 举例 |
| ---- | ---- | ---- |
| 1 | 恰好 1 个 | 1（==既不是素数，也不是合数==） |
| 素数 | 恰好 2 个（1 和本身） | 2，3，5，7，11，… |
| 合数 | 2 个以上 | 4，6，8，9，… |

- **素数**：只有 1 和它本身两个因数；**合数**：除了 1 和本身外还有别的因数。
- 20 以内的素数（**必背**）：2，3，5，7，11，13，17，19。其中 **2 是最小的素数，也是唯一的偶素数**；最小的合数是 4。
- 判断素数：查素数表 / 用 2、3、5、7…去试除。
- **素因数**：既是素数又是某数的因数；**分解素因数**：把一个合数写成几个素数相乘的形式，如 $12=2\times2\times3$。
- 方法：**短除法**（从最小的素因数除起，除到商是素数为止）或"树枝分解"。1 不是素数，不能写进乘积。

## ⚖️ 公因数、最大公因数与互素（1.5）

- **公因数**：几个数公有的因数；其中最大的一个叫**最大公因数**。
- **互素**：公因数只有 1 的两个数。**素数是个数本身的属性，互素是两个数之间的关系**，两者不是一回事。

| 结论 | 对错 | 例 |
| ---- | ---- | ---- |
| 相邻的两个正整数一定互素 | ✓ | 14 和 15 |
| 两个不同的素数一定互素 | ✓ | 3 和 7 |
| 1 和任何正整数一定互素 | ✓ | 1 和 18 |
| 两个合数一定不互素 | ✗ | 8 和 9 互素 |
| 素数和它的倍数互素 | ✗ | 3 和 9 |

- 求最大公因数三法：**列举法**（列因数找最大）、**分解素因数法**（取**公有的**素因数、指数取低的相乘）、**短除法**（除到两个商互素为止，最大公因数 = 所有除数之积）。

## ♾️ 公倍数与最小公倍数（1.6 + 拓展）

- **公倍数**：几个数公有的倍数；其中最小的一个叫**最小公倍数**。公倍数有**无限个，没有最大的**公倍数。
- 求最小公倍数三法：列举法、分解素因数法（公有素因数取一次 × 独有的全部照抄）、短除法。
- **短除法口诀**（两数）：最大公因数 = **只乘除数**；最小公倍数 = **除数 × 最后的商**（一网打尽）。
- 特殊关系速判：

| 两数关系 | 最大公因数 | 最小公倍数 |
| ---- | ---- | ---- |
| 互素（如 7 和 9） | 1 | 两数之积 |
| 倍数关系（如 17 和 68） | 较小数 | 较大数 |

- **三个数的最小公倍数**（拓展专题）：短除时要用**三个数公有的**素因数去除，除到**两两互素**为止；只要其中两个还有公因数就得继续除。
- 应用模型：**同时发车、再次同时出现 → 求最小公倍数**；**裁成同样大小无剩余、最大边长 → 求最大公因数**。

> [!warning] 🔥 易错点（从备课包课后练习错型提炼）
> - **整除的前提是整数**：$7.5\div0.5=15$ 只能叫"除尽"，不是整除（判断题常考）。
> - "能被整除"与"能整除"方向相反：17 和 34，是 34 能被 17 整除，不是 17 能被 34 整除。
> - 1 既不是素数也不是合数；正整数不是只有素数、合数两类——还有 1（"所有正整数不是素数就是合数"是错的）。
> - 分解素因数要**除到全是素数为止**，且 1 不是素因数：$12=2\times2\times3$，不能写 $12=1\times2\times2\times3$。
> - 短除法求最小公倍数时，三个数必须除到**两两互素**（如 12、15、36 还剩公因数 3 时要继续除）；求最大公因数时**别把最后的商也乘进去**。
> - 互素 ≠ 都是素数：8 和 9 互素，但都是合数。
> - 相邻的奇数相差 2 不是 1：三个连续奇数的和是 111 时，中间数是 $111\div3=37$。

## 📝 本讲小结

- **整除**：整数 ÷ 整数（除数≠0），商是整数、余数为 0；表述方向"a 能被 b 整除 ⇔ b 能整除 a"。
- **因数与倍数**：相互依存；因数有限个（最小 1、最大本身），倍数无限个（最小本身）。
- **奇偶**：看个位判 2、5 的整除；奇偶加减"同号得偶、异号得奇"。
- **分类**：正整数 = 1 ∪ 素数 ∪ 合数；20 以内素数必背；2 是唯一的偶素数。
- **分解素因数**：合数 → 素数连乘；工具是短除法。
- **最大公因数**（裁无剩余取最大）与**最小公倍数**（再同时出现取最小）：列举、分解素因数、短除三法；短除结果"除数乘商"分清楚。
- **思想**：分类、短除中的化归，实际问题抽象为 GCD/LCM 模型。

## 📮 例题速递

**1.**（数的整除单元复习与小结 课后练习 第 2 题，题源：该课后练习 PDF 第 1 页）如果 $A=2\times2\times5$，$B=2\times3\times3$，那么 $A$ 和 $B$ 的最小公倍数是＿＿＿＿＿＿＿＿；最大公因数是＿＿＿＿＿＿＿＿。

> [!tip]- 💡 思路导航
> 已给的是分解素因数结果：**公有的素因数**决定最大公因数；最小公倍数 = 公有的取一次 + 各自独有的全部。

> [!success]- ✅ 简解
> 公有素因数只有 2，故最大公因数 $=2$；最小公倍数 $=2\times2\times3\times3\times5=180$。
> **易错**：求最小公倍数时公有素因数只能取一次，别写成 $2\times2\times3\times3\times5$ 之外的重复组合；求最大公因数别把独有的 $5$、$3$ 也乘进去。

**2.**（数的整除单元讲评 课后练习 第 5 题，题源：该课后练习 PDF 第 2 页）这是学校新学期的购货单，由于采购员粗心大意，致使有些部分被墨水遮住，但他记得单价是整数元．你能运用所学知识推算出购买的录音机的单价和总价吗？

| 名称 | 型号 | 数量 | 金额（元） |
| ---- | ---- | ---- | ---- |
| 录音机 | WL-20 | 8 | ¥ 7 5 8 □（□ 处被墨水遮住，角、分为 0） |

> [!tip]- 💡 思路导航
> 单价是整数元 → **总价必须能被 8 整除**；被遮的只有"元位"一个数字，用整除特征逐个试。

> [!success]- ✅ 简解
> 总价形如 $758\square$ 元且能被 8 整除，逐一试验得总价 $=7584$ 元；单价 $=7584\div8=948$（元）。
> **考点**：整除特征的实际应用——"单价整数元"翻译成"总价能被数量整除"。
