# 分数（六年级上）

> [!note] 📖 使用导航
> 本文是概要版（初三基础回炉·运算速查）。公式总表：[[03-数学/知识点/00-六至八年级核心公式定理总表]]；同册章节：[[03-数学/知识点/六年级/数的整除]]、[[03-数学/知识点/六年级/比和比例]]。

> [!note] 中考地位
> 中考不单独考分数，但它是**整式分式运算、比例、解直角三角形中比值计算**的底子；分数四则混合运算的**运算顺序与约分习惯**直接决定初三代数变形的速度与正确率。

## 📌 分数的意义与分数与除法（2.1）

- **分数的意义**：把一个总体（"单位 1"）**平均**分成若干份，表示这样的一份或几份的数。关键在"平均分"，也在于**先说清把谁看作 1**。
- **分数与除法的关系**：两个正整数相除，商可以用分数表示
  $$a \div b=\frac{a}{b}\quad(b\neq 0)$$
  被除数→分子，除号→分数线，除数→分母。
- 分数是一个**数**，除法是一种**运算**——"$\frac{4}{5}$ 米"与"4 米的 $\frac{1}{5}$"在数量上相等，但表述的身份不同（4 米钢管平均截成 5 段：每段长 $\frac45$ 米，每段是全长的 $\frac15$）。
- 带分数 ⇄ 假分数互化：假分数化带分数用除法（商为整数部分，余数为分子）；带分数化假分数：$\text{整数}\times\text{分母}+\text{分子}$ 作分子，分母不变（如 $2\frac79=\frac{25}{9}$，$\frac{37}{5}=7\frac25$）。

## 🧮 分数的基本性质与约分（2.2）

- **基本性质**：分数的分子与分母**同乘以或同除以**一个**不为零**的数，分数的大小不变。（与除法"商不变性质"、比的基本性质同源。）
- **约分**：把分子、分母同除以它们的公因数；约到**分子分母互素**为止，得**最简分数**。
- 填空技巧（如 $\dfrac34=\dfrac{(\ )}{16}$）：先看分母扩大了几倍，分子跟着扩大同样倍数。

## ⚖️ 分数的大小比较与通分（2.3）

| 情形 | 方法 |
| ---- | ---- |
| 同分母 | 分子大的分数大 |
| 同分子 | 分母大的分数反而小 |
| 异分母 | 先**通分**化成同分母，再比分子 |
| 带分数/假分数混合 | 都化成假分数（或先比整数部分）再比 |
| 直观法 | 在数轴上标点，右边的数大 |

- **通分**：把异分母分数分别化成和原来分数相等的**同分母**分数；公分母通常取原来各分母的**最小公倍数**（回炉第一章：短除法求 LCM）。
- 经典结论：介于两个分数之间的最简分数有**无数个**；若限定分母（如"比 $\frac34$ 大比 $\frac56$ 小且分母为 48 的最简分数"），则通分后逐个检验分子与分母是否互素。

## ➕ 分数的加减法（2.4）

| 类型 | 法则 |
| ---- | ---- |
| 同分母 | 分母不变，分子相加减 |
| 异分母 | **先通分**，再按同分母法则加减 |
| 带分数 | 整数部分与分数部分分别相加减，再合并 |

- 结果必须是**最简分数**；结果若是假分数，一般化成带分数或按题目要求保留。

## ✖️ 分数的乘除法（2.5–2.6）

**乘法法则**：分数乘分数，用分子相乘的积作分子，分母相乘的积作分母；**整数与分数相乘**，整数与分子相乘（能整除时也可先"整数÷分母"）。计算前先约分（能约先约）最省力：
$$\frac{p}{q}\times\frac{m}{n}=\frac{p\times m}{q\times n}$$

**倒数**：1 除以一个**不为零**的数所得的商，叫做这个数的倒数；**乘积为 1 的两个数互为倒数**。

| 数 | 倒数 | 说明 |
| ---- | ---- | ---- |
| $\dfrac pq$（$p,q\neq0$） | $\dfrac qp$ | 分子分母颠倒 |
| 整数 $a$（$a\neq0$） | $\dfrac1a$ | 5 的倒数是 $\frac15$ |
| 带分数 $2\frac23$ | $\dfrac38$ | **先化假分数** $\frac83$ 再倒 |
| 0 | 不存在 | ==0 没有倒数== |
| 1 | 1 | 倒数等于它本身的正整数只有 1 |

**除法法则**：甲数除以乙数（乙数不为 0），等于甲数乘乙数的倒数：
$$\frac pq\div\frac mn=\frac pq\times\frac nm$$

## 🔁 分数与小数的互化（2.7）

- 分数化小数：**分子除以分母**。
- **判定能否化成有限小数**：先化成**最简分数**，==分母中除了 2 和 5 以外不含其他素因数，就能化成有限小数==（如 $\frac{7}{8}$、$\frac{17}{40}$ 可以；$\frac{4}{15}$、$\frac{45}{31}$ 不行；$\frac{6}{15}$ 要先约成 $\frac25$ 再判断）。
- 小数化分数：一位小数→十分之几，两位→百分之几……再约分（$0.234=\frac{234}{1000}=\frac{117}{500}$）。

## 🧪 四则混合运算与分数应用（2.8–2.9）

- **运算顺序与整数四则完全相同**：先乘除后加减，有括号先算括号内，同级运算**从左到右**。
- **分数、小数混合**的取舍经验：乘除法中把小数化分数（便于约分）；加减法中若各分数都能化成有限小数，可统一成小数算。
- 常用简算：乘法分配律逆用（$a\times b+a\times c=a\times(b+c)$）、凑整（$26\times(26-\frac1{26})\times0.04$ 型先拆括号）。
- 分数应用三类模型（**找准单位 1** 是一切的前提）：

| 题型 | 数量关系 | 列式 |
| ---- | ---- | ---- |
| 求一个数的几分之几是多少 | 单位 1 的量 × 分率 | 乘法 |
| 求一个数是另一个数的几分之几 | 比较量 ÷ 单位 1 的量 | 除法（写成分数） |
| 已知一个数的几分之几是多少，求这个数 | 比较量 ÷ 分率（或设未知数列方程） | 除法/方程 |

- "余下的几分之几"：单位 1 换成**余下的量**，先算出余下多少再作除数。

> [!warning] 🔥 易错点（从备课包"判断解法对错"题提炼）
> - **除号变乘号的同时，除数必须取倒数**：$\frac38\div\frac34=\frac38\times\frac43$，只翻一半（$\frac38\times\frac34$）或把被除数也翻了都是错的。
> - **同级运算从左到右**：$\frac38\div3\times\frac34$ 只能先算 $\frac38\div3$，不能先算后面的 $3\times\frac34$（备课包思考题里两种错误解法都栽在这里）。
> - **先乘除后加减**：$\frac38+\frac58\times8\neq\Big(\frac38+\frac58\Big)\times8$，前者是 $\frac38+5=5\frac38$，不能先加再乘。
> - 结果必须化**最简分数**；计算前先约分（$\frac{38}{21}\times\frac7{19}$ 先约再乘，一步出 $\frac23$）。
> - 0 没有倒数；"假分数的倒数都是真分数"是错的（假分数 1 的倒数还是 1）。
> - 判断能否化有限小数：**先约成最简**再查分母（$\frac{12}{25}$ 可以，但 $\frac{6}{15}$ 要先约成 $\frac25$ 再判断）。
> - 应用题单位 1 不清就动笔：男生是女生的 $\frac32$，是把**女生**看作 1；"男生比女生多 $\frac12$"也是把**女生**看作 1，别把全班当 1。
> - 求一个数的几分之几用乘法，"求这个数"用除法或方程——方向别反。

## 📝 本讲小结

- **意义**：平均分 + 单位 1；$a\div b=\dfrac ab$（$b\neq0$），分数是数、除法是运算。
- **性质**：分子分母同乘除非零数，大小不变 → 约分（最简分数：分子分母互素）与通分（公分母取 LCM）。
- **比较**：同分母比分子，异分母先通分；介于两分数间的最简分数无限个。
- **运算**：加减先通分；乘法分子乘分子；除法 = 乘倒数；混合运算顺序同整数。
- **互化**：最简分数分母只含素因数 2、5 ⇔ 能化有限小数；小数化分数按位写再约分。
- **应用**：单位 1 定方向——"求几分之几"乘，"求这个数"除。
- **思想**：类比（分数→分式）、化归（异分母→同分母、除法→乘法）。

## 📮 例题速递

**1.**（分数单元讲评 课后练习 第 2 题，题源：该课后练习 PDF 第 1 页）若 $\dfrac34<x<\dfrac56$，且 $x$ 是分母为 48 的最简分数，则 $x=$＿＿＿＿＿＿＿＿。

> [!tip]- 💡 思路导航
> 先把两个端点**通分成以 48 为分母**，再看夹在中间的、与 48 互素的分子有哪几个。

> [!success]- ✅ 简解
> $\dfrac34=\dfrac{36}{48}$，$\dfrac56=\dfrac{40}{48}$，故 $x$ 的分子只能是 37、38、39；其中 $\dfrac{38}{48}=\dfrac{19}{24}$、$\dfrac{39}{48}=\dfrac{13}{16}$ 都要约分（分母不再是 48），只有 $\dfrac{37}{48}$ 与 48 互素。所以 $x=\dfrac{37}{48}$。
> **考点**：通分 + 最简分数判定（分子分母互素）两章知识的串联。

**2.**（分数单元讲评 课后练习 第 6 题，题源：该课后练习 PDF 第 3 页）古希腊数学家丢番图的墓碑上写着：他生命的六分之一是幸福的童年，再活了他生命的十二分之一，两颊长起了细细的胡须，他结了婚，又度过了一生的七分之一；再过五年，他有了儿子，感到很幸福，可是儿子只活了他父亲全部生命的一半；儿子死后，他又在极度的悲伤中度过了四年，也与世长辞了。请根据这段话推算出丢番图活了多少岁？

> [!tip]- 💡 思路导航
> 把"他的一生"设为 $x$ 岁，各段都是 $x$ 的几分之几，按时间顺序**分段相加恰等于一生**，列一元一次方程。

> [!success]- ✅ 简解
> 设丢番图活了 $x$ 岁，据题意得
> $$\frac16x+\frac1{12}x+\frac17x+5+\frac12x+4=x$$
> 通分合并：$\Big(1-\dfrac{14+7+12+42}{84}\Big)x=9$，即 $\dfrac{9}{84}x=9$，解得 $x=84$。
> 答：丢番图活了 84 岁。
> **考点**：异分母分数加减（通分到 84）+ 方程思想；单位 1 全程是"一生的岁数"。
