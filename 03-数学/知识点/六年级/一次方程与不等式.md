# 一次方程与不等式（六年级下）

> [!note] 📖 使用导航
> 本文是概要版（初三基础回炉·考前速查）。公式总表：[[03-数学/知识点/00-六至八年级核心公式定理总表]]；同册章节：[[03-数学/知识点/六年级/有理数]]、[[03-数学/知识点/六年级/线段与角的画法]]、[[03-数学/知识点/六年级/长方体的再认识]]。

> [!note] 中考地位
> **消元与化归思想的起点**：一元一次方程是七年级代数方程、九年级二次方程的底座；一元一次不等式（组）直接服务八年级一次函数取值范围与九年级方案决策题。解方程的"移项变号"、解不等式的"乘除负数变号"是全初中代数变形的高频失分点。

## 📌 方程与方程的解（6.1 / 6.2）

- **方程**：含有未知数的等式。不含未知数的等式（如 $1+100=99$）和不等式（如 $x+1<0$）都不是方程。
- **列方程**：先找**等量关系**，再设未知数、把关系翻译成方程。例："苹果是香蕉的 3 倍，共 152 千克"→ 设香蕉 $x$ 千克，得 $x+3x=152$。
- **方程的解**：使方程左右两边相等的未知数的值。**检验方法**：把值代入方程，看左右两边是否相等。
- **列方程解应用题五步**（6.4 课件）：**审**（审清题意）→ **设**（设未知数，相关的量用代数式表示）→ **列**（根据等量关系列方程）→ **解**（解方程）→ **答**（检验作答）。常用等量关系：`路程=速度×时间`、`工作总量=工作效率×工作时间`。

## ⚖️ 等式性质与一元一次方程（6.3）

### 等式的两条性质

| 性质 | 内容 |
| ---- | ---- |
| 等式性质 1 | 两边同时**加上（或减去）**同一个数或同一个含字母的式子，仍是等式 |
| 等式性质 2 | 两边同时**乘以**同一个数（或**除以**同一个不为零的数），仍是等式 |

### 一元一次方程与解法

**一元一次方程**：只含**一个**未知数，且含未知数的项的次数都是**一次**的方程。判别看三点：一个未知数、未知数的指数为 1、分母中不含未知数（如 $\frac12x-6=0$ 是，$\frac12x^2-6=0$ 不是）。

**移项**：把方程中的某些项**改变符号**后，从方程的一边移到另一边（依据是等式性质 1）。

**解一元一次方程的一般步骤**：

1. **去分母**（两边同乘各分母的最小公倍数）；
2. **去括号**；
3. **移项**（过"="变号）；
4. **合并同类项**；
5. **未知数的系数化为 1**（两边同除以系数）。

解完把解代回原方程检验。

## 🔀 二元、三元一次方程组（6.8～6.11）

- **二元一次方程**：含有两个未知数，且含未知数的项的次数都是一次。它的解有**无数个**（解的全体叫解集），常按要求求**正整数解**等特殊解，如 $x+4y=16$ 的正整数解有 $(12,1),(8,2),(4,3)$。
- **二元一次方程组**：方程组中含**两个未知数**，且含未知数的项的次数都是一次。辨析要点：方程组里每个方程都看（含 $z$ 的不是、含 $xy$ 项的不是、指数为 2 的不是）。
- **方程组的解**：能使每个方程左右两边都相等的一组未知数的值，写成 $\begin{cases}x=\cdots\\y=\cdots\end{cases}$——是**一对数**。
- **解法（消元思想）**：

| 方法 | 适用 | 操作 |
| ---- | ---- | ---- |
| 代入消元法 | 某方程中一个未知数可用含另一未知数的式子表示（如 $y=3x$） | 把式子代入另一个方程，化为一元 |
| 加减消元法 | 两方程中同一未知数的系数相同或互为相反数 | 两方程相加减，消去一个未知数 |

- **三元一次方程组**：含三个未知数、次数都是一次。解法路径：==消元：三元→二元→一元==，先消去系数最简单的未知数。

## 🚫 不等式及其性质（6.5）

**不等式**：用不等号（$<$、$>$、$\le$、$\ge$）表示不等量关系的式子。翻译口径："大于或等于"记 $\ge$；"不小于"即 $\ge$、"不大于"即 $\le$；"非负数"即 $\ge 0$。

| 性质 | 内容 | 与等式性质对比 |
| ---- | ---- | ---- |
| 不等式性质 1 | 两边同时加上（或减去）同一个数，**不等号方向不变** | 类似等式性质 1 |
| 不等式性质 2 | 两边同乘（除以）同一个**正数**，方向不变 | 等式性质 2 拆开 |
| 不等式性质 3 | 两边同乘（除以）同一个**负数**，==不等号方向必须改变== | 等式没有对应物 |

巧记口诀（6.5 课件）：加减都用性质 1，方向不改变；乘除正数性质 2，方向还不变；**乘除负数性质 3，方向必改变**。

## 📉 一元一次不等式（组）的解法（6.6 / 6.7）

- **不等式的解**：能使不等式成立的未知数的值；**解集**：解的全体——一般有**无数个**（对比：一元一次方程的解一般只有一个）。
- **解法**：与解一元一次方程步骤相同（去分母→去括号→移项→合并→系数化为 1），唯一区别：**系数化为 1 时两边同除以负数，不等号要改方向**。
- **解集的数轴表示**：大于向右画、小于向左画；**含等号（$\le,\ge$）画实心点，不含等号（$<,>$）画空心圈**。

![不等式解集在数轴上的表示：上为 $x<4$（空心圈、向左），下为 $x\ge-5$（实心点、向右）](figs/六年级/一次方程与不等式-q1.png)

- **一元一次不等式组**：几个含同一个未知数的一元一次不等式合在一起；解集是各不等式解集的**公共部分**，借助数轴确定。设 $a>b$，四种基本型：

| 不等式组 | 解集 | 口诀 |
| ---- | ---- | ---- |
| $x>a$ 且 $x>b$ | $x>a$ | 同大取大 |
| $x<a$ 且 $x<b$ | $x<b$ | 同小取小 |
| $x<a$ 且 $x>b$ | $b<x<a$ | 大小小大中间找 |
| $x>a$ 且 $x<b$ | 无解 | 大大小小无解了 |

### 方程 vs 不等式 对照表

| 项目 | 一元一次方程 | 一元一次不等式 |
| ---- | ---- | ---- |
| 定义 | 一个未知数、次数一次的**等式** | 一个未知数、次数一次、含**不等号** |
| 变形依据 | 等式性质 1、2 | 不等式性质 1、2、3 |
| 解的个数 | 一般一个 | 一般无数个（解集） |
| 移项 | 变号 | 变号 |
| 系数化为 1 | 除以系数即可 | 除以**负数要变号** |
| 结果表示 | $x=2$ | $x<2$，并在数轴上表示 |

> [!warning] 🔥 易错点
> - **移项忘变号**：由 $5x=4x+8$ 移项应得 $5x-4x=8$，写成 $5x+4x=8$ 就错（6.3 辨一辨原题）。
> - **去分母漏乘**：分母去掉后，**不含分母的项也要乘**最小公倍数，如 $\frac{x}{2}-1=3$ 两边乘 2 得 $x-2=6$，漏乘得 $x-1=6$ 是典型错误。
> - **除以负数忘变号**：$-3x\le12$ 的解集是 $x\ge-4$（方向改），写成 $x\le-4$ 全错。
> - **数轴表示**：$x<4$ 用空心圈、$x\le4$ 用实心点；方向别画反（大向右）。
> - **"乘除后方向"的陷阱判断**：$2a$ 不一定大于 $a$——$a\le0$ 时不成立；同理 $-3a>-3b\ \Rightarrow\ a<b$。
> - **二元一次方程组的解是一对数**，代回**每一个**方程都要成立；"整式含 $xy$ 项"或"三元"的方程组不是二元一次方程组。
> - 应用题最后**必须检验**（是否符合题意/实际意义），并写"答"。

## 📝 本讲小结

- **方程主线**：方程 → 方程的解（检验）→ 一元一次方程（一元、一次）→ 五步解法（去分母、去括号、移项、合并、系数化 1）→ 应用题五步（审设列解答）。
- **方程组主线**：二元一次方程（无数解）→ 方程组（解是一对数）→ 消元（代入、加减）→ 三元化二元化一元。
- **不等式主线**：性质 1/2/3 → 解法同方程、除负数变号 → 解集数轴表示（实心/空心、向左/向右）→ 不等式组取公共部分（四大口诀）。
- **思想**：化归（消元、减转加）、类比（方程 vs 不等式）、数形结合（数轴定解集）。

## 📮 例题速递

**1.**（6.6 课后练习 第 5 题·补充选做，题源：6.6 课后练习 PDF 第 2 页）小杰代表班级参加学校组织的知识竞赛，竞赛题是 50 道选择题，答对一题得 2 分，答错或不答扣 1 分，问小杰至少要答对多少道，才能保证最后得分不少于 85 分？

> [!tip]- 💡 思路导航
> 设答对 $x$ 道，则答错或不答 $(50-x)$ 道；"不少于"即 $\ge$，列不等式解之。

> [!success]- ✅ 简解
> 设小杰至少要答对 $x$ 道。根据题意，得 $2x+(50-x)\times(-1)\ge85$，化简得 $2x-50+x\ge85$，$3x\ge135$，解得 $x\ge45$。
> 答：小杰至少要答对 45 道。
> **考点**：得分型不等式应用题；"至少/不少于"对应 $\ge$，解集取满足条件的最小整数值。

**2.**（6.7 课后练习 第 5 题·补充选做，题源：6.7 课后练习 PDF 第 2 页）若不等式组 $\begin{cases}x-a>2,\\ b-2x>0\end{cases}$ 的解集是 $-1<x<1$，求 $(a+b)^{2020}$ 的值。

> [!tip]- 💡 思路导航
> 先用含 $a$、$b$ 的式子写出两个解集，再与 $-1<x<1$ 逐个"对端点"——逆用不等式组解集的确定方法。

> [!success]- ✅ 简解
> 由 $x-a>2$ 得 $x>a+2$；由 $b-2x>0$ 得 $x<\dfrac b2$。故解集为 $a+2<x<\dfrac b2$。
> 与 $-1<x<1$ 对照得 $a+2=-1$，$\dfrac b2=1$，即 $a=-3$，$b=2$。
> 所以 $(a+b)^{2020}=(-1)^{2020}=1$（负数的偶次幂为正——衔接 [[03-数学/知识点/六年级/有理数]]）。
> **考点**：含参不等式组逆求参数；对照端点时注意两个不等号是否含等号。
