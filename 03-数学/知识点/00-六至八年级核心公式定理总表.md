# 六至八年级核心公式定理总表

> 一轮复习的"总检查表"：逐项自评（会 ✓ / 模糊 ？/ 不会 ✗），✗ 的项回教材补笔记并加入闪卡。

## 一、数与式（六~七年级）

- **因式分解**：提公因式 $ab+ac=a(b+c)$；平方差 $a^2-b^2=(a+b)(a-b)$；完全平方 $a^2\pm2ab+b^2=(a\pm b)^2$；**十字相乘** $x^2+(p+q)x+pq=(x+p)(x+q)$（上海常考，别忘！）
- **幂运算**：$a^m\cdot a^n=a^{m+n}$；$(a^m)^n=a^{mn}$；$(ab)^n=a^nb^n$；$a^m\div a^n=a^{m-n}$；$a^{-n}=\dfrac{1}{a^n}$（$a\neq0$）；$a^0=1$（$a\neq0$）
- **科学记数法**：$a\times10^n$，$1\le |a|<10$
- **分式**：异分母先通分；**分式方程必验根**
- **二次根式**：最简二次根式两个条件（被开方数不含分母、不含能开尽方的因式）；分母有理化
- **实数**：无理数识别（π、开不尽方的根号数）；绝对值非负；相反数/倒数

## 二、方程与不等式（六~八年级）

- **一元一次不等式（组）**：数轴找公共部分；**两边乘除负数要变号**
- **一元二次方程**：求根公式 $x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$；判别式 $\Delta=b^2-4ac$（>0 两不等实根 / =0 两相等 / <0 无实根）；根与系数关系（韦达定理）$x_1+x_2=-\dfrac{b}{a},\ x_1x_2=\dfrac{c}{a}$
- **分式方程**：换元或去分母 → **验根**（增根使最简公分母=0）
- **无理方程**：平方有理化 → **验根**（增根使被开方数<0）
- **二元二次方程组**：因式分解降次（如 $x^2-5xy-6y^2=(x-6y)(x+y)=0$）
- **应用题模型**：增长率 $a(1+x)^2=b$；利润 = (售价-成本)×销量

## 三、函数（八下 + 九上）

- **一次函数** $y=kx+b$（$k\neq0$）：k 定增减，b 定交点；两直线平行 ⟺ $k_1=k_2$
- **正比例函数** $y=kx$：过原点
- **反比例函数** $y=\dfrac{k}{x}$：双曲线；k>0 在一三象限；**k 的几何意义：矩形面积 |k|**
- **二次函数**：见 [[03-数学/知识点/九年级/二次函数]]
- **平面直角坐标系**：两点间距离 $d=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$；平移与轴对称的坐标规律
- **函数应用**：实际问题的定义域（几何约束/实际意义）

## 四、几何（六~八年级）

### 三角形

- 内角和 180°；外角 = 不相邻两内角和；三边关系
- **全等判定**：SAS、ASA、AAS、SSS、HL（直角三角形）
- **等腰**：三线合一；等边三角形三线均合一
- **直角三角形**：勾股定理 $a^2+b^2=c^2$；斜边上的中线 = 斜边一半（及其逆定理：一边中线等于该边一半 ⟺ 直角三角形）；30° 角所对直角边 = 斜边一半
- **中位线**：平行于第三边且等于其一半
- **重心**：分中线为 2:1（自顶点起）

### 四边形（八下第 23 章）

- 平行四边形：对边平行且相等、对角相等、**对角线互相平分**；判定五法
- 矩形：+ 四个直角、对角线相等；菱形：+ 四边相等、对角线互相垂直平分且平分内角、面积 = 对角线乘积一半
- 正方形：兼具两者；梯形：平移腰/作高/延长两腰转化
- **中点四边形**：顺次连接任意四边形各边中点 → 平行四边形；原对角线相等 → 菱形；原对角线垂直 → 矩形

### 图形运动

- 平移：对应点连线平行且相等；轴对称：折痕垂直平分对应点连线；旋转：对应点到中心等距、旋转角相等

## 五、统计与概率

- 平均数 $\bar{x}=\dfrac{x_1+\cdots+x_n}{n}$；中位数（排序取中）；众数；方差越小越稳定 $S^2=\dfrac{1}{n}\sum(x_i-\bar{x})^2$
- 统计图选择：条形比数量、折线看趋势、扇形看占比（圆心角 = 百分比×360°）
- 频数分布直方图：求总数/频率/中位数所在组
- 概率 $P=\dfrac{m}{n}$（等可能）；树状图/列表法；**放回与不放回**
- 用样本估计总体：样本比例 × 总数

## 六、平面向量（八下 + 九上）

- 加法三角形法则 $\vec{AB}+\vec{BC}=\vec{AC}$；减法 $\vec{AB}-\vec{AD}=\vec{DB}$；平行四边形法则
- 共线：$\vec{AB}=\lambda\vec{AC}$；基底分解（选两个不共线向量表示目标向量）
