# 分式（七年级上）

> [!note] 📖 使用导航
> 本文是概要版（初三基础回炉·考前速查）。公式总表：[[03-数学/知识点/00-六至八年级核心公式定理总表]]；同册章节：[[03-数学/知识点/七年级/整式]]。

> [!note] 中考地位
> 上海中考计算题与"先化简再求值"的常客，列分式方程解应用题也屡屡出现。**分母不为零**与**分式方程验根**是选择填空的经典小题。整套运算的地基是**因式分解**（提公因式、平方差、完全平方、十字相乘）。

## 📌 分式的意义（10.1）

- **分式**：两个整式 $A$、$B$ 相除，可写成 $\dfrac{A}{B}$；如果**除式 $B$ 中含有字母**，那么式子 $\dfrac{A}{B}$ 叫做分式。（整式除整式：除式不含字母的仍是整式，如 $\dfrac{xy}{3}$、$x^2-2y$。）
- 判别只看一个地方：**分母里有没有字母**。$\dfrac{x+2}{\pi}$ 的分母是常数 $\pi$，不是分式。
- 三种条件（核心三问）：

| 问题 | 条件 |
| ---- | ---- |
| 分式有意义 | 分母 $B\ne 0$ |
| 分式无意义 | 分母 $B= 0$ |
| 分式的值为零 | 分子 $A=0$ **且** 分母 $B\ne 0$（两条同时满足） |

- 例（10.1 例题 4）：$\dfrac{2x+1}{3x-1}$ 的值为零 $\iff x=-\dfrac12$ 且 $3\times\big(-\dfrac12\big)-1\ne0$，即 $x=-\dfrac12$。

> [!warning] 意义易错
> - "值为零"别只令分子为零：还要回代检验分母 $\ne0$，分子为零与分母非零**缺一不可**。
> - 有意义的范围是"分母不为零"，不是"分母大于零"：$\dfrac{x^2+1}{2x}$ 有意义只需 $x\ne0$。
> - $\pi$ 是数不是字母；分母含 $\pi$、含具体数字都照常是整式。

## ⚖️ 分式的基本性质与约分（10.2）

- **分式的基本性质**：分式的分子与分母都乘以（或除以）同一个**不等于零**的整式，分式的值不变。

  $$\frac{A}{B}=\frac{A\cdot C}{B\cdot C}=\frac{A\div C}{B\div C}\quad(C\ne0,\ B\ne0)$$

  这是分数基本性质的类比推广，是约分、通分的依据。
- **约分**：把分式分子与分母中的**公因式**约去；先**因式分解**，再约公因式。
- **最简分式**：分子与分母没有公因式（1 除外）的分式。**分式运算的结果都要化成最简分式**。
- 符号处理：分子、分母与分式本身的符号，**改变其中任意两个，分式的值不变**，如 $\dfrac{-a}{b}=\dfrac{a}{-b}=-\dfrac{a}{b}$。

化简示例（10.2 例题）：

$$\frac{x-2}{x^2-4x+4}=\frac{x-2}{(x-2)^2}=\frac1{x-2},\qquad \frac{15b-5a}{2a-6b}=\frac{5(3b-a)}{2(a-3b)}=-\frac52$$

> [!warning] 约分易错（10.2 辨析题原题）
> - $\dfrac{x^6}{x^2}=x^4$，不是 $x^3$——约分是除法，指数相减。
> - $\dfrac{x^2-y^2}{x+y}$ **能**约：先分解成 $\dfrac{(x+y)(x-y)}{x+y}=x-y$，说"不能约"是没先分解。
> - $\dfrac{x+m}{y+m}\ne\dfrac{x}{y}$——"+"连着的项不是公因式，加号不能约。
> - $\dfrac{4x^2(y-1)}{x(1-y)}$：注意 $y-1$ 与 $1-y$ 互为相反数，约分后带负号。

## 🔢 分式的乘除（10.3）

| 运算 | 法则 |
| ---- | ---- |
| 乘法 | 分子乘分子、分母乘分母：$\dfrac{A}{B}\cdot\dfrac{C}{D}=\dfrac{AC}{BD}$ |
| 除法 | 除以一个分式等于乘以它的**倒数**：$\dfrac{A}{B}\div\dfrac{C}{D}=\dfrac{A}{B}\cdot\dfrac{D}{C}$ |
| 乘方 | 分子分母各自乘方：$\Big(\dfrac{b}{a}\Big)^n=\dfrac{b^n}{a^n}$ |

- 运算空门：**先因式分解、能约分的先约分**，再相乘，最后结果化最简分式。

  $$\frac{x^2-1}{x^2}\div\frac{x+1}{x}=\frac{(x+1)(x-1)}{x^2}\cdot\frac{x}{x+1}=\frac{x-1}{x}$$

  遇到 $x^2-9$、$a^2-2ab+b^2$ 这类式子，一律先分解因式再约；分子分母出现 $2b-a$ 与 $2a-b$ 这类相反数时，先把符号统一再约分。

> [!warning] 乘除易错
> - 除法**必须颠倒相乘**，不能直接约分；连续乘除按**从左到右**顺序，别把"除号后面两因式"先乘起来（单元复习的典型错例：$\dfrac{x^2-y^2}{x}\div(x-y)^2\cdot\dfrac1x$ 先算了 $(x-y)^2\cdot\dfrac1x$ 就错位了）。
> - 负号处理：$(2b-a)=-(2a-b)$，奇次幂取负、偶次幂不变。
> - 乘方再乘除：$\Big(\dfrac{b}{a}\Big)^2=\dfrac{b^2}{a^2}$，别写成"分子分母都不动"。

## ➕ 分式的加减（10.4）

| 类型 | 法则 |
| ---- | ---- |
| 同分母 | 分母不变，分子相加减：$\dfrac{A}{C}\pm\dfrac{B}{C}=\dfrac{A\pm B}{C}$（$C\ne0$） |
| 异分母 | 先**通分**变成同分母，再按同分母相加减 |

- **通分**：把异分母分式化成同分母分式，公分母取**最简公分母**——各分母系数的最小公倍数 × 所有字母（因式）的最高次幂。
- 分母互为相反数先化同（10.4 课后练习 1(4) 型）：$\dfrac{x+y}{x-y}+\dfrac{x-2y}{y-x}$ 中把 $y-x$ 化为 $-(x-y)$，先统一分母再加减。

  例（10.4 例题 1）：$\dfrac{2}{x^2-4}+\dfrac{x}{4-x^2}=\dfrac{2}{(x+2)(x-2)}-\dfrac{x}{(x+2)(x-2)}=\dfrac{2-x}{(x+2)(x-2)}$，再分解分子判断能否约分。

> [!warning] 加减易错
> - 分子相减时**整个分子要加括号**：$\dfrac{3x+1}{x^2-1}-\dfrac{x+2}{x^2-1}$ 的分子是 $(3x+1)-(x+2)$，直接写 $3x+1-x+2$ 就错了。
> - 结果要**化成最简分式**（分子分母分解到底，约净公因式）。
> - 通分是乘"最简公分母"，别把每个分母连乘起来（公分母取最高次幂，不是全乘）。

## 🧩 可以化成一元一次方程的分式方程（10.5）

- **分式方程**：分母中**含有未知数**的方程；分母不含未知数的（一元一次方程等）叫整式方程。
- **解法思想**：去分母（两边同乘最简公分母）→ 化为**一元一次方程（整式化）**→ 解整式方程 → ==验根==。

| 步骤 | 操作 | 注意 |
| ---- | ---- | ---- |
| ① 去分母 | 两边同乘**最简公分母** | 常数项也要乘；含相反数的分母先统一符号 |
| ② 解整式方程 | 移项、合并、系数化 1 | 一元方程的解也叫方程的**根** |
| ③ 验根 | 把根代入**最简公分母** | 公分母 $=0$ 的是**增根**，舍去；$\ne0$ 才是原方程的根 |

- **增根的来源**：去分母这一步把"分母 $\ne0$"的限制丢掉了，可能产生使原方程分母为零的根。

  例（10.5 例题 2 型）：解 $\dfrac{x}{x-1}+1=\dfrac{1}{x-1}$，去分母得 $x+(x-1)=1$，解得 $x=1$；代回最简公分母 $x-1=0$，是增根，舍去——**原方程无解**。
- 应用题模式（行程/工程/浓度）：设未知数 → 找等量关系（时间 $=$ 路程 $\div$ 速度、工作量、浓度）→ 列分式方程 → 解并验根 → 答句。

## ⚡ 整数指数幂及其运算（10.6）

- **负整数指数幂**：$a^{-p}=\dfrac{1}{a^p}$（$a\ne0$，$p$ 是正整数）。它是"同底数幂相除 $a^m\div a^n=a^{m-n}$ 在 $m<n$ 时仍成立"的**规定**，由此整式（正整数幂）与分式在形式上**统一**了。
- 指数范围扩充后（$a\ne0$）：
  - $a^m\cdot a^n=a^{m+n}$、$(ab)^m=a^mb^m$、$(a^m)^n=a^{mn}$ 对**整数**指数幂仍成立；
  - $a^m\div a^n=a^{m-n}$ 也适用（负指数已把"除"收编），所以不再单列除法法则。
- **科学记数法**：绝对值小于 1 的正数可写成 $a\times10^{-n}$（$1\le a<10$，$n$ 为正整数），如 $0.0009=9\times10^{-4}$。

> [!warning] 🔥 幂与方程易错
> - $2^{-3}=\dfrac18$，不是 $-8$；$10^0=1$ 而不是 $0$。
> - 底数是分数、负数先辨符号：$\Big(-\dfrac12\Big)^{-2}=4$。
> - 解分式方程**忘验根**是最大丢分点；验根代的是最简公分母，不是代回原方程看"像不像"。
> - 分母出现 $1-2x$ 与 $2x-1$：先统一成 $-(2x-1)$，符号错则全错。

## 📝 本讲小结

- **概念**：分母含字母的式子 $\dfrac AB$；有意义 $\iff B\ne0$；值为零 $\iff A=0$ 且 $B\ne0$。
- **变形**：基本性质（同乘除非零整式）支撑约分与通分；结果一律化最简分式。
- **运算**：乘除先分解因式再约分，除法颠倒相乘；加减先通分（最简公分母），分子相加减要整体加括号。
- **方程**：去分母整式化 → 解一元一次方程 → **验根**（增根舍去）。
- **幂**：$a^{-p}=\dfrac1{a^p}$、$a^0=1$（$a\ne0$）；正整数指数幂的性质推广到整数指数；科学记数法表示绝对值小于 1 的数。
- **思想**：类比分数、化归（分式→整式）、从特殊到一般。

## 📮 例题速递

**1.**（10.5 课后练习 第 3(3) 题，题源：10.5 课后练习 PDF 第 2 页）解方程：$\dfrac{5}{2x-1}+\dfrac{3}{1-2x}=2$。

> [!tip]- 💡 思路导航
> 两个分母 $2x-1$ 与 $1-2x$ 互为相反数，最简公分母取 $2x-1$：$3/(1-2x)=-3/(2x-1)$，先统一符号再合并。

> [!success]- ✅ 简解
> 原方程即 $\dfrac{5}{2x-1}-\dfrac{3}{2x-1}=2$，合并得 $\dfrac{2}{2x-1}=2$，所以 $2x-1=1$，$x=1$。
> **验根**：$2\times1-1=1\ne0$，故 $x=1$ 是原方程的根。（课后练习答案：$x=1$。）

**2.**（10.5 课后练习 第 4 题，题源：10.5 课后练习 PDF 第 2 页）通信员要从营地前往相距 2400 米的哨所去送信，然后立即按原路返回，这样从出发到回到营地共花了 40 分钟。若通信员送信时的速度是回来时的速度的 1.5 倍，求他去送信时的速度。

> [!tip]- 💡 思路导航
> 等量关系是"去的时间 + 回的时间 = 40 分钟"，时间 $=$ 路程 $\div$ 速度；设**回来**的速度为 $x$，则去程速度为 $1.5x$，去程时间分母带 $1.5x$。

> [!success]- ✅ 简解
> 设通信员回来时的速度为 $x$ 米/分，则送信（去程）速度为 $1.5x$ 米/分。由题意得
> $\dfrac{2400}{1.5x}+\dfrac{2400}{x}=40$，即 $\dfrac{1600}{x}+\dfrac{2400}{x}=40$，所以 $\dfrac{4000}{x}=40$，$x=100$。
> **验根**：$x=100$ 时分母不为零，是原方程的根。故送信时的速度为 $1.5\times100=150$ 米/分。（课后练习答案：150 米/分。）
