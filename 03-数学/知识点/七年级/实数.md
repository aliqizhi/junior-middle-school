# 实数（七年级下）

> [!note] 📖 使用导航
> 本文是概要版（初三基础回炉·考前速查）；第一次学或没学懂 → 详细版：[[03-数学/知识点详解/七年级/实数]]。公式总表：[[03-数学/知识点/00-六至八年级核心公式定理总表]]；同册章节：[[03-数学/知识点/七年级/相交线与平行线]]、[[03-数学/知识点/七年级/三角形]]、[[03-数学/知识点/七年级/平面直角坐标系]]。

> [!note] 中考地位
> 上海中考计算题的"地基"：所有含根号的化简、求值，以及八年级二次根式的系统运算，都建立在**平方根、立方根、实数分类**这套概念上。无理数的辨析（判断题）是经典送分/丢分小题。

## 📌 实数的概念与分类（12.1）

- **有理数**：可统一写成 $\dfrac{q}{p}$ 的数（$p$、$q$ 均为整数，$p\ne 0$，$p$ 与 $q$ 互素），即**整数与分数**；小数形态表现为**有限小数或无限循环小数**。
- **无理数**：==无限不循环小数称为无理数==。教材通过"面积为 2 的正方形边长"探究并论证 $\sqrt2$ 不是有理数（希帕斯发现，第一次数学危机）。
- **实数**：有理数与无理数**统称**实数。

| 分类角度 | 类别 | 举例 |
| ---- | ---- | ---- |
| 按定义 | 有理数（整数、分数：有限小数或无限循环小数） | $-3,\ 0,\ \dfrac{22}{7},\ 3.14159,\ 0.\dot{2}\dot{3}$ |
| | 无理数（无限不循环小数） | $\sqrt2,\ \pi,\ 0.3737737773\cdots$ |
| 按符号 | 正实数（正有理数、正无理数） | $\sqrt5,\ \pi$ |
| | $0$ | $0$ |
| | 负实数（负有理数、负无理数） | $-\sqrt3,\ -\pi$ |

**无理数的三种常见形态**（判断时逐一对照）：

1. 开方开不尽的数：$\sqrt2,\ \sqrt5,\ \sqrt[3]{4}$；
2. 含 $\pi$ 的数：$\pi,\ \dfrac{\pi}{2},\ \pi-3$；
3. 人为构造的无限不循环小数：$0.101001000\cdots$（每两个 1 之间依次多一个 0）、$0.3737737773\cdots$（每两个 3 之间 7 的个数依次加一）。

> [!note] 判断速查
> $\pi$ 是无理数，但 $3.14159$ 是有理数（有限小数）；$\dfrac{22}{7}$ 是分数，是有理数；$\sqrt4=2$ 是有理数；**无理数都是无限小数（√）**，**无限小数都是无理数（×，无限循环小数是有理数）**；实数分为正实数、零、负实数三类（漏 0 即错）；任何实数都能用数轴上的点表示。

## 🧮 平方根与开平方（12.2）

- **平方根**：若 $x^2=a$，则 $x$ 叫做 $a$ 的**平方根**（二次方根）。正数 $a$ 的平方根记作 $\pm\sqrt a$，$a$ 叫**被开方数**。
- **开平方**：求一个数平方根的运算，与**平方互为逆运算**。

| $a$ 的类型 | 平方根 | 算术平方根 |
| ---- | ---- | ---- |
| 正数 | 两个，互为相反数 $\pm\sqrt a$ | 正平方根 $\sqrt a$ |
| $0$ | 只有一个，是 $0$ | $0$ |
| 负数 | **不存在**（负数没有平方根） | 不存在 |

- **算术平方根**：正数的正平方根和零的平方根，统称算术平方根，记作 $\sqrt a\ (a\ge 0)$。**双重非负**：被开方数 $a\ge 0$，且 $\sqrt a\ge 0$。
- 由平方根定义立得：$(\pm\sqrt a)^2=a\ (a\ge 0)$；$\sqrt{a^2}=\lvert a\rvert$（先平方再开方须保非负，如 $\sqrt{(-4)^2}=4$）。

## 🧊 立方根与开立方（12.3）、n 次方根（12.4）

- **立方根**：若 $x^3=a$，则 $x$ 叫做 $a$ 的**立方根**（三次方根），记作 $\sqrt[3]{a}$；求立方根的运算叫**开立方**。
- **立方根性质**：任何实数**都有且只有一个**立方根；正数的立方根是正数，$0$ 的立方根是 $0$，负数的立方根是负数。常用关系：$\sqrt[3]{-a}=-\sqrt[3]{a}$；$(\sqrt[3]{a})^3=a$（对任意实数成立）。

| 对比 | 平方根 | 立方根 |
| ---- | ---- | ---- |
| 定义 | $x^2=a$ | $x^3=a$ |
| 个数 | 正数 2 个（互为相反数）；0 一个；负数没有 | 任何数都有且只有 1 个 |
| 记号 | $\pm\sqrt a$（要求 $a\ge 0$） | $\sqrt[3]{a}$（$a$ 可正、可负、可为 0） |

- **n 次方根**：若 $x^n=a$，则 $x$ 叫 $a$ 的 $n$ 次方根。**奇次方根**：任何实数都有且只有一个；**偶次方根**：只有非负数才有（正数有两个 $\pm\sqrt[n]{a}$，$0$ 的偶次方根是 $0$，负数没有）。

## 📏 实数与数轴（12.5）

- **一一对应**：==每一个实数都可以用数轴上的一个点表示，数轴上每一个点都表示唯一的一个实数==（有理数点之间还有"空隙"，无理数把数轴填满）。
- 数的范围扩充到实数后，**相反数、绝对值、倒数、大小比较**等概念照用：
  - 相反数：只有符号不同的两个实数，$-\sqrt2$ 与 $\sqrt2$ 互为相反数；
  - 绝对值：$\lvert a\rvert$ = 数轴上表示 $a$ 的点到原点的距离；数轴上两点 $A(a)$、$B(b)$ 的距离 $AB=\lvert a-b\rvert$；
  - 大小比较：数轴上**右边的点表示的数大**。无理数先用"两边夹"估出大致范围（如 $1<\sqrt2<2$），再比较；负数比较时**绝对值大的反而小**（$-\sqrt{12}<-\sqrt8$）。

## 🔢 实数的运算（12.6）与分数指数幂（12.7）

- **运算通则**：有理数的运算法则、运算性质、运算顺序（先乘方开方，再乘除，后加减，有括号先算括号）与运算律，**在实数范围内仍然适用**。
- 两条常用化简性质（八年级二次根式将系统展开）：

$$\sqrt a\cdot\sqrt b=\sqrt{ab}\ (a\ge 0,\ b\ge 0),\qquad \frac{\sqrt a}{\sqrt b}=\sqrt{\frac{a}{b}}\ (a\ge 0,\ b>0)$$

- **含无理数的运算**：若题目没有指明结果保留几位小数，通常利用运算法则与性质**化简算式**，结果可能是一个化简了的算式（如 $2\sqrt2+3\sqrt2=5\sqrt2$、$(\sqrt3)^2=3$、$(\sqrt3+1)(\sqrt3-1)=2$）；需要近似值时再用计算器。
- **分数指数幂**（把指数从整数推广到分数，方根与幂互化）：

$$a^{\frac{m}{n}}=\sqrt[n]{a^m}\ (a\ge 0),\qquad a^{-\frac{m}{n}}=\frac{1}{a^{\frac{m}{n}}}\ (a>0)$$

  例：$2^{\frac12}=\sqrt2$，$5^{\frac13}=\sqrt[3]{5}$，$49^{\frac12}=7$，$16^{-\frac14}=\dfrac12$；计算器可求分数指数幂的近似值。

> [!warning] 🔥 易错点
> - $\sqrt9=3$，但 9 的平方根必须写 $\pm\sqrt9=\pm3$——**漏写"±"是本章最高频错误**。
> - $\sqrt{(-4)^2}=\lvert-4\rvert=4$，不是 $-4$（"先平方后开方"要保证结果非负）；$(-\sqrt4)^2=4$ 与 $-\sqrt{4}=-2$ 要分清。
> - "$\sqrt{81}$ 的平方根是 $\pm3$"：先算 $\sqrt{81}=9$，再求 9 的平方根，不能直接答 $\pm9$。
> - 负数**没有平方根**，但**有立方根**：$\sqrt{-4}$ 无意义，$\sqrt[3]{-8}=-2$。
> - 无理数辨析：$\dfrac{22}{7}$ 是有理数；$0.101001000\cdots$（规律性不循环）是无理数；"无理数都是开方开不尽的数"是错的（含 $\pi$ 的数反例）。
> - 实数比较大小：$-\sqrt{12}$ 与 $-\sqrt8$，先比 $\sqrt{12}>\sqrt8$，再加负号反转；**别把负号方向弄反**。
> - 分数指数幂化方根时注意底数条件（负指数要求 $a>0$），$0$ 没有负指数幂。

## 📝 本讲小结

- **分类**：实数 = 有理数（有限小数 / 无限循环小数）+ 无理数（无限不循环小数）；按符号再分正实数、零、负实数。
- **平方根**：正数两个、互为相反数；0 一个；负数没有。算术平方根 $\sqrt a\ge 0$，双重非负。
- **立方根**：任何数都有且只有一个；$\sqrt[3]{-a}=-\sqrt[3]{a}$。n 次方根：奇次人人有，偶次非负才有。
- **数轴**：实数与数轴上的点**一一对应**；$AB=\lvert a-b\rvert$；绝对值、相反数概念照用。
- **运算**：法则、顺序、运算律照搬有理数；$\sqrt a\cdot\sqrt b=\sqrt{ab}$；不要求近似值时化简到最简算式。
- **分数指数幂**：$a^{\frac{m}{n}}=\sqrt[n]{a^m}$，方根与幂互化，负指数取倒数。
- **思想**：数形结合（数轴）、类比（平方根 ↔ 立方根）、从特殊到一般（n 次方根、分数指数幂）。

## 📮 例题速递

**1.**（12.2 课后练习 第 2 题，题源：12.2 课后练习 PDF 第 1 页）一个正数 $m$ 的两个平方根之和等于多少？这两个平方根的乘积是多少？

> [!tip]- 💡 思路导航
> 抓住平方根的性质：**正数的两个平方根互为相反数**。"和"与"积"都从这一条出。

> [!success]- ✅ 简解
> 设两个平方根为 $\sqrt m$ 与 $-\sqrt m$，它们互为相反数，所以**和为 $0$**；乘积为 $\sqrt m\cdot(-\sqrt m)=-m$，即**积为 $-m$**。
> **易错**：把"积"写成 $m$——相反数之积等于 $-m$（负号别丢）。

**2.**（12.6 课后练习 第 2（3）题，题源：12.6 课后练习 PDF 第 2 页）计算：$\sqrt[3]{-1000}-\sqrt{100}+\sqrt[3]{0.001}+\sqrt{36}$。

> [!tip]- 💡 思路导航
> 逐项"开方归位"：注意第三个是**立方根**（可以开负数、结果很小），别与平方根混。

> [!success]- ✅ 简解
> 原式 $=-10-10+0.1+6=-13.9$。
> **易错**：$\sqrt[3]{-1000}=-10$（负数能开立方）；$\sqrt[3]{0.001}=0.1$ 与 $\sqrt{0.01}=0.1$ 的混写是最常见笔误。
