# 整式（七年级上）

> [!note] 📖 使用导航
> 本文是概要版（初三基础回炉·考前速查）。公式总表：[[03-数学/知识点/00-六至八年级核心公式定理总表]]；同册章节：[[03-数学/知识点/七年级/分式]]；第一次学或没学懂 → 详细版：[[03-数学/知识点详解/七年级/整式]]

> [!note] 中考地位
> 全部代数变形的地基：整式运算是上海中考计算题与"化简求值"的基本功，**因式分解**更是分式化简、解一元二次方程、二次函数配方的核心工具。幂的运算法则、乘法公式、十字相乘法都是九年级还要反复用到的"硬通货"。

## 📌 整式的概念（9.1～9.4）

- **字母表示数**：字母可表示运算律（$a+b=b+a$）、公式（$S_{三角形}=\dfrac12 ah$）、未知数和有变化规律的数。
- **代数式**：用运算符号和括号把数或表示数的字母连接而成的式子；**单独一个数或一个字母也是代数式**。等号、不等号连接的式子（如 $S=\pi r^2$、$a>b$）**不是**代数式。
- **代数式的值**：用数值代替代数式里的字母，按运算关系算得的结果。求值时**代入要加括号**——负数与分数代入必须加括号。

### 单项式、多项式、整式

| 概念 | 定义 | 关键量 |
| ---- | ---- | ---- |
| 单项式 | 数与字母的乘积组成的代数式；单独一个数或一个字母也是单项式 | 系数＝数字因数；次数＝所有字母指数的和 |
| 多项式 | 几个单项式的和 | 项＝其中每个单项式（含符号）；次数＝**最高次项的次数** |
| 整式 | 单项式与多项式统称整式 | 分母中**不含字母** |

辨析示例（9.4 例题）：$ab^2$、$2a+3b$、$-\dfrac{4a^2b^4}{7}$ 是整式；$\dfrac{4x+y}{x}$（分母含字母）不是整式。

> [!warning] 概念易错
> - 系数带符号：$-\dfrac{4}{3}x^2y^2$ 的系数是 $-\dfrac{4}{3}$，不是 $\dfrac43$；$-\dfrac{4x^2y^2}{3}$ 同理。
> - $\pi$ 是**数**不是字母：$2\pi r$ 的系数是 $2\pi$，次数是 1（$r$ 的指数）。
> - 次数只看**字母**的指数：$2a^2$ 的次数是 2；$3\times10^5$ 是单项式，次数是 0（不含字母）。
> - 多项式的次数取"最高"：$a^4-2a^3-3a$ 的次数是 4，三项都要看。

## ✂️ 整式的加减（9.5～9.6）

- **同类项**：所含**字母相同**，且**相同字母的指数也相同**的单项式；几个常数项也是同类项。（与系数无关：$-4.5a$ 与 $2.3a$ 是同类项；$2x^2y$ 与 $-3y^2x^2$ 不是。）
- **合并同类项法则**：把同类项的**系数相加**作为结果的系数，**字母和字母的指数不变**。
- **去括号法则**（由有理数去括号类比得来）：
  - 括号前是"＋"号：去掉"＋"号和括号，括号里各项**不变号**；
  - 括号前是"－"号：去掉"－"号和括号，括号里各项**都变号**。

  符号语言：$a+(b+c-d)=a+b+c-d$；$a-(b+c-d)=a-b-c+d$。
- 添括号是去括号的逆向运用：添"－"号括号，进括号的各项同样**全部变号**——配方法、因式分解分组时常要用。
- **整式加减的步骤**：先去括号，再合并同类项。

> [!warning] 计算易错（9.5/9.6 辨析题原题）
> - $-2x-3x=-5x$，不是 $-5$——合并的是系数，字母别丢。
> - $2x+3y\ne 5xy$——不是同类项，不能合并。
> - $3x^2-2x^2=x$（系数 $3-2=1$ 省略不写），不是 $x^2$。
> - $-5xy+2xy=-3xy$，符号要带走。

## 🔢 幂的运算法则（9.7～9.9、9.17）

| 运算 | 法则 | 公式 | 条件 |
| ---- | ---- | ---- | ---- |
| 同底数幂的乘法 | 底数不变，**指数相加** | $a^m\cdot a^n=a^{m+n}$ | $m,n$ 为正整数 |
| 幂的乘方 | 底数不变，**指数相乘** | $(a^m)^n=a^{mn}$ | $m,n$ 为正整数 |
| 积的乘方 | 每个因式分别乘方 | $(ab)^n=a^nb^n$ | $n$ 为正整数 |
| 同底数幂的除法 | 底数不变，**指数相减** | $a^m\div a^n=a^{m-n}$ | $a\ne 0$，$m>n$ |
| 零指数幂 | 任何不等于 0 的数的 0 次幂等于 1 | $a^0=1$ | $a\ne 0$ |

- 三个及以上的同底数幂相乘同样适用：$a^m\cdot a^n\cdot a^p=a^{m+n+p}$；$(abc)^n=a^nb^nc^n$。
- 底数可以是数、字母，也可以是**多项式**：$(a+b)^2\cdot(a+b)^3=(a+b)^5$。
- 除法注意符号统一：$(-a)^7\div a^6=-a$（奇次幂把负号提出来）；$(a-b)^{19}\div(b-a)^{10}=(a-b)^9$（偶次幂 $(b-a)^{10}=(a-b)^{10}$）。

## ✖️ 整式的乘法（9.10）

- **单项式 × 单项式**：系数相乘作系数；同底数幂相乘（指数相加）；只在某个单项式里含有的字母，连同它的指数写在积里。例：$-4ax^2\cdot(-3a^2x^3)=12a^3x^5$。
- **单项式 × 多项式**：用分配律，$m(a+b+c)=ma+mb+mc$，每一项都要乘到。
- **多项式 × 多项式**：先用一个多项式的每一项乘以另一个多项式的每一项，再把所得的积相加，即

  $$(a+m)(b+n)=ab+an+bm+mn$$

  例：$(x-2)(x+7)=x^2+5x-14$。

> [!warning] 乘法易错
> - 系数别漏乘：$6a^8\cdot 6a^8=36a^{16}$，不是 $12a^{16}$。
> - 多项式乘多项式**每一项都要乘遍**，注意不重不漏，最后合并同类项。
> - 连乘符号要看清：$-2x^2y\cdot 5xy^3\cdot\Big(-\dfrac35x^2y^2\Big)=6x^5y^6$，负负得正。

## 📐 乘法公式（9.11～9.12）

| 名称 | 公式 | 结构特征 |
| ---- | ---- | ---- |
| 平方差公式 | $(a+b)(a-b)=a^2-b^2$ | 一同一异：同号项平方 **减** 异号项平方 |
| 完全平方公式 | $(a\pm b)^2=a^2\pm 2ab+b^2$ | 首平方，尾平方，首尾两倍中间放 |

- 两数**和**的平方＝两数的**平方和，加上**它们积的两倍；两数**差**的平方＝平方和**减去**积的两倍。公式中的 $a$、$b$ 可以是任意的数或代数式。
- 乘法公式是多项式乘多项式的**特例**（从一般到特殊），可用图形面积验证（正方形分割图）。
- 常用变形（9.12 课后练习第 2(7)(8) 题）：

  $$(a+b)^2-(a-b)^2=4ab,\qquad (a+b)^2+(a-b)^2=2a^2+2b^2$$

  由此 $a^2+b^2=(a+b)^2-2ab=(a-b)^2+2ab$——知二求一的桥梁。

> [!warning] 公式易错
> - $(a+b)^2\ne a^2+b^2$：==中间项 $2ab$ 是最容易丢的==。
> - $(a-b)^2=a^2-2ab+b^2$，展开永远三项；$(x-y)(x+y)=x^2-y^2$ 才是两项。
> - 带系数的项要整体平方：$(3x+2)^2=9x^2+12x+4$，首项是 $(3x)^2$ 不是 $3x^2$。
> - 负号进出：$(-x-y)(x+y)=-(x+y)^2=-x^2-2xy-y^2$；$(-x-y)(x-y)=y^2-x^2$。

## 🧰 因式分解（9.13～9.16）

- **定义**：把一个多项式化为**几个整式的积**的形式，叫做把这个多项式因式分解（分解因式）。
- **与整式乘法的关系**：正好相反，互为逆变形。$ab+ac=a(b+c)$，从左到右是因式分解，从右到左是整式乘法。
  - 判断标准（9.13 例题）：左边是"和"右边是"积"才是分解，如 $3xy-4x^2y+5x^2y^2=xy(3-4x+5xy)$ ✓；$3x(x+y)=3x^2+3xy$ 是整式乘法 ✗；$1+2x+3x^2=1+x(2+3x)$ 右边不是"整式的积" ✗。

### 四种方法与选择顺序

| 方法 | 适用模型 | 例 |
| ---- | ---- | ---- |
| 提取公因式法 | 各项含公因式 | $10a^3bc^2+15a^2b^2c=5a^2bc(2ac^2+3b)$ |
| 公式法（平方差） | 二项、两平方差 | $x^2-100=(x+10)(x-10)$ |
| 公式法（完全平方） | 三项、"首尾和中间" | $x^2-8xy+16y^2=(x-4y)^2$ |
| 十字相乘法 | $x^2+px+q$，$q=ab$ 且 $a+b=p$ | $x^2-7x+12=(x-3)(x-4)$ |
| 分组分解法 | 四项，"2+2"或"3+1"分组 | $2ac-6ad+bc-3bd=2a(c-3d)+b(c-3d)=(2a+b)(c-3d)$ |

- **公因式**：各项系数的**最大公约数** × 相同字母的**最低次幂**。首项为负时先提负号，括号内各项变号。
- **十字相乘法**（沪教版七上就学）：$x^2+(a+b)x+ab=(x+a)(x+b)$——拆**常数项**凑**中间项**。
- **分组分解法**：恰当分组后组内提公因式、组间再提公因式，或先组成完全平方再平方差（如 $a^2+2ab+b^2-1=(a+b)^2-1$）。
- 一般顺序：==一提二套三十字四分组，分解要彻底==。

> [!warning] 分解易错
> - 提公因式后**括号里的项数不变**：$-4x^2y+6xy^2-2xy=-2xy(2x-3y+1)$，别丢"+1"。
> - **分解要彻底**：每个因式都不能再分才停，如 $2a^3-8a=2a(a^2-4)=2a(a+2)(a-2)$；$x^4-16$ 要用两次平方差。
> - 结果必须是"积"的形式：$1+x(2+3x)$ 不是因式分解。
> - 提负号要变号：$-3ax+6ab-12ay=-3a(x-2b+4y)$。

## ➗ 整式的除法（9.18～9.19）

- **单项式 ÷ 单项式**：系数相除作系数；同底数幂相除（指数相减）；只在被除式里含有的字母连同指数不变写在商里。例：$16x^5y^8\div 4x^2y^3=4x^3y^5$；$-7x^4y^2\div(-21x^2y^2)=\dfrac13x^2$（系数 $-7\div(-21)=\dfrac13$，负负得正）。
- **多项式 ÷ 单项式**：多项式的每一项分别除以这个单项式，再把所得的商相加，即

  $$(ma+mb+mc)\div m=a+b+c$$

  例：$-18x^3y^2+12x^2y^3-6x^2y^2$ 除以 $-3x^2y^2$，得 $6x-4y+2$——**每一项都别漏**。

> [!warning] 🔥 易错点汇总
> - 幂运算三兄弟别混：$a^3\cdot a^4=a^7$（加），$(a^3)^4=a^{12}$（乘），$(2a)^4=16a^4$（每个因式都乘方）；$2^3\times 2^4$ 是幂的乘法（$=2^7$），而 $2^3+2^4$ 是加法，**不能套幂的法则**。
> - $a^{10}\div a^5=a^5$，不是 $a^2$（指数相减不是相除）。
> - $x^5+x^5=2x^5$，不是 $x^{10}$——合并同类项与幂运算分开处理。
> - 去括号变号：$-(a-b)+(2c-3d)=-a+b+2c-3d$，负号后第一项也要变。
> - $(x-y)^2=x^2-2xy+y^2$，绝不能等于 $x^2-y^2$。
> - 混合运算顺序：先乘方开方，再乘除，后加减，有括号先算括号。

## 📝 本讲小结

- **概念链**：字母表示数 → 代数式 →（单项式/多项式）→ 整式；求值即"代入＋计算"。
- **加减**：去括号（＋不变、－全变）→ 合并同类项（系数相加、字母不变）。
- **幂运算**：乘（指数加）、乘方（指数乘）、积的乘方（各自乘方）、除（指数减）、零指数 $a^0=1$（$a\ne0$）。
- **乘法**：单×单、单×多（分配律）、多×多（每项乘遍）；两个乘法公式是特例，逆用可求 $a^2+b^2$。
- **因式分解**：与整式乘法互逆；一提二套三十字四分组，**分解要彻底**。
- **除法**：单÷单逐个相除；多÷单每一项分别除。
- **思想**：类比（数→式）、化归（新运算→旧运算）、数形结合（公式面积图）、从特殊到一般。

## 📮 例题速递

**1.**（9.12 课后练习 第 4(2) 题，题源：9.12 课后练习 PDF 第 1 页）化简：$(x+1)^2-(x-2)(x+2)$。

> [!tip]- 💡 思路导航
> 两个乘法公式同台：前者是完全平方，后者是平方差；展开后**再去括号合并**——减号后面要整体加括号变号。

> [!success]- ✅ 简解
> $(x+1)^2-(x-2)(x+2)=x^2+2x+1-(x^2-4)=x^2+2x+1-x^2+4=2x+5$。
> **易错**：直接把 $(x-2)(x+2)$ 写成 $x^2+4$，或减号后忘记变号。

**2.**（9.14 课后练习 第 3(2) 题，题源：9.14 课后练习 PDF 第 1 页）分解因式：$x^4-16$。

> [!tip]- 💡 思路导航
> 二项式先想平方差；分解出 $x^2+4$ 与 $x^2-4$ 后自问“还能不能再分”——$x^2-4$ 仍能用平方差。

> [!success]- ✅ 简解
> $x^4-16=(x^2+4)(x^2-4)=(x^2+4)(x+2)(x-2)$。
> **易错**：只分解一次得 $(x^2+4)(x^2-4)$ 就停笔——分解要彻底。同类题：$2a^3-8a=2a(a+2)(a-2)$（先提公因式再用平方差）。
