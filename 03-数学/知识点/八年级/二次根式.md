# 二次根式（八年级上）

> [!note] 📖 使用导航
> 本文是概要版（初三基础回炉·考前速查）。公式总表：[[03-数学/知识点/00-六至八年级核心公式定理总表]]；同册章节：[[03-数学/知识点/八年级/一元二次方程]]；第一次学或没学懂 → 详细版：[[03-数学/知识点详解/八年级/二次根式]]

> [!note] 中考地位
> 上海中考计算题（化简、混合运算、分母有理化）的常客，也是勾股定理、函数、解三角形等一切含根号问题的运算基础。==根号下字母的取值范围==是选择填空的经典小题。

## 📌 概念与有意义条件

- **二次根式**：形如 $\sqrt{a}$（$a \ge 0$）的式子。**双重非负性**：被开方数 $a\ge 0$，且 $\sqrt{a}\ge 0$。
- **有意义的条件**：被开方数 $\ge 0$；若根号外还有分母，再叠加"分母 $\ne 0$"。
  - 例：$\sqrt{2x}$ 有意义 $\iff x\ge 0$；$\sqrt{\dfrac{2}{x-1}}$ 有意义 $\iff x-1>0$；$\sqrt{-x^2}$ 有意义 $\iff x=0$。

## 🧮 两个基本性质

| 性质 | 表达式 | 条件 |
| ---- | ---- | ---- |
| 性质 1 | $(\sqrt{a})^2=a$ | $a\ge 0$ |
| 性质 2 | $\sqrt{a^2}=a$ | $a\ge 0$（一般地 $\sqrt{a^2}=\lvert a\rvert$，对任意实数 a 成立） |

- 两者互为逆运算关系的体现：**先开方再平方（性质 1）不损失符号；先平方再开方（性质 2）要用绝对值保结果非负**。
- $\sqrt{a^2}=\lvert a\rvert$ 的两个常用落点：
  - $\sqrt{(\pi-4)^2}=4-\pi$（因为 $\pi<4$）；$\sqrt{(\pi-3)^2}=\pi-3$（因为 $\pi>3$）；
  - $\sqrt{(a-b)^2}=\begin{cases}a-b & a\ge b\\ b-a & a<b\end{cases}$——**先判断被开方数开出来是正是负**。

## ✂️ 最简二次根式与同类二次根式

**最简二次根式**须同时满足：

1. 被开方数**不含分母**；
2. 被开方数中**不含能开得尽方的因数或因式**。

判别步骤：先看根号内有无分母 → 再把被开方数分解因数/因式，看有无"平方数因子"。例：$\sqrt{18}=3\sqrt2$（$18$ 含 $9$），$\sqrt{\dfrac{a}{3}}$ 含分母，都不是最简二次根式。

**同类二次根式**：几个二次根式**化成最简二次根式后**，如果被开方数相同，就叫做同类二次根式（类比"同类项"）。判别口诀 ==先化最简，再看被开方数是否相同==。

| 概念 | 判断对象 | 关键动作 |
| ---- | ---- | ---- |
| 最简二次根式 | 单个根式 | 查分母、查平方因子 |
| 同类二次根式 | 一组根式 | 先各自化最简，再比较被开方数 |

## 🔢 二次根式的运算

**乘除法则**（正用化简、逆用合并）：

$$\sqrt{a}\cdot\sqrt{b}=\sqrt{ab}\ (a\ge 0,\ b\ge 0),\qquad \frac{\sqrt a}{\sqrt b}=\sqrt{\frac{a}{b}}\ (a\ge 0,\ b>0)$$

**加减法则**：各根式先化成**最简二次根式**，再合并**同类二次根式**（类比合并同类项，系数相加减、根号部分不变）。

- 例：$\sqrt{48}+\sqrt{75}=4\sqrt3+5\sqrt3=9\sqrt3$；不是同类的（如 $\sqrt2$ 与 $\sqrt3$）不能合并，保留即可。

**有理化因式与分母有理化**：两个含二次根式的代数式相乘，若积不含二次根式，则它们互为**有理化因式**。常用搭配：

| 式子 | 有理化因式 |
| ---- | ---- |
| $\sqrt a$ | $\sqrt a$ |
| $\sqrt a\pm\sqrt b$ | $\sqrt a\mp\sqrt b$（平方差） |
| $a\sqrt b$ | $\sqrt b$（或 $\dfrac{1}{\sqrt b}$ 思路） |

**混合运算**：顺序与整式一样（先乘方开方，再乘除，后加减，有括号先算括号），运算律（分配律等）照用。本章还会用这些运算**解一次项系数或常数项含二次根式的一元一次方程、不等式**——把 $\sqrt2$、$\sqrt3$ 当成"字母"参与合并与移项。

> [!warning] 🔥 易错点（从教材练习与课后作业错型提炼）
> - $\sqrt{a^2+b^2}\ne a+b$：根号内的"+"不能拆开（对应课后判断题（4））。
> - $\sqrt{a^2}=a$ 只在 $a\ge0$ 时成立：$a<0$ 时必须写 $\lvert a\rvert$，如 $\sqrt{(3-\pi)^2}=\pi-3$、$\sqrt{(4-\pi)^2}=4-\pi$，别"见平方就摘"。
> - $(-\sqrt a)^2=a$ 而不是 $-a$；$\sqrt{(-a)^2}=\lvert a\rvert$，与 $-\sqrt{a^2}$ 相区分。
> - 加减前**必须先化最简**再合并：$\sqrt{12}$ 与 $\sqrt{\tfrac13}$ 化简后是 $2\sqrt3$ 与 $\tfrac{\sqrt3}{3}$，才是同类。
> - 分母有理化时分子分母**同乘**同一个因式，别只乘分母；结果要约到最简。
> - 求 $\sqrt{a^2}$ 型的值要先定 $a$ 的范围（如 $a=\tfrac15$ 时 $\tfrac1a-a>0$），方向错了整题错。

## 📝 本讲小结

- **概念**：$\sqrt a$（$a\ge0$），双重非负；有意义 = 被开方数 $\ge0$（有分母再加 $ \ne 0$）。
- **性质**：$(\sqrt a)^2=a$（$a\ge0$）；$\sqrt{a^2}=\lvert a\rvert$（任意实数）。
- **化简**：目标是最简二次根式（无分母、无开得尽方的因子）；工具是分解因数/因式与分母有理化。
- **运算**：乘除合一根号；加减先化最简、合并同类二次根式；混合运算顺序同整式。
- **思想**：类比整式（同类项 ↔ 同类二次根式）、化归（新运算 → 旧运算）。

## 📮 例题速递

**1.**（16.1 课后练习 第 5 题，题源：16.1 课后练习 PDF 第 2 页·练习册第 1 页第 5 题）先看甲乙两人对以下问题的解答，再进行判断．

化简求值：$\dfrac{1}{a}+\sqrt{\dfrac{1}{a^{2}}+a^{2}-2}$，其中 $a=\dfrac{1}{5}$．

甲的解答是：$\dfrac1a+\sqrt{\dfrac{1}{a^2}+a^2-2}=\dfrac1a+\sqrt{\Big(\dfrac1a-a\Big)^2}=\dfrac1a+\dfrac1a-a=\dfrac2a-a=\dfrac{49}{5}$．

乙的解答是：$\dfrac1a+\sqrt{\dfrac{1}{a^2}+a^2-2}=\dfrac1a+\sqrt{\Big(a-\dfrac1a\Big)^2}=\dfrac1a+a-\dfrac1a=a=\dfrac15$．

谁的答案是错误的？为什么？

> [!tip]- 💡 思路导航
> 根号内的 $\dfrac{1}{a^2}+a^2-2$ 恰是完全平方式，配成 $\Big(\dfrac1a-a\Big)^2$ 后**必须先判断被开方数开出来的符号**再取绝对值——甲乙的分歧行就在这一步。

> [!success]- ✅ 简解
> **乙错**。当 $a=\dfrac15$ 时 $\dfrac1a-a=5-\dfrac15>0$，而 $a-\dfrac1a<0$，故 $\sqrt{\Big(a-\dfrac1a\Big)^2}=\Big|\dfrac1a-a\Big|=\dfrac1a-a$，不能直接取 $a-\dfrac1a$。正确结果为甲的 $\dfrac{49}{5}$。
> **考点**：$\sqrt{a^2}=\lvert a\rvert$ 必须先判断符号——本章最高频易错点。

**2.**（16.1 课后练习 第 4(1) 题，题源：16.1 课后练习 PDF 第 2 页）求二次根式的值：$\sqrt{(\pi-4)^2}$。

> [!tip]- 💡 思路导航
> 同一个模型 $\sqrt{a^2}=\lvert a\rvert$：只差 $\pi$ 与 4、3 的大小关系，结果方向相反。

> [!success]- ✅ 简解
> 因为 $\pi<4$，所以 $\sqrt{(\pi-4)^2}=\lvert\pi-4\rvert=4-\pi$。（同类陷阱：$\sqrt{(\pi-3)^2}=\pi-3$，方向相反。）
