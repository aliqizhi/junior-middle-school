# 圆与正多边形（九年级下）

> 中考地位：**第 25 题压轴的另一半**（相似 + 圆），选择填空也常考基本性质。垂径定理 + 圆周角定理是两大支柱。

## 📌 知识结构（27.1-27.6）

### 圆的确定（27.1）

- 过不在同一直线上三点确定一个圆；外接圆/外心（三角形三边垂直平分线交点）
- 点与圆位置关系：$d\lessgtr r$ → 点在圆外/上/内

### 圆心角、弧、弦、弦心距（27.2）

- 同圆等圆中：圆心角 ⟺ 弧 ⟺ 弦 ⟺ 弦心距（一组相等则其余全相等）
- 圆周角定理：圆周角 = 同弧圆心角的一半；**直径所对圆周角 = 90°**（构造直角三角形的钥匙）

### 垂径定理（27.3）★高频

垂直于弦的直径**平分弦，并且平分弦所对的两条弧**。

标准构图：半径 r、弦长 c（半弦 a）、弦心距 d → **$r^2 = a^2 + d^2$**（勾股），逢垂径先画"十字架"。

### 直线与圆（27.4）

- 位置关系：$d>r$ 相离；$d=r$ 相切；$d<r$ 相交
- 切线性质：切线 ⊥ 过切点的半径
- 切线判定：过半径外端且垂直于半径的直线是切线（证明题两句话写全）
- 切线长定理：圆外一点引两条切线，切线长相等，连心线平分夹角

### 圆与圆（27.5）

- 五种位置关系由圆心距 d 与 R、r 判定：外离 $d>R+r$；外切 $d=R+r$；相交 $|R-r|<d<R+r$；内切 $d=|R-r|$；内含 $d<|R-r|$

### 正多边形与圆（27.6）

- 中心角 $=\dfrac{360°}{n}$；内角 $=\dfrac{(n-2)\cdot180°}{n}$
- 半径 R、边心距 r、半边长 a：$R^2=r^2+a^2$
- 弧长 $l=\dfrac{n\pi R}{180}$；扇形面积 $S=\dfrac{n\pi R^2}{360}=\dfrac{1}{2}lR$

## 🧩 典型例题（第 25 题套路）

> **套路**：圆中出现等角 → 找圆周角相等 → 转化为相似三角形 → 比例式 → 函数关系/定值。
>
> **组合拳**：直径出直角 → 勾股/相似；切线出垂直 → 半径即斜边；同弧圆周角 → 等角代换。

## 🔥 易错点

- 垂径定理的"弦"要是**非直径弦**（直径情形另证）。
- 圆周角定理用错弧：确认角对着哪条弧再换算。
- 相交两圆的圆心距范围是 $|R-r|<d<R+r$，端点是相切不是相交。
- 分类：点/直线/圆的位置关系讨论动点时，漏"相切"临界情形最常见。
