# 相似三角形（九年级上）

> 中考地位：**第 23 题（几何论证）的核心考点 + 第 25 题压轴的骨架**。判定和性质必须做到"看见图形 3 秒内反应"。

## 📌 知识结构

### 1. 成比例线段与相似形（24.1-24.3）

- **比例性质**：$\dfrac{a}{b}=\dfrac{c}{d} \Rightarrow ad=bc$（交叉相乘）；合比、等比性质。
- **黄金分割**：点 C 把线段 AB 分成 $\dfrac{AC}{AB}=\dfrac{\sqrt5-1}{2}\approx0.618$（较长段比全长）。中考常与相似、圆结合出题。
- **平行线分线段成比例**：平行于三角形一边的直线截其他两边，所得线段对应成比例（**A 字型 / 8 字型的基础**）。

### 2. 相似三角形的判定（24.4）

| 判定 | 简写 | 典型图形 |
| ---- | ---- | ---- |
| 两角对应相等 | AA | 公共角、对顶角、同角的余角 |
| 两边成比例且夹角相等 | SAS | 旋转手拉手模型 |
| 三边成比例 | SSS | 网格题 |
| **平行线法**（上海特色表述） | 平行于一边的直线截得三角形与原三角形相似 | A 字、8 字 |

**常见模型（识别即得分）**：A 字型、8 字型（X 型）、母子型（Rt△ 斜边上的高）、一线三等角、旋转相似。

### 3. 相似三角形的性质（24.5）

- 对应边成比例、对应角相等
- 周长比 = 相似比；**面积比 = 相似比的平方**（易错：直接用面积比开方找相似比时别忘了开方方向）
- 对应高、对应中线、对应角平分线之比 = 相似比

### 4. 平面向量（24.6-24.7）

- 实数与向量相乘：$\vec{AB}=\lambda\vec{AC}$ 共线判定
- 向量加法三角形法则：$\vec{AB}+\vec{BC}=\vec{AC}$；减法：$\vec{AB}-\vec{AD}=\vec{DB}$
- **平面向量几乎每年在选择/填空考 1 题**：分解式（基底表示）是主流考法

## 🧩 典型例题（第 23 题套路）

> **题目**：梯形/四边形中，已知 AB∥CD，求证 △△ 相似，再求比例中项。
>
> **思路**：找平行线 → 得等角（A 字或 8 字）→ AA 判定 → 写对应边比例式 → 代入求值。
>
> **规范书写**：每一步标注依据（"两角对应相等的两个三角形相似"），结论句写全。

## 🔥 易错点

- 相似比有方向：△ABC ∽ △DEF 时，$\dfrac{AB}{DE}$ 才是对应边比，写反全盘皆错。
- 面积比 = 相似比的**平方**，不是相似比。
- "共角共边"型（母子型）：公共角两边成比例即可判定，别漏用公共角。
- 动点相似问题：**分类讨论**（对应关系可能有两种）。
