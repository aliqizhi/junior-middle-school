# 二次函数（九年级上）

> 中考地位：**第 24 题（12 分）专属考点**，也常出现在选择填空。核心是"图象 + 表达式 + 几何综合"三位一体。

## 📌 定义与公式

### 三种表达式（按条件选最省事的）

| 形式 | 适用条件 |
| ---- | ---- |
| 一般式 $y=ax^2+bx+c$ | 已知三个点 |
| 顶点式 $y=a(x+m)^2+k$（沪教版用 +m 记号！） | 已知顶点/对称轴/最值 |
| 交点式 $y=a(x-x_1)(x-x_2)$ | 已知与 x 轴两交点 |

> ⚠️ **沪教版顶点式记号与全国版不同**：沪教版是 $y=a(x+m)^2+k$，顶点 $(-m,k)$。平移口诀相应为"左加右减"对应 m 的变化。别混用两套记号！

### 图象性质

- 开口：a>0 向上（有最小值）；a<0 向下（有最大值）
- 对称轴 $x=-\dfrac{b}{2a}$（一般式）；顶点 $(-m,k)$（顶点式）
- **平移**：左加右减（自变量）、上加下减（常数项）；平移只改位置不改形状（a 不变）
- 对称性：抛物线上纵坐标相等的两点关于对称轴对称——求交点/对称点的利器

## 🧩 第 24 题五大题型

1. **平移问题**：先写出平移后的表达式（顶点加减），再联立求交点/面积。
2. **面积问题**：割补法 / 铅垂法 $S=\dfrac{1}{2}\times 水平宽 \times 铅垂高$；常与最值结合。
3. **等腰/直角三角形存在性**：分类（谁当顶角顶点/直角顶点），坐标列方程，别漏解。
4. **角度问题**：转化为三角比相等（构造直角三角形）或平行（斜率相等）。
5. **新定义抛物线**（回归抛物线/优雅抛物线/不动点等）：把定义逐字翻译成代数条件。

## 🔥 易错点

- **定义域**：动点在线段上时，横坐标有范围，求函数关系式必须写定义域！
- 存在性问题分类不全：等腰三角形 3 类、直角三角形 3 类，逐类检查。
- a 的符号影响最值方向："最大值"只在 a<0 时成立，别套反。
- 求交点联立方程后，判别式要算（判交点个数/参数范围）。
