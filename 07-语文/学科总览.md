# 语文 · 学科总览

> 语文 150 分中**作文 60 + 古诗文 36 + 现代文 34 + 综合运用 20**（2025 真题结构）。2027 届是新中考改革元年：样卷出现病句题、作文改自拟题、A 类卷加"立意深刻"要求。老师纪要的核心策略：**滚动古诗文默写 + 审题能力 + 条理清晰的逻辑分析**。

## 🎯 考情速览（据 2025 真题深度分析，与家长会纪要互证）

| 模块 | 分值 | 核心考点 | 抽样失分率 |
| ---- | ---- | ---- | ---- |
| 文言文阅读 | 36 | 默写、实词、翻译、**文本互证**（原文+评点对比） | 18-22% |
| 现代文阅读 | 34 | 情节分析、语言鉴赏、**文体比较**（新闻通讯 vs 特写） | 25-30% |
| 综合运用 | 20 | 文献梳理、探究启示、诗歌赏析（跨学科情境） | 20-25% |
| 写作 | 60 | 辩证立意与叙事抒情 | **35%（审题偏差）** |

## 📌 老师策略与备考建议（家长会 + 深度分析报告）

### 默写与古诗文（"绝不丢的分"）

- 课内古诗文 35 分**全力争取**：默写覆盖《望岳》《岳阳楼记》等课内篇目；九上文言文加重（《醉翁亭记》《岳阳楼记》《曹刿论战》）
- **滚动默写保持正确率，家默抽背签字**（家长会要求，正确率 ≥95%）
- 文言翻译兼顾"信"与"达"：如"何陋之有"须调整为"有什么简陋的呢？"
- 文言新趋势："经典评点 + 原文"对比阅读，强化文本互证——只答"品德高尚"表层会丢分

### 现代文阅读（审题与分析框架）

- 记叙文建立"**细节描写 → 情节作用 → 主题表达**"分析框架
- 实用文区分文体语言：通讯客观严谨 vs 特写细节现场感（新中考爱考文体比较）
- 审题是重点（纪要原话："准确把握文本主旨/作者观点，条理清晰，逻辑自洽"），从文字挖掘深意，可能需正面+侧面描写结合

### 综合运用（20 分，跨学科情境）

- 围绕真实情境的阶梯任务（文献查证 → 历史梳理 → 诗歌创作）
- 关注文化遗产、乡村振兴等主题；新文体可能扩展到短视频脚本、直播文案

### 写作（60 分，审题定生死）

- **审题拆解关键词**：如 2025 题"相互成全"，"相互"须突出双向性，单向叙事即偏题
- A 类卷标准："立意深刻"（新要求，取消"有新意"）——真情实感、材料与中心匹配
- 素材体系：构建"个人—社会—历史"三层（管鲍之交、国际文物合作等），**保留作文电子稿按主题归档**（老师要求）
- 反对编造：虚构套路化情节是大忌（纪要明确）
