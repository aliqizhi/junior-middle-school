# 知识库质量规范（2026-11-04 起生效）

> 用户确认的两项决策：**折叠用 Obsidian 原生 callout（样式 A）**；**填空空位用全角下划线**。本规范对全库真题精讲/知识点生效，新文件一律遵守。

## 一、题干配图（铁律）

1. 卷面有图的题，**必须**裁切配图入库并在文档中引用：`![第N题图](figs/{系列}-{区}/q{题号}.png)`。**禁止**用 `[图示：…]` 占位或纯文字描述替代配图。
2. 工作流：页图（150dpi）Read 定位 → PIL 按比例裁切（脚本放 /tmp/en_ym26_tools/crop_{名}.py，`python3 -I` 运行）→ **Read 核验裁片**（完整、不带邻题、不缺边）→ 存 figs 目录 → md 引用。偏了调坐标重裁（≤2 轮），仍不理想则用最接近版本并在图下注明"裁片略偏"。
3. 图源页图位置见各批次任务书；/tmp 丢失可用 `pdftoppm -png -r 150 <pdf> <前缀>` 重生成（原件在 `~/Downloads/00.中考/`）。
4. 文字描述不保留在题干里（图已可达）；描述中的**题干信息**（如"滑片 P 向右移动"）本来就该在题干文字里，不因嵌图而丢失。

## 二、真题精讲版式

1. **选项逐行**：选择题每个选项独立一行（缩进对齐），禁止四个选项挤一行：

   ```
   **21.** It is ______ common knowledge that the earth is round.
   - A) a
   - B) an
   - C) the
   - D) /
   ```

   （中文选项用（A）（B）（C）（D）全角括号，同样逐行；选项前可用无序列表或直接换行，同文件内统一。）

2. **填空空位**：一律用 **8 个全角下划线** `＿＿＿＿＿＿＿＿` 替代 ▲、`____`、单个下划线等短空位。（留作手写感；答案在解析中给。）
3. **小题编号**：同一文件内统一为**全角（1）（2）**；禁止 (1)、（1）、① 在同一文件内混用。题干内部的 ①②③ 枚举（原卷固有记号）保留不动。
4. **题目序号弱化**：题号统一 `**N.**` 加粗形式作行首锚点，不用标题层级表示题号；每题之间空一行。
5. **折叠区块（样式 A，已确认）**：每题解析组织为两个默认折叠的 Obsidian callout，题干与配图始终展开：

   ```
   > [!tip]- 💡 思路导航
   > 一两句破题要点（从详解中提炼"从哪里下手"），不含最终答案。

   > [!success]- ✅ 详解 · 评分点 · 易错 · 关联
   > **详解**：完整解答过程与答案。
   >
   > **评分点**：分步给分点（如有）。
   >
   > **易错**：常见错误与辨析（如有）。
   >
   > **关联**：知识点链接 / 同系列同类题（如有）。
   ```

   - 缺失的子项（评分点/易错/关联）整体省略，不留空标签。
   - 文件级说明、卷面结构说明等**不折叠**。
   - 注意 callout 内每行都要以 `>` 开头；空行用单独的 `>`。

## 三、知识点 / 知识点详解版式

1. 章节用多级标题（## 分章、### 分节）；**重要结论/概要加粗**；易混概念、公式、单位用行内代码 `` ` `` 或 LaTeX；关键句可用 `==高亮==`（Obsidian 支持）。
2. 枚举用有序/无序列表；对照类内容用表格；"注意/提示"用 `> [!warning]` / `> [!note]` callout。
3. 章末"本讲小结"用加粗 + 列表收束。

- [ ] 所有选择题选项逐行
- [ ] 填空位全部为 8 全角下划线
- [ ] 小题编号文件内统一
- [ ] 解析均为两个折叠 callout（tip + success）
- [ ] 所有 `![...]()` 引用路径真实存在且裁片已 Read 核验
